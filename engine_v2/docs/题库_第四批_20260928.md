# 题库第四批：补上「跑」这一级，并给每路感觉配一格「什么都没来」（2026-09-28 夜，全库 123 道题）

一句话：整套题库现在是 **123 道题、15 个方面、7 级先修阶梯**。这一批加了 4 道、改写了 3 道，
改的是两件事：把「跑」这一级补齐；以及**每一路感觉都配上相反的那一格**——没有信号的时候，
读数不再是一片 0，而是旁边那格亮着。第三批那份文档里的 116 道，加上这一批就是现在的全库。

## 三、相反神经元这一批到底补了什么

- **接外部信号的那几路感觉，每一路都是两格。** 进来的那格拿到信号本身，旁边那格拿到「1 减去同一个
  数」，同一拍、同一个来源。所以没有信号进来的时候，第二格是亮着的。（本体那种「亮了几格就代表多大」
  的通道不用另配一格：亮着的前一半说的就是「这一档到了」，剩下那半说的就是「还没到」。）
- **补的路**：碰、绊（脚前有东西）、打滑、脚底受力（各 4 格）、耳蜗（6 格）、耳朵分前后（6 格）、
  耳廓（4 格），加上视觉：每个像素旁边一格（`photoreceptors_opposite`），而且**没光的那一半有自己
  的汇总层**（`retina_opposite`），不并进亮的那一半 —— 因为「不是红」不等于红。
- **出厂实测**（三种子，都是真跑）：
  - 全黑：`photoreceptors` 0.00000、`photoreceptors_opposite` 0.96985、`retina_opposite` 0.97143；全白反过来。
  - 安静：`cochlea` 0.00000、`cochlea_opposite` 0.98983。
  - 没人碰：`body_touch`、`foot_obstacle`、`foot_slip` 全 0.00000，旁边三格全 1.00000。
  - 站在地上：四只脚 0.424 / 0.544 / 0.485 / 0.446 对 0.576 / 0.456 / 0.515 / 0.554，逐格相加误差 0.000。
- **它们现在一条出边都没有。** 所以这四道题只证明「这一格在、黑的时候它真的亮」，
  **不证明它意识到灯灭了**：黑画面到不了反射层。论文 R19 和方法 5.15 记的就是这件事。

## 四、「拧指令」这件事已经删掉

之前有几道题是这么问的：同一个种子、同一条路、同样十秒，把外部前进指令从 0.35 拧到 1.00，
看它会不会走快。实测（三种子）比值是 **1.00**：

| 指令 | 十秒平均速度 |
|---|---|
| `amble` 0.35 | 0.0788 / 0.0778 / 0.0788 米/秒 |
| `sprint` 1.00 | 0.0788 / 0.0778 / 0.0788 米/秒 |

也就是说这条线在考试尺寸下是死的，那些题当时实际测的是「它自己走不走」。既然线没接上、也不打算拧，
这一批就把用 `driven` 的题全部改成自主场景并改名，原来问「拧大指令会不会快」的题改问
「前面有亮东西时会不会比空房间快」。

## 五、「跑」这一级出生时为什么全是空的

- 四道跑题出生时全不过，而且**空房间那次连 0.15 米/秒的匀速门槛都不到**，所以挡在前面的其实是
  「匀速走」那一关，不是「跑」本身。训练之前这一级只是靶子，不是成绩。
- 「跑起来」在 47 个可动基因里有路（`gait_gain` 出厂 0.45、`rhythm_speed` 2.5 这类管步态力度和节律），
  属于「要练」，不属于「要改结构」。
- 相反，「相反神经元」那四道属于「要改结构」：出厂动物以前全黑画面下视觉层整排是 0.00，
  调参调不出这一半，只能给它加上。

## 六、整库现在长什么样

- **123 道题**，分成 **15 个方面**：看 19、摸与本体 18、听 16、地形 12、走路 12、学习 8、记忆 7、
  转弯 6、自救 6、跑 4、站立 4、注意 3、自我 3、走快 3、特征层 2。
- **7 级先修阶梯**：0 级站住/翻回来/盯着球 → 1 级走/自救/看的基础 → 2 级带道具走、听辨、摸辨 →
  3 级一直走、走成一条线、一边走一边做别的 → 4 级地形、走久、跑 → 5 级上坡下坡、走三十秒 →
  6 级从台子上下来。出厂动物现在最深到**第 5 级**：种子 0 学会 96 道，种子 1、2 各 91 道。
- 每道题都带三样东西：**问什么**、**读什么数**、**门槛多少**，还有一行「**这题不证明什么**」。
  用 `python tools/taskbank.py --explain` 可以把 123 道全打出来。

## 七、这 123 道题仍然测不了什么

- **「跑」这一级现在全是空的**（见第五节）。
- **相反神经元这四道只证明读数在，不证明它用上了**：那几格没有出边，黑画面到不了反射层。
- 第三批文档第五节列的四条一条没变：外部前进指令那条线是死的（现在改成不问它了）、
  冲过来的东西那条线是死的、眼睛上下没测、两眼一致性没测。
- **时间尺度最长只有一分钟**：一道题一次只跑几秒到两分钟，所以「还记得吗」这类题最多只问到几十秒。
  要证明按天算的记忆，得换一种考法（跨会话保存状态再考），那是另一件事，不在题库里。
