## 一、已经查清的事实

### 1. 「红球在哪个方位」的特征神经元已经存在，不用新造
- 眼睛看到的是**原始视网膜**：每只眼 36 行 x 48 列 x 3 色 = 5184 个 `photoreceptors` 细胞
  （`born_wired/embodied.py:288`），外加同样大的一层 `retinal_opponent`（`:302`）。
- `retinal_opponent[眼,行,列,色]` 是一个**颜色对立细胞**：本像元该色强、另两色弱就亮
  （接线在 `embodied.py:419-422`：本色 +2，另两色各 -1）。全脑红细胞 = 2 x 36 x 48 = 3456 个。
- 实测（`tools/measure_red_ball_features.py`，红球 0.9 米、半径 0.06 米、清空摆设）：
  - 球在哪些位置，哪些红细胞就亮；**换绿球时红通道总活动全是 0.00**（对照跑过），
    所以这层是"认红色"，不是"认亮点"。
  - 18 格粗细胞 `retina`（2 眼 x 左中右 x 红绿蓝）：球在左扇区 → 第 0 格亮，中间 → 第 1 格，
    右 → 第 2 格。这层先天接着 `aversive`（红色 = 危险，`reflex_controller.py:349-353`）。

### 2. 球亮的是**方块**，不是一列（用户提的对）
`tools/sweep_red_ball_features.py` 让球在视野里扫 403 个位置（左右 31 x 上下 13），
每个位置停 12 步读 6 步，逐像元读全部视觉层。实测：
- 球（半径 0.06 米，0.9 米远）在视网膜上亮的是 **5.6 列 x 6.2 行** 的一小块
  （单点 ASCII 图那次：第 20~27 行、第 30~37 列，51 个细胞超过半高）。
- 所以**不能按列汇总**：48 列里只有 5~8 列亮，按列平均会把球的大小信息抹掉。
- 亮块中心跟着球走：列中心 = -1.049 x 方位(度) + 29.94（约 1.05 列/度），
  行中心 = -1.016 x 高低(度) + 20.05（约 1.02 行/度）。**两端会被裁掉**（球的像出了画面，
  列被顶到 47，或直接 nan），所以线性只在中间约 +-15 度内成立；最大偏差 7.4 列。
- 402 个位置里 382 个能看到球 → 视野大约左右 +-24 度、上下 +-20 度。
- 球在正前方（方位 0、高低约 2.3 度）时，**左眼**亮块中心在（第 18.7 行、第 33.8 列）。

## 二、原定的做法（用户口述的，已确认）

1. **不是随便连线**：先用上面两步把"红球在哪儿"的特征神经元和它们的位置野量出来
   （已完成），再按测出来的位置野接线。
2. 接线规则：
   - 每根线从"细胞所在方位"来，不是从"列号"来（因为采样在中心密、边缘疏）。
   - 该方位往左为正的部分 → `eye_look_left`；往右的部分 → `eye_look_right`；上下同理
     → `eye_look_up/down`。权重用实测表逐格给。
   - **死区**：球离正前方 3 度以内的格子不接（球已在正中就不许再动）。
   - 归一化到一个总增益：球多红不改变转速，只有位置决定快慢。
   - 每一只眼各接一套，所以两只眼都会朝球转。眼肌互斥**现成**（`eye_look_left/right`
     在肌肉端是一正一负），不用另加抑制神经元。
3. 规则线接好后再撒一点随机连接，成批生成、按朝向误差挑最好。
4. 课程：固定红球 → 追移动红球 → 两眼会聚同一点 → 任何方位都不斜视。

## 五、不要忘的坑
- 读细胞要用 `brain.network.activity`；`brain.step()` 第二个返回值是**12 个关节的电信号**，
  不是全脑活动（踩过）。
- `retinal_opponent` 展平后是（眼, 行, 列, 色）四个维度，取红色通道要用"每 3 个取 1 个"，
  不能直接切前 1728 个（踩过，会拿到眼 0 的前 12 行）。
- 跑测量时把 `--colour` 之外的场地摆设挪开，否则地板纹理的红绿会污染读数。
