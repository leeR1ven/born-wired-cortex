## 一、这套东西长什么样

三道命令：

```
python tools/taskbank.py --list                  # 47 道题一行一道
python tools/taskbank.py --tree                  # 先修阶梯：哪道题要先过哪道
python tools/taskbank.py --explain               # 每道题：问什么、量什么、门槛多少、出厂读数
python tools/taskbank.py --stage full --seeds 0 1 2 --output artifacts/exam_birth_full.json
python tools/taskbank.py --unlocked walk_flat,eyes_follow_ball    # 这几道过了，接下来能考什么
```

- **一道题 = 建一个场景 → 读几个数 → 和一个写死的门槛比一比。**
- 题目**从不决定动作**。它只看身体最后到了哪、全程有没有倒、哪个细胞群亮了多亮。
- 两个候选之间**只有出生连接不同**：47 个具名先天增益 + 抽支架的种子。结构、尺寸、
  传感器、学习规则一个字都不动。
- 参考尺寸固定为 `motor 200 / proprio 64 / association 256 / eye 48x36`，
  这是考试自己的尺寸，跟实时窗口那套（192x144 / 1600-512-2048）无关。

## 三、为什么是"过 / 不过"，不是 0~1 分

第一批的想法是每题给个分数，方便排序。写着写着发现有两个坑：

1. **有些题的正解是"没反应"。** "摆着不动的东西不该让眼睛乱转""身上被碰和脚上被绊
   不是一回事"——这种题给分给不出方向，只能给一条线，超过就是错。
2. **分数一多了就开始骗人。** 位移 0.23 m 和 0.24 m 差 0.01 分，看着能排序，其实两边
   都是同一次随机。分数会让人以为那点差别有意义。

所以每题只给**过 / 不过 + 一句为什么**。要比较候选的时候，比的是「过了哪几道」这个
集合，不是 47 个小数。`tools/screen_candidates.py` 已经按这个改了：它挑的是
**能覆盖最多道题的组合**（贪心覆盖），不是"总分最高"的那一个。

## 四、门槛是从哪来的

每条门槛都有出处，写在 `taskbank.BAR` 里，两种来源：

- **仓库里本来就有的判据**，直接引：`validate_reflex_v3.behavior_pass`（全程不倒）、
  `probe_righting` 的 `recovered`（站住 0.5 秒）。
- **2026-09-28 先量出厂动物，再留余量定门槛**。出厂动物自己那次读数一条条写进
  `taskbank.BIRTH`，`--explain` 会把门槛和出厂读数并排打出来，门槛的来历一直是可见的。

**出厂动物考不过的题是故意留着的。** 题库要比这只动物宽。每道题都有一句
"这题不证明什么"，写清一道读数说明不了什么、以及哪里是它自己没接上的线
（比如眼球那套距离细胞现在读数是 0.12→0.10，墙上的接触细胞压根没亮）。

## 五、先修阶梯（用户提的"先会站，再会走，再会跑"）

每道题可以写 `requires`：它前面那些题的名单。这样：

- 站都不会的候选不会被拉去跑地形；
- 一次考试报的不是"过了 31 道"，而是**"最高到第 2 级"**加**"接下来能考哪几道"**；
- `--unlocked a,b,c` 直接打印"这几道过了以后，新开出来的是哪几道"。

现在的阶梯是 4 级：

- **第 0 级**（不用先过任何题）：站着、四种姿势自救、被推、追球、听左右、受惊、教会反射、配对记忆。
- **第 1 级**：走路那一档、地形里不存在的地形题的前置、眼/耳/触的进阶、对照臂。
- **第 2 级**：满场走、走得久、台阶/斜坡/窄道/墙、进阶自救、身上与脚上。
- **第 3 级**：矮坎、矮台（要先用第 2 级的地形题）。

## 六、怎么加新题

加一道题只要三步，写在 `tools/taskbank.py` 里：

1. 写一个 `measure(ctx)`：它接收 `ctx`（种子 + 参数 + 场地路径），返回一个 dict。
   现成的地基够用：
   - `cell_read(...)`：把动物按在一个固定处境里，喂进接触 / 声音 / 画面，读指定细胞群。
   - `contrast_read(...)`：两个处境各读一遍，给差值，也给"逐格分开多少"。
   - `walk_measure(...)`：真走一遍，给位移、最低直立程度、最快滑移、各细胞群的峰值。
   - `righting_measure(...)`：从某个姿势翻身。
2. 写一个 `bar(measures)`：返回 `(True/False, 一句为什么)`。**失败时一定要说不**，
   `tests/test_taskbank.py` 会对每道题都喂一个坏结果，任何一条门槛放它过去都会红。
3. 在 `task(...)` 里登记，并在 `TASK_DOC` 里补上"量什么 / 门槛是什么"。

每题必须短（现在平均 3 秒墙钟），因为"每个候选都考全套题"这件事只有短了才做得起。

## 七、这 47 道题测不了什么

- 它测不了"懂"和"意识"。第 10 组叫"自我"，但它测的是两件很窄的事：被推和自己走
  在同一个细胞上分不分得开、身上和脚上的两条线有没有接反。这离自我意识很远，
  拿它当证据是不诚实的。
- 它测不了多步推理、工具使用、语言。题库里没有这类题。
- 环境只有这一个场地、一种身体、两档尺寸。换个身体、换套传感器，门槛全部要重定。
- 出厂动物过不了的 6 道（见 `--explain`）现在不改门槛迁就它：它们是给候选爬的。
