# 红球注视：手动接线、抖动与对照（2026-09-30 下午）

用户 2026-09-30 的定调：「**这些神经元还有连线都是透明的，哪个神经元该连哪个神经元都是确定的，
或者你直接手动连也行。不训练。**」所以这一轮不生成候选、不随机、不训练，每一根线都由实测的
位置野表算出来。

## 一、接线规则（`tools/wire_red_gaze.py`）

1. 起点是 `retinal_opponent` 的**红色通道**细胞（下标 `i % 3 == 0`），取被球亮过的（`peak > .15`）。
2. 每个细胞对自己**看到的方位**和**看到的高低**各出一根线，两轴独立；一个细胞出多大力
   = 该档「每弧度增益」x 它自己看到的角度，所以中央轻、越偏越重。
3. 方向：方位正则接 `eye_red_*_left`，负接 `right`；高低正则接 `up`，负接 `down`。
   `+yaw = 往左看`、`+pitch = 往下看`，由 `tools/probe_eye_axis.py` 把眼球转到 +0.30 弧度量出来。
4. **两档力度**：近处（3 度到 0.10 弧度）的细胞推得轻（保持档），远处的推得重（移动档）。
5. 3 度以内的细胞不接（死区）。
6. 别的看东西的通路（对比度、明暗变化、声音、记忆、会聚）全部掐到 `1e-9`（不能给 0，构造要求正数）。
7. 一根指令细胞同时推到两只眼的同一关节（`push(joint, ...)`，对 0/2 或 1/3）。

## 二、两个真正的错，都是自己找出来、改根因

### 1. 归一化的分母用错了：球亮的是「一团」，不是「一竖列」

每档的接线粗细 = 增益 /「球摆在该档最远处时点亮的那片细胞的 |角度| 之和」。原来那片细胞
只按**方位**卡，结果把**所有高度**的细胞都算进了分母。实测后果（`tools/probe_red_drive.py`，
日志 `logs/红驱动探针.log`）：球在远处时指令细胞只放电 **0.041 ~ 0.138**，设计意图是 0.5 ~ 1
—— 分母大了约 8 倍，眼睛只能动一点点。

改成按两个方向一起卡（方位 ±3.3 度 **且** 高低 ±3.0 度），即球在视网膜上真正亮的那一团。
同一个探针放电变成 **0.17 ~ 0.40**（`logs/红驱动探针2.log`）。

### 2. 抖动不是参数没调好，是「比例反射」这条路的两难

- 比例反射的稳态：眼睛停在「推力刚好顶住静息电流」的地方，所以
  **偏离 = 球的角度 / (1 + 环路增益)**。增益低了永远偏（下垂），增益高了在目标两侧来回撞。
- 两头都实测到了：增益 1.0 抖动 **0.002**、中位偏离 **0.150**（`logs/眼睛_接线_归一.log`）；
  增益 3.5 中位偏离 **0.043**、抖动 **0.503**（`logs/眼扫5_0.01_3.5_1.00_0.40.log`）。
- 单档比例反射要求增益 < 2 才稳，而偏离压到 0.10 以内要增益 > 2.5，够不着。
- 试过「自激勾住」（两个细胞互相激，用户说的循环激活）：`logs/眼勾_A_0.9.log` 8/25、
  `logs/眼勾_B_0.98.log` 15/25 —— 抖动降了但偏离更大，因为指令细胞放电一饱和（速率上限 1）
  就变成「要么顶死要么不推」。**机制留着（`--latch`/`--cross`），但要配很小的输入增益才行。**
- 走通的是**把眼肌本身放慢**（`--motor-time`）：慢肌肉跟不上快振荡，眼睛就不抖，同时允许把
  增益留在能压住偏离的位置。注意这是**肌肉自己的时间常数**，模型里默认 0.015 秒，
  这一轮用 0.15~0.20 秒，属于把眼肌调慢，不是接线上的补丁。

## 三、位置野表：原来没量到那么高

测试里球的高低 ±0.28 换算成相对头的真实高低是 **±0.37 弧度**，而旧的位置野表只量了 ±0.36，
球在高处时它的像上半团落在没量过的细胞上，驱动变弱 —— 高处的球就偏得多。

- 重量了一张更大的：`tools/sweep_red_ball_features.py --bearings=-0.50,0.50,36 --elevations=-0.50,0.50,26`
  （936 个位置，日志 `logs/红球位置野_红_大.log`），产物 `artifacts/红球位置野_红_大.json`。
- 新旧表各跑一遍，同一套增益下最差误差从 **0.174 降到 0.088**。

## 四、最终读数

- **绿球对照只有 2/25**，而且那 2 个正好是球摆在正中央、眼睛本来就不用动的位置 —— 说明这条
  通路确实只认红色，不是认亮块。
- **不分两档也是 25/25**（中位稍差一点、抖动更小）：这套参数下两档没有明显好处。要做成
  「小力度保持 / 大力度移动」，实际起作用的是「近处细胞权重轻」这件事本身，不是两个细胞。
- 剩下的误差结构：**高低方向整体偏 +0.03 ~ +0.056（眼睛比该看的位置略低）**，越靠近正中相对
  越明显，这是 3 度死区加比例下垂的结果；左右方向的误差已经都在 0.088 以内。
- 抖动从 0.503 降到 0.056（约 3 度），肉眼上已经不是「抖」而是很轻微的颤。
- `python -m unittest tests.test_eye_muscles tests.test_embodied`：20 个单测全过
  （`logs/单测_眼睛.log`），正常模型（`red=None`）一个字节都没动。

## 五、还没做 / 下一步

1. 高低方向那个 +0.04 的系统偏置：可用更小的死区（1.5 度）或给上下两档单独定标去掉。
2. 两眼会聚（现在两眼静止时不指同一点，差约 20 度）属于第三关。
3. 对照实验还可以补：把 `eye_motor` 的时间常数改回去（证明慢眼肌是必要的）、
   关掉红通路（证明没别的通路在帮忙）。
