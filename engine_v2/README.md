# Born Wired Cortex — 原始感觉与局部学习

当前是 MuJoCo Go2 神经闭环研究模型。旧目录 `F:\born-wired-cortex` 没有改写，当前代码在 `F:\born-wired-cortex-v2`。已按用户最新要求停止 DeepSeek 分工，后续由 Codex A 实现和验证。

## 打开模型

双击桌面的 **神经机器狗 - MuJoCo**，或运行本目录的 `运行模型.ps1`。窗口持续运行，直到用户关闭；再次启动时已有窗口会继续使用。依赖本机 Python 3.13、NumPy、MuJoCo 3.13，以及 `C:\mujoco_models\unitree_go2` 的模型资产。

窗口底部是左右眼实际收到的原始 RGB。左上显示探索、疲劳、休息、趋近/回避、节律募集与双目神经活动。默认外部前进输入为零。场地有球、箱、柱、发声物体、低台阶、斜坡、平台、围墙和通道。

| 键 | 操作 |
|---|---|
| E | 开关探索许可输入；感觉反射仍然存在 |
| W/S | 手动增加/减少实验性节律输入 |
| F/V | 手动增加/减少屈曲输入 |
| J / T | 短惊跳刺激 / 短侧向扰动 |
| P | 暂停/继续物理仿真 |
| H | 开发时重建神经网络，计数公开显示 |
| R | 显式重置身体，供实验初始化 |
| 空格 | 清除手动输入，内源活动仍可产生行为 |

开发重载会按 `born_wired/runtime.py` 重载全部运行时模块并初始化新脑，不等于学习连续保持；改身体或物理（`go2_body.py`）需要重启窗口。当前关闭进程后尚不保存学习状态。

## 神经回路

主图规模由眼睛分辨率和各区单元数一起决定：实时窗口跑的是每只眼 160×120、运动/本体/联想 800/256/1024 时 **40.8 万神经元、118 万连接**（参考尺寸仍是 48×36，单元测试与指纹按参考尺寸回归）。每关节 800 个共享运动单元、本体感觉 256 个单元；支持、屈曲、平衡、撤回、节律、转向和四块眼肌共同使用这些运动单元。

双眼只提供两幅原始 RGB（当前 160×120，尺寸和中心采样密度都属于这一只动物），不做图像匹配、物体识别、距离计算或方向解码。光感受器、色对手、局部对比及固定双眼连接都在神经图中；不同信号激活不同隐藏细胞。不把它们先变成“几米远”再驱动身体。

双耳只提供原始声压波形。仿真声场负责传播声音；脑内固定轴突延迟、兴奋/抑制、阈值和适应形成频带与左右偏好。在线通路不调用 FFT、相位定位、相关搜索或声源坐标。目前声音是简化的仿真输入，电脑扬声器不会播放。

感觉连接到共享的趋近、回避、探索、疲劳、休息、触碰退让、足端撤回、冲击适应、平衡和节律回路。颜色/音调偏好是人工设置的先天连接，不是已经识别出食物或危险物种。没有外部动作状态机、固定动作轮播、预训练策略或轨迹播放。

## 学习与稳定性

神经活动按 100Hz 模拟时间更新；突触更新每 50ms 使用实际累计时间，仍是局部在线规则。听觉按声波采样步更新。结构连接有非零塑性与回拉，关联记忆边有更宽的可塑范围；单边上下界及分目标兴奋/抑制预算限制参数漂移。

视觉记忆保留局部隐藏信号。原始蓝色图案与身体接触配对后，图案单独出现能引起新的回避相关神经响应；错时和禁学对照未出现相同响应。数据见 `artifacts/retinal_learning_current.json`。

模型也可以被"教会"它出生时不会的事。`backup_routes` 先在两个脑区之间铺一层权重 1e-4 的空连接（下限 0、有上限、无回拉，出生时不传导）；`touch_dopamine_gain` 把被摸到和 `dopamine` 细胞接起来；`dopamine_gain` 决定那一刻按多少比例写入。三个开关出厂都是 0，模型行为与改动前逐位相同（`tests/test_nursery.py` 用整片活动数组核对）。实测 20 秒课程教会"262 Hz 声音 → 后退"：通路权重 0.0001 → 0.95，撤掉老师后声音单独就能驱动后退细胞（0.000 → 1.000），静音时只有 0.020；从不被摸的对照组权重掉回 0、学不到任何东西，没铺空连接的对照组同样的课也什么都不会出现。做法、四个对照臂与限制见 [怎么把模型训练出来](docs/如何训练模型_20260927.md)，日志 `artifacts/nursery_20s.log`、`artifacts/nursery_20s.json`、`artifacts/nursery_noroute.log`。

这些机制约束数值。可靠运动、记忆质量、环境泛化与永不故障是不同问题，不能相互替代。

## 规模与时延

图像尺寸和中心采样密度是每一只动物自己的参数（`EmbodiedController(..., eye_width=, eye_height=)`、`RawEyes(centre_gain=)`），视网膜与各区的单元数一起构成规模旋钮。同一套出生连线在不同分辨率下走出来的动作是一样的：160×120 与 90×120 在同一个种子下前进距离、最低高度、最小直立轴完全一致（`tools/probe_resolution_behaviour.py`）。原因不是巧合——一个扇区的三张汇总细胞在所有尺寸下收到的总权重相同，见 `tests/test_cortex_scale.py`。

视网膜采样密度从中心向外递减：`count` 个细胞先把视野等分，再把分界朝中间拉，中间一度上有 `centre_gain`（默认 2.5）倍的细胞。每个细胞报告自己那一片的均值，片宽就是它到相邻细胞的间距，切片正好铺满整幅画——没有插值，没有像素被搬动，所以中心更清楚、边缘更粗，而画面不变形。这取代了早先"按 `|t|**2` 变形后取单点像素"的做法，那种做法会让中心无界放大，把远处的球拉成一条横条。对照图 `artifacts/retina_modes.png`，两份采样的实测差距见 `artifacts/bank_honest_vs_warped.log` 与 `docs/视网膜采样与全区放大_20260927.md`。

| 每只眼 | 运动/本体/联想 | 细胞 | 连接 | 大脑一步 | 加物理与眼睛渲染 | 墙钟 |
|---|---|---|---|---|---|---|
| 48×36（参考） | 200/64/256 | 49,042 | 190,532 | 8.4 ms | 14.1 ms | 71 Hz |
| 120×90 | 200/64/256 | 236,098 | 563,298 | 23.2 ms | 32.6 ms | 31 Hz |
| 120×90 | 800/256/1024 | 246,370 | 802,194 | 27.2 ms | 45.4 ms | 22 Hz |
| 160×120（实时窗口） | 800/256/1024 | 410,770 | 1,110,088 | 44.6 ms | 68.7 ms | 15 Hz |
| 160×120 | 1600/512/2048 | 424,466 | 1,428,616 | 49.7 ms | 74.2 ms | 13 Hz |
| 192×144 | 1600/512/2048 | 587,090 | 1,726,770 | 66.4 ms | 98.6 ms | 10 Hz |
| 240×180 | 1600/512/2048 | 882,866 | 2,260,402 | 90.3 ms | 135.3 ms | 7 Hz |

把模型做大 4.8 倍，每步耗时基本没变。做到这一点靠三件事，都不是近似：突触学习按 README 里本来就写的 50 ms 节拍走（`LEARNING_INTERVAL`），每步不再重复测量可以一次算完的量，以及一步里的数组运算改成原地写入。每一项都用 `tools/check_model_fingerprint.py` 逐位核对过（改前后权重与活动摘要完全一致）。

### GPU 执行引擎

上表是 host（NumPy）引擎。神经部分现在也可以在显卡上算，公式不变，行为不变：

| 每只眼 | 运动/本体/联想 | 细胞 | 连接 | host 大脑一步 | device 大脑一步 | 倍数 | 显存峰值 |
|---|---|---|---|---|---|---|---|
| 48×36（参考） | 200/64/256 | 49,042 | 190,532 | 8.3 ms | 6.8 ms | 1.2× | 72 MiB |
| 120×90 | 800/256/1024 | 246,370 | 802,194 | 27.4 ms | 12.1 ms | 2.3× | 310 MiB |
| 160×120（实时窗口） | 800/256/1024 | 410,770 | 1,110,088 | 40.6 ms | 14.1 ms | 2.9× | 406 MiB |
| 240×180 | 1600/512/2048 | 882,866 | 2,260,402 | 88.9 ms | 25.9 ms | 3.4× | 844 MiB |

模型越大差距越大：设备上真正贵的东西已经不是连接，而是每步在 host 和显卡之间搬的那几个整片数组。开关是环境变量 `BORN_WIRED_DEVICE`（`auto` / `cpu`），没有显卡就自动退回 host。`tools/compare_engines.py` 会同时报告"每个引擎自己重跑是否逐位一致"和"两个引擎之间差多少"；`tools/probe_engine_speed.py` 给上表。做法、实测与限制见 [GPU 执行引擎](docs/GPU执行引擎_20260927.md)。

## 考试台（题库）

`tools/taskbank.py` 是这套模型的能力清单：**123 道题、15 个方面、7 级先修阶梯**。每道题都是一次真跑出来的行为读数，没有人写好的动作脚本。

- `python tools/taskbank.py --list` 列全部题目；`--tree` 打先修阶梯（0 级站住 → 走 → 走快 → 跑 → 转弯 → 地形 → 一边走一边做别的）；`--explain` 逐题印出「读什么数 / 门槛多少 / 出厂读数 / 这题不证明什么」。
- 跑一整遍：`python tools/taskbank.py --stage full --seeds 0 1 2 --output artifacts/exam_birth_full.json`。出厂读数已经存在这个文件里，`python tools/taskbank.py --birth-text` 可以把它们印成源码里的 `BIRTH` 字典。
- 门槛（`BAR`）只有两个来源：沿用仓库原有判据（`validate_reflex_v3.behavior_pass`、`probe_righting.recovered`），或者按出厂实测数字定，而那个数字必须写进 `BIRTH`。`tests/test_taskbank.py` 会拦住「对坏结果也说好」的门槛。
- 每个感觉通道都是**一对细胞**：进来的那一格，和它旁边那一格（`1 − 进来的那一格`，所以没有信号时它亮着）。安静、黑屏、没人碰的时候读数不是 0，而是相反那格满亮；四只脚的受力格加上相反格，逐格恒等于 1。四道题在看这件事（`the_dark_room_is_not_silence`、`a_quiet_room_is_not_a_sound`、`nothing_touching_it_is_not_nothing`、`the_weight_pair_still_carries_the_weight`），论文里是结果 R19 和方法 5.15。
- 题目清单和判据写在 `docs/题库_第三批_20260928.md`、`docs/题库_第四批_20260928.md`，两份文档都写了这 123 道题**测不了什么**。
- 挑模型：`tools/screen_candidates.py` 只允许题目里点名的那几十个增益变化，代际之间按「谁cover的题目多」留人，融合就是把两个基因组取平均。
## 验证与限制

进展与失败见 [当前状态](docs/当前状态.md)。旧版的一小时测试只属于 `releases/v0_2`，不能当作当前视觉/听觉模型的长测证明。扩大模型和调参过程中保留了摔倒、滑动、无法通过地形等结果。

目前不具备完整动物智能、任意物体识别、可靠翻身、自主通过任意地形、开放世界长期记忆等能力。双目细胞对错位有选择性，不等于准确、通用的空间理解。强音、重复纹理和感觉冲突仍可能产生错误反应。
