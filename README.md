# Born wired —— 天生的皮层连接 + 局部可塑性，就够了

> **网页版（想快速了解就看这个）**：https://leer1ven.github.io/born-wired-cortex/  
> 一页读完摘要、关键数字和“什么没声明”；往下是机器人自己站起来、自己走向红块的四幕动画。  
> 本地看：双击 `index.html`（首页）或 `playback/index.html`（四幕动画）。

**一句话**：148,032 个皮层神经元、309,148 根**出生时就写好的兴奋连接**、只有一条局部规则
（上一拍亮的细胞 → 这一拍亮的细胞，连接强一点）。没有奖励函数、没有反向传播、没有目标函数、
没有"输入 token / 输出 token"。结果是：身体自己从趴着站起来、看见红块自己走过去、
眼睛自己盯住移动的小球。

本仓库是论文 **《Born wired: innate cortical connectivity plus local plasticity is enough
to stand, walk and look》** 的代码、日志、图和数据。

## 2026-09-27 新增：怎么教，以及能做到多大

两件事原来答不上来，现在都有实测。

**一、新能力写在哪里。** 两块脑区之间可以先铺一层**出生就有、但权重小到不传导的空连接**
（权重 0.0001、下限 0、上限 1.5、不往出生权重回拉）。然后一边放一个 262 Hz 的声音，
一边用手按住身体一秒、松开一秒，共二十秒。出厂时声音对后退细胞毫无影响（0.000）；
二十秒之后，撤掉手、只放声音，后退细胞 **1.000**、真正驱动大腿的腿驱动细胞 **0.504**。

四个对照臂，同一个种子、同一节课（日志 `engine_v2/artifacts/nursery_20s.log`、`nursery_noroute.log`）：

| 对照臂 | 课上 | 那条连接课后权重 | 只放声音时的后退细胞 |
|---|---|---|---|
| **taught** | 一边放声音一边摸 | 0.0001 → **0.95 / 0.99** | **1.000** |
| *ignored* | 同样放声音，从不摸 | 0.0001 → **0.000** | 0.000 |
| *ungated* | 摸，但多巴胺门关掉 | 0.0001 → 1.45 / 1.50（上限） | 1.000 |
| *no route* | 摸，但没铺空连接 | 连接不存在 | 0.057，下一段就归零 |

一句话：**赫布规则只知道&#8220;这两个细胞一起亮过&#8221;，不知道&#8220;对不对&#8221;** ——
所以没发生过就学不到，没地方写就写不下。多巴胺不是裁判，它只说&#8220;这一刻算数&#8221;。

**二、能做多大。** 架构本身不涉及细胞数量。重建后的引擎 **58 万 4 千细胞 / 181 万连接**，
眼睛、大脑、物理整套一步 **11.2 毫秒（每秒 89 步）**，一块消费级显卡；
原来的 14.8 万细胞版本闭环一步要 158 毫秒。限制做大的是两条自己定的构建规则
（某区的输入兴奋预算、以及 arena 文件里决定眼睛能画多宽的那个数字），不是显卡。
诚实报告一条读数为零的路线：&#8220;有东西冲我来&#8221;那个细胞在**所有场景里都是 0.000**，
包括以 3 m/s 冲过来的球。

细节在论文的 R12、R13 和方法 5.12；命令、日志、测试（160 项）都在 `engine_v2/`。

## 怎么自己验一遍

论文里的每一个数字，背后都有一个脚本 + 一份日志。脚本可以重跑，日志可以当场对照。

```powershell
cd model
$py = "C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe"   # 换成你自己的 python
& $py -X utf8 核对_论文数字.py        # 几秒钟：程序自己去翻 logs/，把数字抠出来和论文比，应打印"对上 52 条，对不上 0 条"
& $py -X utf8 核对_论文数字.py 重跑    # 约 6 分钟：当场重跑 R1，看真跑出来的数是不是论文里那个
& $py -X utf8 看_大脑开车.py          # 让模型自己开一遍机器人，生成 playback/ 里的四幕回放页
```

论文 5.8 节列了**每个结果对应哪个脚本**（R1–R11，一共四十多个）；论文里每个数字后面
也写着"跑哪个脚本、看哪份日志"。`docs/复现说明.md` 是一张完整的对照表。

**环境**：核心只需要 Python 3 + NumPy；身体用 MuJoCo（Go2 模型缺了会自动从
MuJoCo Menagerie 下载）；画图用 matplotlib + Pillow；只有第三方对照实验
（`对照_RL_训练.py`、`对照_现成RL_驱动.py`）需要 PyTorch 和一个外部 checkpoint。
全部跑在 CPU 上。

**两个开关**（环境变量，不改代码）：`前额叶不保留=1` 关掉前额叶回响（R1–R8 用这档，
论文 Methods 5.5）；`AGI列数`、`AGI数据后缀` 换皮层大小（R11 用）。

## 诚实声明：哪里还会摔

### 已修好：出生就会的那一走（2026-09-18）

以前走到第 66 拍（1.3 秒）就摔。原因不是学习（开/关学习逐拍数字一模一样），
也不是走路链乱了（始终只有 1 个时刻亮），而是**前额叶失控**：它靠自己的环越亮越多（2608 → 2818、还在涨），
于是不只亮“正前方红”，**连“左边红”那一撮也点着了** —— 本能表里正好有“看着左红 → 左转1.5”，
于是每一拍同时去点**两个**动作，两串肌肉力叠在一起，身体从第一拍开始歪。
（已排除：不是返回线——只掉“返回线→运动区”那一段，逐拍一模一样；也不是压得太狠，
前额叶只剩 1 个细胞时走得一样好。）把前额叶压回稀疏（动态整体抑制，现已改为默认开）后，
同一颗脑走 **600 拍、6.62 米、一次没歪过 75 度**。完整证据和对照表：
docs/修复_摔倒_20260918.md。

同一天还把**前额叶的通道和返回线补成了“完整架构”**（见
docs/修复_前额叶七路与返回线_20260918.md）：前额叶的输入从 视觉+听觉+运动 三路
补成**七个区**（多出本体感觉、平衡感觉、机身状态、运动记忆）；天生互惠返回线跟着按同一张表
原路切开，并且——**感觉区不设返回线**：身体读数只能由身体自己报，想象出来的“歪”不该真的去救
（不这么办的话，返回线往身体那三区各塞十几二十个细胞，就把“站起来”“站姿”误点着了，第 126 拍摔倒）。
补完之后那几条结论仍然成立：前额叶按灭 → 走路动作 **0/200 拍**；全黑不给画面 → **0/200 拍**；
站着看红 5 秒 → 走 2.82 米、一次没翻，运动记忆区全程只亮 1 个时刻。

### 还没修好：“教它听见声音就走”那一段（论文 R9）

教学时“红 → 走”和天生的“响 → 原地踏步”两个动作同时被点着，运动记忆区同时亮 2~3 个时刻，
两串肌肉力叠在一起，第 107 拍摔。这是**另一个问题**：两个动作抢一个身体。
论文 4.6 节把它单列成一条缺口，没有藏；排查过程在 docs/论文进展说明_20260916.md。
已经排除的：不是权重在长（进运动区 265,436 根边，考试 200 拍里变化 **0 根**）；
不是返回线的错；也不是整体降权能修的（三档实测反而更早摔，论文 4.6 引了这个负结果）。
两条候选修法写在 docs/修复_摔倒_20260918.md 末尾。
