#
# 格式：   源  ->  目标    力度    固化(是/否)
#
#   「力度」= 当源这一整块亮起来的时候，每个目标细胞一共收到多少电流。
#            会自动平均分到每一根连接上（源块越大，每根越细，但合起来还是这个力度）。
#            所以：力度 2.0 = 整块亮起来就一定压过阈值 1.0，目标放电；
#                  只亮一小部分时，加起来不够，目标不动。
#   固化 = 是 表示这条一辈子基本不变（不写默认不固化）
#
# ★ 这份表是 生成本能表.py 照着 动作库.json 自动生成的，别手改（改了会被覆盖）。
#
# ★ 身体是宇树 Go2（真物理）。运动皮层里每块肌肉占 10 个神经元，亮几个就出多大力。
#   左边这一列「运动记忆:某某」= **运动记忆区里那个动作的头一拍**，相当于脑干里天生
#   就有的动作中枢：点亮它，就等于"想一下要做这个动作"。
#
#   · 姿势类：点亮就一直保持这个姿势。
#   · 多拍动作：只要"想一下"（点亮头一拍），这一串动作就会自己在皮层里
#     一拍接一拍地走下去（循环的一直转圈，不循环的放完就停）。
#     一共多少拍、每拍用哪些肌肉，见 动作库.json。
#
# ★ 走路类是从一个训练好的宇树模型身上抄下来的（见 取动作_从训练好的模型.py）：
#   把速度指令（前后 / 左右 / 转圈）铺成一整片网格，一个个走一遍抄下来，
#   所以这张表基本上就是"这个身体能做的全部走法"。
