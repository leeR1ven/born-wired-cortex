# 下载为什么失败，以及能用的路径

2026-09-13。上一轮扩语料失败，查清了原因。

## 诊断

这台机器有一个本地代理：`127.0.0.1:10808`（HTTP + SOCKS5），系统代理已开启。

| 测试 | 结果 |
| --- | --- |
| 不走代理直连 huggingface.co | 连接被重置（10053） |
| 走代理取 HF 小文件（README，130KB） | 通，0.06 MB/s |
| 走代理取 HF 小接口（/api/datasets，164KB） | 通，200 |
| 走代理取 HF 大文件（parquet） | 重定向到 `us.aws.cdn.hf.co` / `cas-bridge.xethub.hf.co`，**0.01 MB/s 或 0 字节** |
| hf-mirror.com 大文件 | 同样重定向到 `cas-bridge.xethub.hf.co`，0 字节 |

结论：**不是代理坏了，是 HuggingFace 现在把大文件放在 Xet CDN 上，那个域名过不去。**
huggingface.co 本体、API、小文件都正常。所以以前的下载脚本能用，现在不能用。

## 能用的路径：ModelScope

实测 `https://www.modelscope.cn/api/v1/datasets/.../repo?Revision=master&FilePath=...`

**0.6 MB/s**，是 HF 大文件的 60 倍，而且不用改代码，只是换 URL。

## 拿得到的非合成中文文本

| 数据集 | 文件 | 大小 |
| --- | --- | --- |
| `caoaolong/zhwiki` | zhwiki_dataset.jsonl | 2,462 MB |
| `Illusionna/wiki-zh-521MB` | local_train.txt | 1,003 MB |
| `AI-ModelScope/wikipedia-cn-20230720-filtered` | *.jsonl | 521 MB |

合计约 4 GB 原始文本，清洗后估计 **6–8 亿字**。

注意：`opencsg/chinese-cosmopedia` 有 70 GB，但它是**大模型生成的合成文本**，
本项目的语料协议明确排除合成文本，所以不能用。

即使把上面三个全用上（去重后与现有 3.448 亿字有重叠），总量也就 **8–10 亿字**，
是现在的 2–3 倍，到不了 30 亿。要到 30 亿字需要约 10 GB 非合成中文文本，
国内源里目前没找到。
