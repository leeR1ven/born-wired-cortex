# 文字直接建立赫布连接：学习量实验

本目录按用户最新要求简化：一个 Unicode 字符对应一个单元，单元间只有可检查的有向连接。没有调用 PetBrain、Transformer、语言模型接口、语法分析器或答案表。旧宠物模型及旧实验文件不在本实验中修改。

这不是完整架构的替代实现，也不是 AGI 认证。它先回答：大量真实文本是否能改善这个简单机制对未见文本的预测，以及近期多字活动和同图反复传播能否增加有效的上下文利用。

## 实际学习规则

收到新字符 j 时，用之前字符单元的活动 a_i 更新 w_ij，然后衰减旧活动并把 j 的活动设为 1。重复出现同一字符会更新同一个单元；没有为词、句子、角色、问题或答案新建单元。

- adjacent_linear：只保留上一个字，增量为 a_i；对应最直接的有向共现学习。
- adjacent_diminishing：只保留上一个字，增量为 0.25 a_i / (1+w_ij)。
- context_diminishing：保留近期字符的衰减活动（每字乘 0.8，小于 0.02 不再参与），同上式学习。
- context_saturating：相同近期活动，增量为 0.25 a_i max(0,1-w_ij/4)。
- long_context_diminishing：把活动衰减改为每字乘0.98、低于0.01退出，使较早的字也参与关联；其他规则与context_diminishing相同。

训练不按段落清空活动或重置计时；文本分区拼接处的换行也是普通字符，可能学习到边界关联。每个对照模型是独立的完整学习过程。评估时在副本式状态干预中清空活动、输入测试前缀，不学习测试字符，随后精确恢复训练活动和时钟。

预测时累加活动单元通过实际连接产生的电流，归一化为评分分布。为使未出现连接的损失有限，混入 0.001 的均匀读出底值。贪心续写只选该分布的最大字符。另有同一连接图两次传播的对照，限制每次中间活动最多32个字符、与直接电流按0.25混合；这是一项明确的额外活动竞争规则，并非学到了新的推理模块。

## 执行

在仓库根目录运行：

```powershell
& '.\.venv\Scripts\python.exe' '语言规模实验_language_scaling_20260913/check_core.py'
& '.\.venv\Scripts\python.exe' '语言规模实验_language_scaling_20260913/run_experiment.py'
```

runner拒绝覆盖已有结果目录。复跑时添加 `--out` 指向新的绝对目录。默认最多训练400000字符；按1000、10000、100000及最终训练量记录学习曲线，每阶段抽样1024个验证位置和1024个测试位置。

查看最终模型接续及真实连接：

```powershell
& '.\.venv\Scripts\python.exe' '语言规模实验_language_scaling_20260913/query.py' '语言规模实验_language_scaling_20260913/results_v1/context_diminishing/model.npz' '今天的天气' --length 48
```

## 如何解释指标

- 原始语料来源、许可和分区见 `data_sources.md` 与 `data/manifest.json`。
- 字符身份词表只从本轮所用训练文本获得，所有阶段预先分配同一词表。早期阶段知道后续训练字符的身份，尚未学到其后续连接；不称为开放词表测试。
- 测试取非空白位置，不是每个字符。OOV计入准确率失败；NLL/BPC只对已知字符计算并同时报告OOV数量。
- 同分按固定词表顺序决定名次；出生输出不是随机采样基线。
- 单字频率基线只用于评分比较，不选择模型输出。
- 新段落预测改善不等于推理或对话能力。上下文干预、循环对照与全部续写都会保留，不能只挑看起来通顺的例子。
- 若上下文版本劣于相邻字版本，或生成陷入高频循环，应直接报告，不能把重复生成称作思考。
- `model.npz`包含全部字符连接、临时活动和连续时钟。加载不使用pickle；恢复后继续学习128字会与原对象逐项比较。

本轮首先采用CPU。单个矩阵内存为4×词表大小²字节；保存与恢复校验会暂时持有两个矩阵。未在本目录中使用或租用GPU。
