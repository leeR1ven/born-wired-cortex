## 7. 用户已确认的架构结论与禁忌（务必遵守）

### 7.1 论文要树立的核心概念（他的原话意思）
1. **大脑里一层一层的神经网络不是大模型的「左边进 token 右边出 token」**；多层网络的作用是**处理外界信号、把大量信号压缩成少量信号**。
2. **思考是靠大脑皮层的神经元相互激活实现的。**
3. **前额叶是「把其他多个区的信号再次压缩成更少的信号，然后用同样的方法思考」。**
4. **大脑一出生就有很多本能连接**；本能连接让模型一开始就有简单的、有逻辑的行为，才能慢慢发展出更复杂的行为。**用文字直接当神经元训练也间接印证了这一点**（激活某些字，能自己激活出更多文字组合）。
5. 不能通过「具体激活了哪个字」判断它想了什么，**只能确定大致的思考范围**；真正想了什么要看**激活声音区时脑内的声音**、**激活运动区时实际说出的话**等。
6. 用户对「文字网络只证明联想、没证明语义」的回应：**真实思考时不一定有具体文字或说话声音，只是一种模糊想法**；只有决定激活声音区（脑内真实出现声音）或控制肌肉把话说出来时，才有具体语义。

### 7.2 本能连接到底是什么（用户专门澄清过，之前被前几任 AI 搞错）
- 本能连接 = **大脑皮层的神经元连接**，或者说是**多层神经网络输出层神经元之间的互相连接**。
- **包括**：各感觉区/运动区皮层一开始就有的连接，**加上**前额叶皮层一开始就有的连接。范围很广。
- **包括抑制性本能连接，也包括去抑制连接。**
- **不包括**：用来处理外界信号的那些区的多层神经网络本身、前额叶的多层网络、天生互惠返回线——那些只是**传输和处理信号**的。
- 生物学来源：既有直系血缘长辈大脑连接的**模糊化**，也有长辈的**总体混合记忆**（两者不矛盾）。但对这个架构来说，**不需要继承机制，直接在模型上加神经连接就行**。
- 本能连接**也会慢慢变化**，像人一样：有的后天容易改，有的一辈子基本不变。
- **方向定义**：**运动区皮层属于「输入层」**（是往神经网络里输入信号）；**其他区（视觉/听觉等）是外界信号往内输入**。输入/输出要按信号流向算。各区之间**没有直接连接**就说明本能连接没建好。

### 7.3 天生互惠返回线
- **属于架构的一部分**：没有它，前额叶激活的信号传不回其他区，前额叶就「只进不出」。
- 用户用临床现象类比：**心盲症 / 心失语症 = 前额叶信号传不回视觉区/听觉区**。
- **但有些区不该有返回线**：感觉区不要——因为「想象到自己受伤也不该真的疼」。
- 用户纠正过的错误说法：**不能说「直接 前额叶→运动记忆」而绕过返回线**；前额叶要把信息发回各区只能通过返回线。同时**运动记忆/运动区必须往前额叶送信号**，否则前额叶不知道身体在干什么。

### 7.4 抑制用抑制神经元，不用负权重
- **不要使用负权重**——抑制神经元的功能本就等同于负权重，那为什么不直接用抑制神经元。
- 本能表里写负数 → 展开成抑制神经元连接（v2/老线都是这么实现的）。

### 7.5 一切皆神经元，不要代码自动化
- **D6 这类问题不要改成「渐进的代码逻辑」，一切由神经元决定，不要代码自动化。**
- 专注本质上是**神经网络自己达到平衡自动实现**的，不要手写一个门去抑制三条通路。
- 用户认可用「动态整体抑制」只是一种**调参调不到完美时的兜底**：「如果你能调参到完美可以不使用动态抑制」。

### 7.7 其他被确认的设计
- **前额叶不需要海马体索引**：前额叶本身靠赫布连接，本身就有时间顺序。
- **循环不一定是坏事**：它是模型**持续记住一件事的方法**，关键是模型**能不能想到其他事**。
- **多巴胺（用户设计）**：多巴胺区被激活 → **当前正在激活的皮层神经元之间、前额叶神经元之间的连接当场增强**；简化版可以直接手动激活多巴胺；仿生版加触觉区，**外部触摸 → 触觉区皮层 → 再由皮层激活多巴胺区**（**不许外部触觉直接点多巴胺区**）。
- **首尾接环（用户设计）**：任何一段神经元被激活后，在前额叶里把它的**开头和结尾自动接成环**，让它持续激活（像文字网络那样）。**只在前额叶做**，不影响记忆区按顺序激活。这是「声音→走路」这类需要持续激活的任务的前提。
- **视觉输入粒度**：输入层神经元可以代表任何信息，目前只有亮度是因为模型太小；要**用多对特征神经元表示一个基础颜色通道的亮度**（例如用 10 对代表大像素中最基础的 Red 亮度）。
- **眼动跟随移动物体（用户设计）**：变化可能小到皮层末层完全不变，所以要**看视觉区前几层**；把**时间上连续但很弱的信号，转换成某一刻的强信号**（第 1 帧激活 A、第 2 帧激活 B 且 A 又激活 a、第 3 帧 B+a 共同激活 e，e 再激活控制眼肌往右上的神经元 f）。帧数只是举例，**和模型最低帧数不是一个东西**。**皮层不需要知道细微变化**——眼睛先转过去，本身就已经告诉大脑有移动物体了。
- **站立/坐下互斥（必须两边都做）**：用户原话——「站着和坐下是相反的事情……前额叶站着相关的神经元应该会抑制住坐下相关的前额叶神经元，同时运动区的站着相关的神经元也应该抑制坐着相关的神经元，除非前额叶发出明确信息要坐下。」
- **「站着不倒」的根因判断**：不是互斥引起的，是**没有本能在命令"站住"**（站着什么都不给会瘫，约 0.19~0.26 m）。解法两条：① 让站立相关的神经元循环持续激活；② 有其他神经元持续激活站立相关的神经元。
- **强化学习姿势照抄**：用户同意「直接找网上训练好的、动作很完美的模型（如宇树机器人），把**所有可能的动作**解析出来，连同**在什么情况下会执行什么动作**一起烧录成本能」。动作要写进**运动记忆区**，**不是在前额叶划一片细胞当播放列表**（「究竟是哪些细胞代表哪些动作，是由神经网络输出时激活哪些神经元决定的，不是你想划哪里划哪里」）。
- **本体感觉区**：用户认可可以专门加区，但要注意「前额叶的输出要靠各个区充当输入，多加一个区，前额叶可能就要重写」，而且**本体感觉应该拆开**（他要求说清楚接收的究竟是什么信号）。
- **仿生激励**：给机器狗加「想要」的驱动力很简单——眼前有鲜艳的东西就会想站起来走过去；还有声音、感觉等很多种。
