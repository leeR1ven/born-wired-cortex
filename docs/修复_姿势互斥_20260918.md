# 姿势互斥：一个身体同一时刻只摆一种姿势（2026-09-18 定）

## 用户要的是什么（原话）

> "因为坐下的神经元排在站着的神经元后面，所以顺理成章的又激活了坐下。但是站着和坐下是相反
> 的事情，前额叶想要站着时，并且要持续站着时，前额叶站着相关的神经元应该会被持续激活，
> 同时站着相关的前额叶神经元应该会抑制住坐下相关的前额叶神经元，同时运动区的站着相关的
> 神经元也应该会抑制坐着相关的神经元，除非前额叶发出明确信息要坐下。"

## 结论（先说这个）

| 用户要的 | 能不能做 | 结果 |
|---|---|---|
| 运动区"站着"的神经元压住"坐着"的整套动作 | **能，已做** | 站着时"坐下"的入口被压 2.50，整套动作一次都开不了（0/240 拍） |
| 前额叶"想站着"压住前额叶"想坐下" | **做不了**（见下） | 标定出来的「在想站姿」和「在想坐」是同一批细胞（10 个里 10 个重合），站着不动时前额叶正好亮其中 7 个 —— 它俩不是两个意思 |
| 前额叶明确要坐下就坐得下 | **暂时没有通路** | 现在"坐下"没有任何本能通道（没有"坐下"的声音/触觉），需要用户定一条 |

**并且：两幕该有的行为一点没坏** —— 趴着自己站起来（0.261 米、歪 0°）、站着看见红自己走过去（5 秒 2.19 米）。

## 证据一：先把"什么坏了"找出来（2×2 对照）

*地址簿 = `皮层名字.json`（名字 → 哪几个细胞，由标定算出来）；表 = `本能表.txt`。*

| 组合 | 趴着自己起来（3 秒） | 站着眼前一片红（5 秒） |
|---|---|---|
| 旧地址 + 旧表 | 末高 0.261 米 歪 0° | 前进 **-0.23 米**（不走） |
| 旧地址 + 新表（37 行互斥） | 末高 0.209 米 歪 19° | 前进 -0.21 米 |
| **新地址 + 旧表** | 末高 **0.261** 米 歪 0° | 前进 **2.19 米** ✓ |
| 新地址 + 新表（37 行互斥） | 末高 0.209 米 歪 19° | 前进 **0.01 米** ✗ |

两条结论：
1. **地址簿必须用重算过的那一版**（前额叶七路之后的标定）。旧地址下走路是 -0.23 米，等于不动。
2. **别人加的那 37 行互斥把走路压没了**（2.19 米 → 0.01 米），还让起身从 0.261 掉到 0.209。

## 证据二：为什么那 37 行会压坏走路（纯算，不建网）

那 37 行里有一半是 `运动:站姿 → 运动:坐/蹲/趴姿/坐下/趴下去 -2.0`，拿「运动:站姿」当"我在站着"的信号。实测：

| 动作 | 整段用过的肌肉细胞 | 其中和「运动:站姿」重合 |
|---|---|---|
| 前进1.2（走路） | 84 个 | **60 个（100%）** |
| 原地踏步 | 72 个 | 60 个（100%） |
| 坐下 | 60 个 | 60 个（100%） |
| 趴下去 | 70 个 | 60 个（100%） |
| 站起来 | 70 个 | 60 个（100%） |
| 坐 / 蹲 / 趴姿 | 46 / 52 / 50 | 46 / 52 / 40（全在站姿这 60 个里面） |

「运动:站姿」那 60 个细胞 = "12 块肌肉每块低档力"，**几乎每一套动作都用它**。
它是"这几块肌肉在使劲"的意思，不是"我在站着"的意思。拿它当源去压别人 = 站着压自己。

## 证据三：定稿以后，压制是真的在压（逐拍看电流）

站着（自己从趴姿起来站住）之后：

```
2.02~2.18 秒（逐拍）：站姿时刻亮 1 个 | 互斥抑制神经元 #15 亮 | 坐下入口 抑制 2.50
```

- 「运动记忆:站姿」亮 → 抑制神经元 #15/#17 亮 → 「运动记忆:坐下」入口每拍被压 **2.50**（一直压，不是隔一拍）。
- 那 60 拍一套的"坐下"，入口都点不着 → 整段一次没跑过（0/240 拍）。

## 定稿怎么写的

**`本能表.txt` 二之二（2 行）**：

```
运动记忆:站姿                 ->  运动记忆:坐下                 -2.5   是
运动记忆:站姿                 ->  运动记忆:趴下去               -2.5   是
```

- **源**用「运动记忆:站姿」= 记住"我在站着"的那一段时刻（不是肌肉）。
- **目标**用「运动记忆:坐下」= 整套动作**开跑的入口**（一个细胞）。压肌肉没用：50 拍的动作
  只有第 0 拍用那几个肌肉细胞，后面 49 拍照样跑。
- 只写"站着 → 压住坐下/趴下去"这**一个方向**。反方向（趴着压住站起来）不写 ——
  趴着的时候正好要站起来，写了它一辈子起不来。

**`本能工具_instincts.py` 装() 两处小改**：

1. `多拍 = (权重 > 0 and ...)`：**写负数 = 压住，永远只写一条抑制，不展开成多拍**。
   不改这里的话，源写「运动记忆:站姿」（它本身是 2 拍的动作）会被当成"展开一整套动作"，
   那根 -2.5 会被当成兴奋连接写进去。
2. 压制规则里，源写「运动记忆:某动作」时取**那个动作的全部时刻**（不只起手）。
   站姿是 2 拍一循环，只取起手的话抑制神经元隔一拍才亮一次，入口隔一拍就有缝
   （实测：抑制在 2.50 / 0.00 之间跳）；改成全部时刻后逐拍都是 2.50。

## 走过哪些错路（别再走）

1. 拿「运动:站姿」当"我在站着" —— 它就是"低档力"，走路 100% 用它。压坏走路。
2. 靠标定做前额叶的「在想坐」 —— 和「在想站姿」是同一批细胞（10/10 重合），
   站着不动时前额叶亮 7 个，`+2.0` 那条规则一开局就把"坐下"点着了。
3. 用「机身状态:站得高」当源 —— 实测站着时它 0/3 个细胞都不亮，是死规则（已去掉）。
4. 用"从外面注入一个命令"去测互斥有没有效 —— 不干净：赫布学习会把那根临时边变成
   "一个卡住的时刻"（入口被压住，但有一个中间时刻一直亮）。要测就**直接看抑制神经元的电流**。

## 还没解决 / 要用户定的

1. **"除非前额叶发出明确信息要坐下"**：现在没有任何"坐下"的通道。三条路可选：
   (a) 加一条**声音**本能（听觉某个音 → 运动记忆:坐下，力度 3.5 > 被压的 2.5），听到就坐下；
   (b) 加一条**触觉**本能（摸某个部位 → 坐下）；
   (c) 只做"站着就坐不下"这一半，先不演示"除非"。
2. **前额叶那两条互斥做不了**，原因是**尺度**：前额叶分不出"想站"和"想坐"。
   放大之后（前额叶细胞更多、运动那一路分辨率更高）才有可能。
3. 站着**什么都不给**时，身体会瘫下去（约 0.19~0.26 米）。这不是互斥引起的：没有哪条本能
   在命令"站住"。自己从趴姿起来之后是站得住的（站姿维持 240/240 拍、末高 0.260 米、歪 0°）。
