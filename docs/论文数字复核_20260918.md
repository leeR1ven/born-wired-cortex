## 二、这一版改了什么（三处，都是设计决定）

1. **前额叶输入：三路 → 七路**（视觉/听觉/本体感觉/平衡感觉/机身状态/运动记忆/运动）。
2. **返回线按每一路自己的峰值取门限**（不再用整条回传向量的统一峰值）。
3. **身体那三个感觉区不设返回线**（本体感觉/平衡感觉/机身状态只进不出）。
4. **返回线送回运动记忆的那一路"只维持、不点火"**：回传的细胞必须是这一拍运动记忆
   真的在跑的那些细胞。**不是**把这一路砍掉 —— 前额叶往运动区发信息的通路必须留着。

理由与逐拍实测见 `docs/修复_前额叶七路与返回线_20260918.md` 第七节：
* 身体三路给了返回线 → 误点着"站起来/站姿" → 走路第 126 拍摔倒；
* 运动记忆那一路**粗着回**（不设限制）→ 第 51 拍拍回邻着的"趴下去"头一拍 →
  那套 60 拍动作跑起来 → 身体的力被"每块肌肉取最大值"改掉 → 从 0.265 米沉到 0.180 米；
  加了"只维持"以后 → **0.261 米，一点不歪**，走路 1.85 米不变。
* 试过"干脆砍掉运动记忆/运动这一路"，实测也能好，**但那是错的**（前额叶就发不出信息给
  运动区了），用户 2026-09-18 明确否掉。
