# 复现说明 —— 论文里每个数字，怎么自己验一遍

这份文件回答一个问题：**"我自始至终都是通过对话框和你（AI）对话，
根本不清楚实验是不是真的、能不能查。"**

一句话：**论文里的每一个数字，背后都有一个脚本 + 一份日志。脚本可以重跑，日志可以对照，
你也可以跳过我们，自己跑一遍看出同样的数。**

## 一、四层证据（从软到硬）

| 层 | 是什么 | 你要做什么 |
|---|---|---|
| ① 论文自带索引 | 论文里每个数字后面都写着"跑哪个脚本、看哪份日志" | 读论文时逐条对 |
| ② 自动核对 | `核对_论文数字.py`：程序自己去翻日志，把数字抠出来和论文比，52 条全过才算数 | 运行一下，看是不是 52/52 ✓ |
| ③ 真跑一遍 | `核对_论文数字.py 重跑`：当场重新跑一遍 R1，拿新算出来的数和论文对 | 约 6 分钟，看是不是一样 |
| ④ 你自己看 | `回放_大脑_A/B/C/D.html`（模型开机器人）、`论文预览.html`（论文全文） | 双击就能看，不用装任何东西 |

第 ④ 层最重要：**你不需要相信任何人的话，你自己眼睛看。**

## 四、怎么知道日志不是编出来的

1. **日志是程序自己往外写的，不是手打的。** 每次跑都用
   `-RedirectStandardOutput 日志_xxx.log` 直接接程序的标准输出，
   人在中间没有插手的机会。
2. **日志带时间戳和耗时。** 比如 `日志_渐变正式_新.log` 里每一趟都写了
   "共 1040 拍，296 秒"——这是程序自己计时打出来的。
3. **日志之间互相印证。** 同一件事在 R1、R3、R8 用了三套不同的脚本和不同的判据
   （末高 / 走多远 / 点火多少拍），三套都指向同一个结论。
4. **最硬的一条：你自己跑。** 第 ②③ 层就是干这个的——
   如果日志是编的，`核对_论文数字.py 重跑` 当场就会打脸。
5. **别人也能跑。** 整个仓库（脚本 + 日志 + 论文 + 图）可以打包发出去，
   任何人拿到都能重跑，不需要我们在场。

## 五、目前已知的、写在论文里的缺口（不是藏起来的）

这些在论文 4.6 里已经写明，属于"我们知道它还不完美"：

- 走久了会摔：4/5 个种子在 42~101 拍之间歪倒（论文 R9 考试段）。
  ★ 2026-09-17 查明：摔**不是**权重增长造成的（进运动区的权重 200 拍里一点没变，冻死它也没用），
  而是**本能表里“前额叶 → 走路链”那条规则的电流正好等于走路链的点火门槛（0.850 对 0.850）**。
  前额叶不接环时这股电流是“扳机”，只在刺激来的时候出现；一接环，它就变成一个**长期恒定的推力**，
  走路链不再自由跑，越走越歪，最后翻。同一个毛病在**教学段也发生**（五个种子分别在 78 / 154 / 174 / 154 / 175 拍翻）。
  试过把这条天生连接打 0.5、0.75 折：能修好 20260915 这一个种子，但另外 3 个彻底走不起来、1 个照摔 —— 所以**没采用**。
  正解是“扳机要能自己衰减”，那是规则的事，不是学习规则的事。
- 前额叶自压窗口偏窄，动态抑制还在当拐杖。
- 压缩层不会"定位"，只有"记得大概在哪一片"。
- 速度还没压进一拍之内。
- 从**站姿冷启动**（把它直接摆成站着、什么都不给）它撑不住：前 0.6 秒运动区基本不亮、
  肌肉不出力，等平衡反射反应过来已经晚了。让它自己从趴着站起来就完全没问题
  （站定之后 6 秒末高 0.260 米、一步没走）。我们试了两种补法 —— 用机身高度那群细胞去点
  "运动:站姿"、去点"运动记忆:站姿"：第一种行为没变，第二种把走路搞坏了（4 秒挪 2.13 米 → 0.70 米）。
  所以这不是一行本能能补上的，已如实写进论文 4.6 第 7 条。
  实验脚本 `试验_站着站姿本能.py`，日志 `日志_试验站姿.log`。

## 整体降权（`全局衰减率`）为什么修不了 R9 的摔

2026-09-17 试过：给所有可塑兴奋连接加一个每拍乘 (1-率) 的整体衰减，让不常用的连接自己沉下去。
**结论：不管剂量大小都没用，而且会加重。**

| 种子 | 全局衰减率 | 教学段翻倒 | 考试段 |
|---|---|---|---|
| 20260914 | 0（基线） | 第 174 拍 | **一次没翻，末高 0.352 m** |
| 20260914 | 0.0005 | 第 174 拍 | 第 101 拍翻倒 |
| 20260914 | 0.004 | 第 152 拍 | 第 101 拍翻倒 |
| 20260917 | 0（基线） | 第 175 拍 | 第 75 拍翻倒 |
| 20260917 | 0.0005 | 第 175 拍 | **第 45 拍翻倒（更早）** |
| 20260917 | 0.004 | 第 163 拍 | 第 75 拍翻倒 |

原因不在剂量，在结构：`固化比例 = 0.3`，**只有 30% 的本能连接是"固化"的**，另外 70% 可塑。
整体降权把这 70% 也啃了，而本能表的强度是**按精确阈值标定**的（前额叶砸到走路链上的
0.850 正好等于点火门槛）。把标定啃掉，行为就散架。

脚本 `试_全局衰减_修R9.py`；日志 `日志_全局衰减000.log` / `0005` / `004`。
旋钮默认 0（关），所以论文里其它数字一个没动。
