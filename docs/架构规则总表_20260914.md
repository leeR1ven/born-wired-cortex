## 0. 骨架（一句话）

外界信号 → 各感觉前处理（多层局部网络，权重出生固定）压缩成稀疏放电
→ 汇合到前额叶 → 前额叶既能沿**天生互惠返回线**把信号镜像回送各感觉区（"想出"一个东西）
→ 也能把命令发给运动区 → 运动区经**反向赫布网络**展开成肌肉发力。
全程由**海马体时间环**提供唯一时钟，三个记忆区按时刻把每帧放电挂起来，可回放。

当前实际规模：视觉 23040 + 听觉 30000 + 运动 4000 → 前额叶输入 57040。

## 1. 三个基础构件

### 1.1 特征神经元池（`视觉前处理_visual_preprocess.py:3`，四份文件各有一份）
- 每个特征用**正、反一对**神经元表示，二者竞争，**恰好激活一个**。
- 判定规则：`正信号 >= 反信号` 则正神经元赢（**平局算正**），随后清空信号
  （`视觉前处理_visual_preprocess.py:15-21`）。
- 参数：只有 `对数`；`总数 = 对数 × 2`。
- 强弱用"温度计码"表达：L 档 = 前 L 对的正神经元亮，后面对全反 → 0~N 共 N+1 级。

### 1.2 神经网络（多层，局部连接，权重出生固定）
- 每层神经元数量 = 输入层总数；每个神经元只连上一层**环形邻域**
  （`±连接半径`，首尾相接成环）；权重出生随机取 `[0, 权重范围)` 后**固定不变**；
  阈值放电（`加权和 ≥ 阈值` 才亮）。
- **这类网络不做赫布学习**（`架构说明.md` 第 3 节）。

**视觉版多两个东西**（`视觉前处理_visual_preprocess.py:24-31`）：
- 最后一层"归一化放电"：按 `全层均值 + α×全层标准差` 放电，α 在**出生时自动校准**
  （`校准帧数 = 8` 帧随机输入）。想改平均亮几个只改 `输出目标亮数`。
- 最后一层可单独用更宽的 `输出感受野`（默认沿用 连接半径）。
- **`输出目标亮数 = 0` 时完全退回旧版**：所有层都用固定 `阈值初值`。

### 1.3 连接表（可塑连接的管理，`权重连接管理_weight_manager.py`）
- 结构：`起点 → {终点: 权重}`。
- 规则：用一次加 `强化量`；连接条数到 `警戒线` 后，每隔 `衰减间隔` 次维护
  做一次整体衰减（全部 × `衰减率`）；低于 `消失下限` 的连接删除
  → **常用的维持，少用的慢慢消失，条数不会无限涨**。

| 参数 | 值 | 含义 |
|---|---|---|
| `强化量` | 1.0 | 每使用一次加多少 |
| `衰减率` | 0.9 | 整体衰减时权重 ×0.9 |
| `消失下限` | 0.05 | 低于它就删掉这条连接 |
| `警戒线` | 100000 | 连接条数到这条线**才开始**周期衰减 |
| `衰减间隔` | 200 | 到警戒线后每约 200 次维护衰减一次 |

## 2. 各脑区

### 2.1 海马体时间区（`海马体时间区_hippocampal_time.py:4`）
- `时间环(时间神经元数量=1728000, 每步秒数=0.05, 每帧步数=2)`
- 时间神经元绕成一圈首尾相连；**每走一格 = 0.05 秒**（内部时间步）；
  **一帧 = 每帧步数 格 = 0.1 秒**；绕一圈 = 1728000 × 0.05s = 86400s = **24 小时**。
- 规则：`时钟 = 时间环()` 是**全系统唯一**的时钟，所有记忆区都引用它
  （`:38`，这条在 `架构整合/未采用说明.md` 里被用户明确强调过）。

三条机制（`架构说明.md` 2.3）：
1. **单调只增**：命令码亮的神经元向本帧激活的肌肉特征铺连接，`一次学会`（权重到 1 即饱和），**学会永不遗忘**；
2. **门控省位**：先自测召回，已接近真实肌肉就不再新增连接 —— 反复做同类动作不会把记忆铺满；
3. **天生镜像底版**：召回时叠一条固定镜像线的微弱投票（`镜像强度`），让没学过的全新命令码也先给出肌肉大致位置（不学习、不占内存）。

> ⚠️ `class 反向赫布网络旧版`（`:163`）整份留在文件里，**没有任何调用方**。
> 它的签名比新版少了 `门槛 / 封顶 / 镜像强度`。建议删除或改名归档，否则以后容易改错文件。

**规则**（`前额叶区_prefrontal.py:67`）：中间层用一个阈值、最后一层用更高的阈值，
**保证只亮少量神经元**。

**① 天生互惠返回线** `天生互惠返回线(前额网, 返回保留比例=0.3)`
- 把前额叶输出沿**出生时固定镜像的连线**逐层回传给三个输入段（`:135` 注释：
  "直接借用正向的邻居表与出生权重（只读），方向倒过来用就是互惠回路"）。
- **固定权重、不学习、永远可用**（`:612`）。
- 门限参考**未受抑制的峰值**，再乘 `(1-抑制量)` —— 这是为了让专注闸门能做**部分**抑制，
  而不是只能全开/全关（`:153` 的注释，也是本次未提交改动修的地方）。

**② 海马索引** `海马索引()` 无参数
- 只记"哪一刻"，**不存内容**；同一对只记一次，**重复经历不加重**（学一次就记住，不会越记越模糊）。
- 回忆：给一个前额叶输出模式，每个记过的时间细胞"举手报数"，举最多的胜出；
  那一刻各区是什么由各记忆区按胜出的时间细胞补全。
- 没凑够票（票数比例 < 相对门槛）= 没见过这一刻，**不乱回放记忆**。
- 三个锁定 API：`锁定时间(输出模式, 相对门槛=0.7)`（精确匹配，比例诊断）、
  `锁定胜出(输出模式, 底票=80, 领先=40)`（给几百个细胞一起亮的**真实念头**用：
  票最多**且明显领先第二名**才锁定，避免把噪声当事件）、
  `锁定全键(输出模式)`（新写的加速版，**目前没有调用方**）。

**③ 前额叶联想区**
`前额叶联想区(宽度, 每段=40, 门槛=2.0, 目标下限=4, 目标上限=24,
 目标比例下限=0.5, 目标比例上限=1.3, 强度初值=1.0, 强度下限=0.15, 强度上限=15.0,
 调节速度=0.15, 静息抑制=1.0, 反馈抑制=0.12, 去抑抵消=0.2)`

三类神经元布在同一层环上（每 `每段` 个正常神经元配一个抑制/去抑制位点）：
- **正常神经元** = 念头细胞（一个念头 = 其中一小撮细胞亮着）
- **抑制神经元** = 压自己位点附近正常神经元（强度 = 整体强度 ×(静息 + 局部反馈)）
- **去抑制神经元** = 专门压抑制神经元：门一开，本来的抑制被抵消，附近念头容易亮

学习（时序赫布，方向 = 先激活 → 后激活）：
- 上一帧念头 a → 下一帧念头 b：记一格 `联想[a → b]`（同一对再现就加粗）
- 上一帧念头 a → 下一帧念头**附近位点**的去抑制神经元：记一格 `去抑[a → 位点]`

回忆（内部微步，一帧内可连走好几步）：
- 当前念头 → 给学过的后继投票
- 当前念头 → 给学过后继的位点开门（去抑制抵消抑制）
- 没开门的位点仍有 `整体强度 × 抑制` 压着 → 无关念头、噪声亮不起来

**动态整体抑制（自我平衡）**：
- 这一微步亮的念头细胞太少（< 目标下限）→ 整体抑制调低（变容易激活）
- 太多（> 目标上限）→ 整体抑制调高（防止一次冒出太多记忆）
- 目标区间 = 典型念头的 `目标比例下限 ~ 目标比例上限` 倍

发散规则（`:749`）：A 后面既跟过 X 也跟过 Y → **少量候选并存，而不是唯一**。

**④ 专注闸门** `专注闸门(转变速度=0.35, 输入抑制率=0.95, 回忆抑制率=1.0, 运动抑制率=1.0)`
- 抑制池（被内部念头活跃驱动：念头在跑 = 深度思考 → 抑制变强）
  vs 去抑制池（**自发放电维持通路开放**，`:816`：没在想事情时窗全开，听外界/自动回忆/动手都是默认状态）。
- 每条通路**净开度 = 去抑活性 − 抑活性**：压不住就全通，压住了就合闸。
- 三条通路：输入（专注时压低 → 外界叫不醒，思考不被打断）、
  回忆（专注时不主动回忆）、运动（专注时只"想"不动）。
- **不是瞬间开关**：念头一来要几个微步才压过自发放电；念头一停逐步恢复（注意力转移需要时间）。

### 2.6 三个记忆区（视觉/听觉/运动，三份文件结构相同）
- `记忆区(神经元数量)`；两份连接表 `特征到时间` / `时间到特征`。
- **两条规则**（三个文件里的注释一模一样）：
  1. **上一帧的特征 → 下一格时间神经元**（`特征到时间.学习(f, 新时间)`）
  2. **上一格时间神经元 → 下一帧的特征**（`时间到特征.学习(旧时间, f)`）
- `回忆(特征模式, 步数=10, 阈值=1)`：给一组特征 → 各时间细胞按权重加票 →
  得票最高的时刻胜出 → 沿时间环连续播放后续帧。
- 每次学习后调 `维护()`（达到警戒线后定期整体衰减，防无限增长）。
- 运动记忆区记的是**运动输出区每一帧的输出层命令模式**（方案1，和视/听一致：
  记大脑发出的命令序列；真要动肌肉时由反向赫布网络展开）。

## 3. 学习 vs 固定（`架构说明.md` 第 3 节，很关键）

| 组件 | 权重 | 为什么 |
|---|---|---|
| 视觉/听觉/运动/前额叶 **正向网络** | 出生固定，永不改 | 它们是"信号处理电路"，必须稳定 |
| **天生互惠返回线 / 镜像投票** | 出生固定，永不改 | 天生返回布线，不学不遗忘 |
| **三个记忆区** | 赫布学习 + 定期衰减 | 记"什么时刻发生了什么" |
| **前额叶联想区** | 赫布学习 + 动态抑制 | 学念头之间的先后关系 |
| **运动反向赫布网络** | 一次学会、单调只增 | 命令→肌肉的路，学会就固定，绝不遗忘 |
