# 抑制连接只发了一半：`_生抑制()` 的构造 bug（2026-09-29）

## 一句话

`model/皮层连接_cortex_links.py` 的 `_生抑制()` 生成抑制边时，**只有下标前半段的细胞**能长出
抑制出边，后一半一根都没有；而且「一半就近、一半撒全脑」里**就近那一半从来没生成过**，
活下来的全是全脑随机边。

## 为什么

`偏` 的排布是「前 `N*就近条` 个是就近偏移、后 `N*随机条` 个全是 0」，
但代码随后用 `目[:N*随机条] = 随机目标` 去覆盖——**数组的前半段**。
按「每个源连续 `条` 条」的排布，数组前半段正好等于**前一半的源**。于是：

- 前一半细胞：100 条抑制边全是全脑随机（就近那 50 条被覆盖掉了）
- 后一半细胞：`目 = 源 + 0 = 源`，被 `目 != 源` 过滤掉，**一条都不剩**

最小复现（N=120、条=100、半径 24、seed 20260914），每个源最后剩几条：

| 源 | 0..5 | 55..59 | 60..119 |
|---|---|---|---|
| 剩几条 | 98, 99, 98, 99, 100, 100 | 99, 100, 99, 98, 99 | 全是 0 |

## 在论文那套模型上（148,032 个细胞）

| 区 | 起点 | 宽 | 能不能发随机抑制 |
|---|---|---|---|
| 视觉 | 0 | 23,040 | 整区都发 |
| 视觉细节 | 23,040 | 23,040 | 整区都发 |
| 听觉 | 46,080 | 30,000 | 只有前 27,936 个发 |
| **前额叶** | 76,080 | 57,436 | **一根都不发** |
| 运动 / 运动记忆 / 本体感觉 / 平衡感觉 / 机身状态 / 视觉运动 / 多巴胺 / 抑制池 | 133,516 起 | 14,516 | 一根都不发 |

抑制边总数 7,401,600（= 74,016 × 100），而不是设计上的 14,803,200。

## 影响

1. 论文 R1~R12（旧引擎、闭环那批）用的就是这套接线。数字本身没算错——它们报的是
   「这套接线会产生什么行为」——但**和代码注释/参数说的不是一回事**：`抑制就近比例 = 0.5`
   完全没起作用，而且一半皮层（含**整个前额叶**）没有任何随机抑制出边。
2. 「专注」（无关 → 互相抑制变强）这条学习规则**存在、也在跑**（`_学抑制()`），
   但今天只能作用在视觉/听觉之间：前额叶一根随机抑制出边都没有，本能表里
   前额叶当源的 3 条规则全是正力度（0.85），所以**前额叶现在压不住任何东西**。
   这条机制要写成论文，就得先决定下面的甲还是乙。
3. 修好以后模型行为会变。小球规模实测（宽 视觉2000/听觉500/前额叶2000/运动200，
   钉住视觉前 600 个细胞）：
   - 每拍总激活：现在 610 → 修好 780
   - 抑制电流 / 兴奋电流：现在 1.556 → 修好 1.257
   - 能发抑制的细胞：2,350 / 4,700 → 4,700 / 4,700

   所以「修」= 论文里 R1~R12 那一批数字全部要重跑，而且很可能要重新标定本能表。
   （R13~R20 用的是重建引擎 `engine_v2/born_wired`，它的抑制是手工点名的细胞，没有这种
   随机抑制边构造，不受这个 bug 影响；代价是重建引擎里也**没有**这条抑制学习规则。）

## 证据

- 脚本：`model/实验_专注_无关就互压.py`（专为测这条规则写的，第一次跑就撞出了这个 bug）
- 日志：`model/日志_专注_无关就互压.log` / `.json`
- 探针：`_抑制源` 的分布、每源剩几条、以及修好后的对比，都是 2026-09-29 当场跑出来的

## 两条路

- **甲：修**。把 `_生抑制()` 的排布改成「每个源 就近条 + 随机条」，重跑 R1~R12 并重新标定。
  架构终于和它自己的规格一致，代价是一大批实验要重做，且有重新调参的风险。
- **乙：不修**。按现在的接线写论文：把抑制构造如实写进 Methods，不写「前额叶专注」。
  代价是论文里会留一句「本配置下前额叶没有随机抑制出边」。

等用户定。
