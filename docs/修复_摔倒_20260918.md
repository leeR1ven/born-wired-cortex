# 修复：走久了会摔（2026-09-18）

## 一句话

不是学习学歪了，不是走路链乱了，也**不是返回线**。是**前额叶失控**：它靠自己的环越亮越多
（2608 → 2818，还在涨），亮起来的就不只是"正前方红"，**连"左边红"那一撮也点着了**。
本能表里正好有两条相反的指令：

```
前额叶:看着红    ->  运动记忆:前进1.2    0.85
前额叶:看着左红  ->  运动记忆:左转1.5    0.85
```

于是前额叶每一拍同时去点**两个**动作的时刻细胞，两串肌肉力叠在一起，解码出来的发力就错了，
身体从第一拍开始歪，第 66 拍歪过 75 度摔倒。

把前额叶压回稀疏（动态整体抑制，`前额叶自压 = 1e-3`）后，只亮"前进1.2"那一串：
同一颗脑走 **600 拍 / 6.62 米，一次没歪过 75 度**。

## 逐拍证据（种子 20260915，站着看红）

| 这一拍运动记忆区亮着谁 | 前额叶 | 运动区 | 歪 | 结果 |
|---|---|---|---|---|
| 前进1.2 第15拍 + **左转1.5 第25拍** | 2818 个 | 97 个 | 48° | 第 66 拍摔 |
| 只有 前进1.2 第15拍 | 135 个 | 90 个 | 2° | 一直走 |

运动区多出来的那几个细胞（第 60 拍：`25,26,95,104,116,117,118`）就是"左转1.5"那一刻该动的肌肉。
力气一叠，身上这几块就乱了：

```
第50拍  只右前小腿 0.80→0.50   只左前髋 0.40→0.50   只右后髋 0.60→0.50
第70拍  只右前小腿 1.00→0.80   只右后髋 0.70→0.50   只右前大腿 0.50→0.40
```

## 排除掉的（都是实测，不是推理）

| 试的东西 | 结果 |
|---|---|
| 开学习 vs 关学习，各 200 拍 | **逐拍数字一模一样** —— 和赫布学习无关 |
| 只把「返回线→运动区」那一段掐掉 | **逐拍一模一样**，还是第 66 拍摔 —— 返回线不是这条路 |
| 只把「前额叶→运动记忆」那 **5,175 根**（三条手写本能行）掉掉 | 走路动作直接**消失**（0/130 拍）—— “想”就是走这条路去点走路链的 |
| 单独把「前额叶→抑制」234,687 根掉掉 | 逐拍和基准一模一样，还是第 66 拍摔——无关 |
| 前额叶压到 118~154 个 | 走 2.26 米 / 200 拍，歪 2 度，不摔 |
| 前额叶压到只剩 **1 个**细胞 | **逐拍还是一模一样** —— 所以不是"压缩得太狠、信息太模糊" |
| 1e-3 / 2e-3 / 3e-3 三档 | 身体轨迹逐拍相同，只有前额叶亮几个不同（~150 / ~70 / 1） |

结论：起作用的是**"前额叶要保持稀疏"**这件事本身，不是某个具体数值，所以这个旋钮不敏感。

## 改了什么

* `model/皮层连接_cortex_links.py`：`前额叶自压` 默认 0.0 → **1e-3**（原来是关着的）。
* `model/看_大脑开车.py`：
  * 不再强制退回老档，改用**当前默认**（前额叶带环 + 动态整体抑制）；
  * 不再写 8~35 MB 的 base64 巨型 HTML（浏览器打不开），改成几 KB 的小页面。

## 还剩下的

"教会它听见声音就走"（论文 R9）那一段**还是会摔**：教学时"红→走"和天生的"响→原地踏步"两个动作
同时被点着，运动记忆区同时亮 2~3 个时刻，第 107 拍摔。**这是同一个毛病的另一个入口**
（两个动作抢一个身体），只是这次的来源是听觉本能，不是前额叶失控。

可能的修法（还没做）：

1. **动作选择**：同一时刻只许一个动作在跑，多出来的用抑制神经元压掉 —— 生物学上像基底节选动作。
2. **平衡反射**：把 `算反射.py` 那张反射表补厚（现在只有 4 条、只覆盖"右前小腿"一块肌肉），
   让歪到一定程度时**总是**有反射去撑回来 —— 也就是用户最早说的"耳石区没有和运动区形成难以改变的连接"。

## 附：前额叶的出边到底有几条路（实测边数）

| 出去的路线 | 根数 | 是什么 |
|---|---|---|
| **天生互惠返回线** | 单独一套，不在连接表里 | 把前额叶网的正向连接反过来用 → **只能送回当初喂给前额叶的那三路**：视觉、听觉、运动。回返线只镜像**前额网那三路输入**（视觉/听觉/运动），而前额网就只有这三路，
所以它到不了运动记忆 —— 原因在**前额网的输入通道只有三路**，
不是“运动记忆不往前额叶送”（实测：运动记忆 → 前额叶 **135,682 根**，运动 → 前额叶 5,846 根，
前额叶入边共 4,218,871 根）。也就是说：要给返回线补第四条到运动记忆，是**有依据的**，不是凭空加 |
| 出生随机的皮层连接 | 共 5,155,010 根 | 视觉 675,161 / 视觉细节 676,520 / 听觉 881,297 / 前额叶自己 2,662,940 / 抑制 234,687 / 本体感觉 13,943 / 平衡感觉 3,555 / 机身状态 1,732 —— 这是"各区皮层神经元出生就有一批随机连接"那一条通用规则撒出来的 |
| **手写的本能行** | **5,175 根** | `前额叶:看着红 → 运动记忆:前进1.2`（0.85）、`看着左红 → 左转1.5`、`看着右红 → 右转0.75` |

**所以"想走路"现在走的是第三类（那三行手写本能），不是返回线。**
这不是随手加的：2026-09-15 用户要求"视觉区激活运动区这条本能连接要经过前额叶来控制，这样可以验证前额叶有没有正常工作"，
当时的实现方式就是先给前额叶标出"看着红"这些名字，再写这三行，让这条路必须过前额叶才能点火
（见 `model/本能工具_instincts.py` 第 439~446 行的说明）。

**要改成严格走返回线的话**：得给返回线补第四条路（前额叶 → 运动记忆），因为它现在只镜像正向那三路，
而运动记忆不往前额叶送。改不改由用户定。

## 附二：前额叶的输入账本（实测边数 + 设计好的通道）

**设计好的通道**（`前额叶区_prefrontal.py` 的多层前额网）只有**三路**：
视觉（压缩完那一段）+ 听觉 + **运动区**。
第三路喂的就是"现在每块肌肉出多大力"那片肌肉档位细胞 —— 所以前额叶每拍都知道身体在怎么动。
前额叶里"在想走路"这个名字，就是拿"走路第一拍的肌肉模式"喂进去标定出来的（见 `本能工具_instincts.py` 的 `前额叶例子`）。

**出生随机那批边**（每细胞约 100 根）另算，实测：

| 谁 → 前额叶 | 根数 |
|---|---|
| 视觉 | 507,621 |
| 听觉 | 701,830 |
| 前额叶自己 | 2,662,940 |
| 运动记忆 | 135,682 |
| 视觉运动 | 36,018 |
| 本体感觉 | 8,905 |
| 运动 | 5,846 |
| 平衡感觉 | 2,221 |
| 机身状态 | 1,119 |
| 抑制 | 156,689 |
| **合计** | **4,218,871** |

**发现的缺口**：按用户的说法"前额叶是把大脑其他多个地方的信号再次压缩成更少的信号"，
那么本体感觉、平衡感觉、机身状态、运动记忆 都该有**设计好的输入通道**进前额叶；
现在它们只有随机边，没有专门的通道。要不要补齐，由用户定。
