# 修复：走久了会摔（2026-09-18）

## 一句话

不是学习把权重长歪了，是**前额叶在累加**：它一亮就靠自己的环一直亮，越亮越多（2608 → 2818 还在涨），
经天生互惠返回线往运动区灌电流，把运动区点亮到 96/160（共 160 个），身体**从第一拍就开始歪**，
第 66 拍歪过 75 度摔倒。把前额叶压回稀疏（动态整体抑制，`前额叶自压 = 1e-3`），同一颗脑走 600 拍、
6.62 米，一次没歪过 75 度。

## 怎么定到这个原因的（都是一次跑几百拍的实测，不是猜）

| 试的东西 | 结果 |
|---|---|
| 开学习 vs 关学习，各跑 200 拍 | **逐拍数字一模一样** —— 摔跟学习无关 |
| 走路链本身有没有乱 | 出生这一档**始终只有 1 个时刻亮**（300/300 拍），链子是干净的 |
| 运动区亮几个 | 一直 94~101 / 160 个 —— 太多了（一个动作本来只要十几个） |
| 前额叶亮几个 | 2608 → 2818 还在涨（整片 53200） |
| 退回老档「回响关」（每拍重算） | 走 2.26 米、末歪 2 度、**不摔** |
| 开动态整体抑制 1e-3 | 前额叶 118→154，**逐拍轨迹和"回响关"一模一样**，不摔 |
| 2e-3 / 3e-3 | 身体轨迹还是**一模一样**（只有前额叶亮几个不同：~70 / 1） |

结论：起作用的是"把前额叶压回稀疏"这件事本身，不是某个具体数值，所以这个旋钮不敏感。

## 改了什么

* `model/皮层连接_cortex_links.py`：`前额叶自压` 默认 0.0 → **1e-3**（原来是关着的）。
* `model/看_大脑开车.py`：
  * 不再强制退回老档，改用**当前默认**（前额叶带环 + 动态整体抑制）；
  * 不再写 8~35 MB 的 base64 巨型 HTML（浏览器打不开），改成一个几 KB 的小页面。

## 还剩下的

"教会它听见声音就走"（论文 R9）那一段**还是会摔**：教学时"红→走"和天生"响→原地踏步"两个动作同时被点着，
运动记忆区同时亮 2~3 个时刻，两串肌肉力叠在一起，第 107 拍摔。这是**另一个问题**（两个动作抢一个身体），
和上面这个不同。

可能的修法（还没做）：

1. **动作选择**：同一时刻只许一个动作在跑（多出来的那些用抑制神经元压掉）—— 生物学上像基底节选动作。
2. **平衡反射**：把 `算反射.py` 那张反射表补厚（现在只有 4 条，而且只覆盖"右前小腿"一块肌肉），
   让歪到一定程度时**总是**有反射去撑回来。这也是用户最早说的"耳石区没有和运动区形成难以改变的连接"。
