# 修复：走久了会摔（2026-09-18）

## 一句话

不是学习学歪了，不是走路链乱了，也**不是返回线**。是**前额叶失控**：它靠自己的环越亮越多
（2608 → 2818，还在涨），亮起来的就不只是"正前方红"，**连"左边红"那一撮也点着了**。
本能表里正好有两条相反的指令：

```
前额叶:看着红    ->  运动记忆:前进1.2    0.85
前额叶:看着左红  ->  运动记忆:左转1.5    0.85
```

于是前额叶每一拍同时去点**两个**动作的时刻细胞，两串肌肉力叠在一起，解码出来的发力就错了，
身体从第一拍开始歪，第 66 拍歪过 75 度摔倒。

把前额叶压回稀疏（动态整体抑制，`前额叶自压 = 1e-3`）后，只亮"前进1.2"那一串：
同一颗脑走 **600 拍 / 6.62 米，一次没歪过 75 度**。

## 逐拍证据（种子 20260915，站着看红）

| 这一拍运动记忆区亮着谁 | 前额叶 | 运动区 | 歪 | 结果 |
|---|---|---|---|---|
| 前进1.2 第15拍 + **左转1.5 第25拍** | 2818 个 | 97 个 | 48° | 第 66 拍摔 |
| 只有 前进1.2 第15拍 | 135 个 | 90 个 | 2° | 一直走 |

运动区多出来的那几个细胞（第 60 拍：`25,26,95,104,116,117,118`）就是"左转1.5"那一刻该动的肌肉。
力气一叠，身上这几块就乱了：

```
第50拍  只右前小腿 0.80→0.50   只左前髋 0.40→0.50   只右后髋 0.60→0.50
第70拍  只右前小腿 1.00→0.80   只右后髋 0.70→0.50   只右前大腿 0.50→0.40
```

## 排除掉的（都是实测，不是推理）

| 试的东西 | 结果 |
|---|---|
| 开学习 vs 关学习，各 200 拍 | **逐拍数字一模一样** —— 和赫布学习无关 |
| 只把「返回线→运动区」那一段掐掉 | **逐拍一模一样**，还是第 66 拍摔 —— 返回线不是这条路 |
| 把「前额叶→运动记忆」259,092 根边全掐掉 | 走路动作直接**消失**（0/200 拍）—— "想"确实是走这条路去点走路链的 |
| 前额叶压到 118~154 个 | 走 2.26 米 / 200 拍，歪 2 度，不摔 |
| 前额叶压到只剩 **1 个**细胞 | **逐拍还是一模一样** —— 所以不是"压缩得太狠、信息太模糊" |
| 1e-3 / 2e-3 / 3e-3 三档 | 身体轨迹逐拍相同，只有前额叶亮几个不同（~150 / ~70 / 1） |

结论：起作用的是**"前额叶要保持稀疏"**这件事本身，不是某个具体数值，所以这个旋钮不敏感。

## 改了什么

* `model/皮层连接_cortex_links.py`：`前额叶自压` 默认 0.0 → **1e-3**（原来是关着的）。
* `model/看_大脑开车.py`：
  * 不再强制退回老档，改用**当前默认**（前额叶带环 + 动态整体抑制）；
  * 不再写 8~35 MB 的 base64 巨型 HTML（浏览器打不开），改成几 KB 的小页面。

## 还剩下的

"教会它听见声音就走"（论文 R9）那一段**还是会摔**：教学时"红→走"和天生的"响→原地踏步"两个动作
同时被点着，运动记忆区同时亮 2~3 个时刻，第 107 拍摔。**这是同一个毛病的另一个入口**
（两个动作抢一个身体），只是这次的来源是听觉本能，不是前额叶失控。

可能的修法（还没做）：

1. **动作选择**：同一时刻只许一个动作在跑，多出来的用抑制神经元压掉 —— 生物学上像基底节选动作。
2. **平衡反射**：把 `算反射.py` 那张反射表补厚（现在只有 4 条、只覆盖"右前小腿"一块肌肉），
   让歪到一定程度时**总是**有反射去撑回来 —— 也就是用户最早说的"耳石区没有和运动区形成难以改变的连接"。
