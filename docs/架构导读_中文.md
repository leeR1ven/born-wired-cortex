# 架构特点与工作原理：中文导读

对应论文 v0.2 的新增概览，2026-09-08。本文介绍结构、实现机制与研究假设，不宣称所有能力已经验证或所有组件都是首次提出。

## 一句话理解

把「当时看见什么、听见什么、做了什么」连到同一条时间轴上，让当前感觉与回忆在前额叶模块中反复相互激活、竞争和调节，最终通过神经运动解码产生动作，并把新的经历接续记录下去。

## 整体结构

实际运行是一个循环：环境和身体产生感觉；感觉前处理与实际运动编码进入前额叶；前额叶通过返回投射、索引和原三模态记忆交换活动；多种运动电流竞争出命令，运动反向网络解码为肌肉发力；身体改变环境及下一时刻感觉。

「感觉进入前额叶」和「感觉/动作在时间记忆中形成记录」是相互联系的通路，不应画成必须先写完记忆才允许思考的单向流水线。

## 集中说明的六项特点

| 特点 | 具体机制 | 目前能准确说明的程度 |
| --- | --- | --- |
| 唯一时间轴连接三种记忆 | 视觉、听觉、运动共用原时间标识；一个时刻只有一个时间位置激活 | 已实现；不等于所有记忆永不丢失或无限容量 |
| 从局部线索找回相关经历 | 特征到时间与时间到特征的连接、内容检索和互惠返回，让声/画面/动作记录相互关联 | 有实现和记录可检查；特定声音是否找对整段经历须实测 |
| 多簇共同招募后续活动 | 不同来源的活动经连接权重汇合，阈值、抑制和去抑制决定后续激活 | 已有递归机制；能否形成复杂逻辑属于行为实验问题 |
| 记忆接入真实肌肉出口 | 正向网络编码肌肉状态，原运动记忆提供命令内容；竞争后由反向赫布网络解码为力 | 已实现神经控制；反向网络不是梯度反向传播，当前宠物解码连接有先天预接线 |
| 交互中局部学习与活动调节 | 符合条件的共活动增强连接，部分连接衰减；低权重增长较快，高权重趋于饱和；疲劳与抑制调节活动 | 已实现对应更新；不是保证正态分布、永不遗忘或必然产生新行为 |
| 连接与经历可追踪，模块可研究扩展 | 可查看实际权重、活跃单元、回忆时间、候选运动电流；为单独训练和兼容连接融合提供研究接口 | 可检查不等于所有行为已被解释；旧版有融合实验，当前完整宠物尚未验证融合 |

固定的感觉编码和先天连接提供初始组织；在线学习改变指定的可塑连接。角色还会随当前激活、疲劳和抑制状态改变行为，因此不是「每一次行为变化都必须先改变长期权重」。

## 用“听到喂食声”理解设计意图

1. 声音和眼前景象变成当前神经活动。
2. 学习到的声音关联若满足检索条件，可以激活原时间点的记忆，唤回当时的喂食器画面及相关内容。
3. 这个回忆与当前所在位置的视觉活动一起进入前额叶。两簇或多簇贡献共同提高另一簇的输入，竞争、抑制与去抑制影响谁胜出。
4. 进一步联想或经历传播可能激活与当前情况匹配的下一段经历，从其原时间读取运动记忆。
5. 这一路运动电流与当前感觉、本能等电流共同竞争，经原解码和注意门输出肌肉动作。
6. 身体走动后得到新的画面；接下来的决定继续基于新感觉、当前活动与原记忆。

这是待完整验证的声到目标再到路径的机制示例。现有主要对照并未调用出目标条件的运动序列记忆，因此不能把这段说明当作已经成功规划导航的实验记录。

反复学习后也可能形成直接的声到动作关联，某些中间簇不再每次必经。不能把出现直接联想一概判为错误；需要通过新起点、新目标组合和通路干预，区分熟练响应与灵活组合。



## 结论适用范围

本文中“未验证/负向结论”的适用范围，仅限于当前这次模型实例、该次续接任务的训练经历和五房任务设置；这并不等于该架构在全部场景下“不可能规划”“不可能扩展”或“不可能走向 AGI”。这同样不意味着扩大模型就必然产生 AGI。先天接线是可实验的结构先验，而非手写某张地图的特例答案；应通过在相同经历轨迹下对照“有/无先天接线”，再在陌生起点和新布局重复复现，区分结构先验与路线答案的因果来源。

## “本能、思考、创新”应怎样写

本能描述连接的来源，是否经过前额叶描述活动的通路，两者可以同时成立。先天权重也可能位于前额叶；看到前额叶活动或肌肉记忆回放，仍要进一步检查具体计算和行为。

本稿的候选架构贡献是这些部分的具体组合及其可核查实现：统一经历引用、跨模态回忆、递归群活动、神经运动出口和局部在线可塑性。单独的赫布学习、联想记忆、抑制、时间索引已有相关工作；不能直接写成世界首创。现有独立结果主要是运动电流平衡的诊断和对照效果。

后续若首次路线组合、移动前计算和原前额叶通路干预产生可靠结果，应把它们作为新贡献写入论文。把模型扩大、把多个模型融合、接入复杂社会或形成自然语言，都应注明各自已经验证到哪一步。

## 群体联想怎样变成脑海里的话：新增机制假说

多个前额叶样群体相互激活时，可能维持一个尚未确定为某句话或画面的大致联想状态。它与连续感觉记忆的双向提取、补全及重组，可能逐步形成更明确的声音、词序或视觉表征；这些表征又参与下一轮联想。实际发声还需要发音运动输出通路接通并执行，运动准备活动本身不等于已发声。这些过程可交互、可跳转，不要求每次都按固定阶段依次发生，也不要求声音和画面必定同时出现。

这是论文 v0.3 第 6.1-6.2 节提出的待验证假说。它不要求所有记忆都是具体经历的原样副本，也不把前额叶限定为只能提取具体记忆。本次字符群体实验没有运行完整前额叶、听觉记忆、视觉记忆和发音系统；字组的人工主题概括不能证明某个确定想法，更不能据此把没有成句的原因归结为缺少这些通路。

相应检验应比较记忆返回通路完整与中断、发音出口关闭与接通、同一提示处于不同经历背景时的具体内容恢复和行为。重点是检查恢复了什么、是否随情境改变及哪些连接起因果作用。详见[机制假说与证据说明](population_reinstatement_hypothesis_20260913.md)。
