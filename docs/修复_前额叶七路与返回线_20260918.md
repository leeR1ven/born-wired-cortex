> 用户原话："既然前额叶通道和返回线有问题，说明你没有按照我说的把完整架构搭建好，
> 我之前说过把完整架构搭建好，不然出了问题找不到，结果你还是没有搭建好。"

这份记录说的就是这件事：**前额叶的输入通道和天生互惠返回线，以前只搭了三路，现在按
架构补全了**；以及补的过程里撞到什么、怎么定的规则、最后实测是什么样。

## 一、改之前是什么样

`前额叶区_prefrontal.py` 里，前额网只有 **三路输入**：

| 路 | 宽度 |
|---|---|
| 视觉（第 4 层，压缩完的） | 23040 |
| 听觉 | 30000 |
| 运动（肌肉发力那一片） | 160 |
| **合计** | **53200** |

天生互惠返回线是把上面这三路**原样倒过来**用，所以它**只能回到视觉 / 听觉 / 运动**。

问题是：架构里前额叶该收的是 **"大脑其他多个地方的信号"**。实际有七个区都在往外发：

| 区 | 有没有设计好的通道进前额叶？ |
|---|---|
| 视觉 | 有 |
| 听觉 | 有 |
| 运动 | 有 |
| 本体感觉 | **没有**（只靠出生时撒的随机边碰运气） |
| 平衡感觉 | **没有** |
| 机身状态 | **没有** |
| 运动记忆 | **没有** |

用户 2026-09-18 点出来的正是这个："运动记忆不往前额叶送，那前额叶怎么知道有没有运动呢？
而且也不对啊，模型架构说好的前额叶神经网络输入是好几个其他区当作输入。"

## 二、改成了什么样

### 2.1 一张路表现在是**唯一的一份真相**

`前额叶区_prefrontal.py` 里：

```
输入路 = [
    ("视觉",     视宽,                        10, True),
    ("听觉",     听宽,                        10, True),
    ("本体感觉", int(本体感觉.输出层数量),      5, False),
    ("平衡感觉", int(平衡感觉.输出层数量),      5, False),
    ("机身状态", int(机身状态.输出层数量),      5, False),
    ("运动记忆", int(运动记忆.输出层数量),     10, True),
    ("运动",     运宽,                         1, True),
]
```

四列分别是：**区名 / 这一路多少个细胞 / 这一路的扩散半宽 / 这一路有没有返回线**。
前额叶一层从 53200 个细胞变成 **57436** 个。

主循环喂前额叶、返回线往回送，**都读这张表**，不各写一份切片
（以前是主循环手写三路切片、前额叶那边手写三路拼，改一处漏一处 —— 这次改成一处说了算）。

### 2.2 每一路的"扩散半宽"为什么不一样

各区送来的是稀疏码（几万个细胞里只亮几十个），直接进固定阈值的局部网络一个细胞都推不亮，
所以每一路先各自"扩散"（每个亮点连同周围 ±半宽 一起点亮成小亮斑），亮斑密到一定程度
上一层才收得够电流。半宽各不一样，理由：

| 路 | 半宽 | 为什么 |
|---|---|---|
| 视觉 / 听觉 | 10 | 两万三 / 三万个细胞里只亮几十个，糊 10 才连成小亮斑 |
| 本体感觉 / 平衡感觉 / 机身状态 | 5 | 一个特征占 20 个细胞、真实状态点 3 个，糊 5 变 13 个（刚够推亮上一层），又没糊过 20（不把相邻特征混成一个） |
| 运动记忆 | 10 | 一个神经元 = 一个时刻，顺带把"前后几拍"也带上（记忆本来就该模糊） |
| 运动 | 1 | 只有 160 个细胞（12 块肌肉 × 档位），糊大了九个动作就分不出来（2026-09-15 实测过） |

### 2.3 返回线：**按同一张表原路切开，而且感觉区不设返回线**（§7 又往前推了一步：运动记忆 / 运动也不设）

`天生互惠返回线.返回()` 现在返回的是**一个字典**（谁的路还给谁），不再是一条要手工切的长数组。

★ 门限是**每一路按自己那一路的峰值**算的（`返回保留比例 = 0.4`）。
不这样的话，一路大的（视觉 23040、听觉 30000）会把"峰值"顶得很高，
一路小的（平衡感觉 120）就永远回不去。

★ **感觉区不设返回线**（用户 2026-09-18 定的一条）：

> "有些区域不该有返回线，比如感觉区，因为感觉区触发后会真的触发很多本能反应。
> 对于生物来说想象到自己受伤也不会真的疼。这就有点像心盲症，但这不是坏事。"

所以现在：

| 区 | 有返回线吗 | 含义 |
|---|---|---|
| 视觉 | 有 | 心里能"看见"（心盲症 = 这条断） |
| 听觉 | 有 | 心里能"听见"（心失语症 = 这条断） |
| 运动记忆 | 有 | 前额叶"想着"一个动作，能真把它跑起来 |
| 运动 | 有 | 同上（想着的姿势能落到肌肉上） |
| 本体感觉 / 平衡感觉 / 机身状态 | **没有** | **只进不出**：身体读数只能由身体自己报，想不出来 |

## 三、补通道时撞到的两件事（都实测过）

### 3.1 先撞上的：返回线点亮身体感觉区 → 误触发"站起来"

一开始把七路**全部**接上返回线。结果：

* 站着看红，前额叶每拍往 **本体感觉塞 12~22 个细胞、平衡感觉 17 个、机身状态 13 个**；
* 平衡感觉那几个"情况"（`翻过去了`、`往前倾`……）一个只占 **2~3 个细胞**，
  被这十几个细胞一盖就整块亮了 → 把 `平衡感觉:翻过去了 → 运动记忆:站起来`、
  `听觉:停 → 运动记忆:站姿` 这些本能**误点着**；
* 于是运动记忆里同时跑 **2~3 个动作**（`站起来` + `站姿` + `前进1.2`），
  几串肌肉力叠在一起 → **第 126 拍摔倒**。

A/B 对照（同一条轨迹、同一种子，只改"返回线回不回那三路"）：

| 条件 | 结果（150 拍） |
|---|---|
| A 七路全回 | **第 126 拍翻倒**，末拍动作 `站姿 + 站起来 + 前进1.2` |
| B 身体三路不回 | **一次没翻**，歪 0~6 度，末拍动作只有 `前进1.2` |
| C 只回 视/听/记忆/运动 | **一次没翻**，同上 |

也就是说：**想象出来的"身体歪了"会真的去救** —— 那不是思考，是幻觉。
用户那条"感觉区不该有返回线"的规则，正好就是这件事的解。

（中途还试过另一个办法：把一拍里的顺序改成"现实盖住想象" —— 先让返回线送回来，
再把真的外界信号盖上去。它也能修好摔倒，但那是"另一条规则"，用户给的规则更干净，
所以最后按用户的规则实现，那个顺序改回去。）

### 3.2 还剩下的：身体那三路对前额叶的影响还很小

实测（同一张红图，只换身体姿势）：

| 给前额叶的身体那三路 | 前额叶输出层亮多少个 |
|---|---|
| 站着 | 1440 |
| 趴着 | 1443 |
| 不给 | 1433 |

站着 vs 趴着，前额叶输出只差 **11 个细胞（占亮着的 0.8%）**。

也就是说：**通道通了、前面那三层真的被推亮了（本体感觉那一路推亮 322 个第 1 层细胞），
但到输出层只剩很小的差别。** 原因是视觉那一路又宽又密（扩散完占该路的 69%），
把前额叶输出压住了。要让身体那三路说话，下一步得调各路的扩散 / 权重 / 阈值
（这是"调参"，不是"架构缺件"）。

## 七、追加（2026-09-18 夜）：返回线灌进运动记忆会误点着一整套动作

### 7.1 起因：趴着自己站起来又塌回去（R3 从 3/3 变成 0/3）

补完七路以后，单跑 `闭环_前提.py` 实测：**它确实起来了**（机身 0.099 → 最高 0.265 米），
但站不住，2.5 秒后塌回 0.180 米。论文 R3 那条"从趴着自己站起来"于是从 3/3 变成 0/3。

逐拍看（`诊断_起身逐拍.py`、`诊断_趴下去哪来的.py`）才看清断在哪：

| 拍 | 机身高度 | 运动记忆区亮着哪几个动作 | 返回线送回运动记忆的东西 |
|---|---|---|---|
| 0~50 | 0.102 → 0.241 | 站起来 | 空 |
| 51~53 | 0.245 → 0.253 | 站起来 → 站姿 + **趴下去** | **站起来 + 趴下去** ← 就是这一下 |
| 54~100 | 0.265 → 0.191 | 站姿 + 趴下去 | 空（"趴下去"已经自己在跑了） |
| 110~ | 0.180（塌定） | 站姿 + 坐下 + 趴姿 | 空 |

"站起来"跑完交给"站姿"，站姿本来能一直把身体托在 0.261 米（论文 4.4 单独测过：
十二块肌肉恒 0.5 就站得住）。**第 51 拍，返回线把邻着的"趴下去"头一拍送回了运动记忆**
—— 运动记忆是一条时间线，一个细胞 = 一整套动作（60 拍），"趴下去"的头一拍正好排在
"站起来"最后一拍后面，返回线那圈粗信号（连接半径 10）一散就跨过去了。那套动作当场跑起来。

**为什么两个动作一起亮，身体就会沉下去**：运动区是"每块肌肉一组神经元，亮几个就是几档力"
（运动单位募集）。两套动作同时亮 = 每块肌肉取**最大值**（不是平均）。所以"趴下去"要求
更大力气的那几块肌肉，就把"站姿"的力盖掉一部分，身体一点点从 0.265 米沉到 0.180 米。

### 7.2 ★ 走过的一条错路（记下来，别再犯）

第一反应是"运动记忆/运动这一路干脆不要返回线"，实测确实立刻好了（0.180 → 0.261）。
**但那是错的** —— 用户 2026-09-18："你把运动记忆/运动也不设返回线，那前额叶怎么发信息给
运动区？"。前额叶往运动区发信息这条通路是这个架构的一半意义所在，砍掉它等于把好的一起扔了。
（砍掉以后，论文 2.1 里"前额叶能按住 / 调制一个动作"那句话也就不成立了。）

用户当时给的思路也一并记下："你想让角色保持站立，有两种方法，一是让站立相关的神经元循环
激活，二是有其他神经元持续激活站立相关的神经元。" —— 实测补充一句：**"站姿"这两条其实
都已经在用了**（站姿本身就是首尾接成环的 2 拍循环，全程没灭过），身体倒不是因为站姿熄了，
而是因为返回线把**另一套**动作也点着了。所以修法要落在"别凭空点着另一套"上。

### 7.3 定下来的修法：**运动记忆这一路"只维持、不点火"**

`天生互惠返回线` 现在多了一条规则（`只维持的区 = ("运动记忆",)`）：

> 送回运动记忆的细胞，必须**同时**是这一拍运动记忆真的在跑的那些细胞（没扩散过的原始输入）。

* 效果一：返回线还能**维持**正在做的那套动作 —— 这正是"有其他神经元持续激活站姿相关的
  神经元"那条思路。
* 效果二：它再也不能**凭空点着**一套新动作。想真正挑一个动作，走本能表那条精确的路
  （`前额叶:看着红 → 运动记忆:前进1.2`），以及赫布学习长出来的
  `视觉/听觉/前额叶 → 动作入口`。
* 别的路一条没动：视觉 / 听觉照样"心里看见 / 听见"，运动区照样接前额叶的信号。

实测（`诊断_站立维持.py`，同一张网）：

| 情形 | 改之前 | 改之后 |
|---|---|---|
| 趴着自己站起来（3 秒） | 0.265 → **0.180**（塌） | **0.261 米，一点不歪** |
| 站着眼前一片红（4 秒） | 前进 1.85 米 | 前进 **1.85 米**（一样） |
| 运动记忆里同时亮着哪几个动作 | 站起来/站姿 + 趴下去 + 坐下… | 只有站起来 / 站姿 |

### 7.4 改了哪里

`前额叶区_prefrontal.py`：
* `前额叶神经网络.拼输入` 顺手记下这一拍各路**原样**（没扩散）拼起来的输入 `原始输入`；
* `天生互惠返回线` 多了 `只维持的区 = ("运动记忆",)`，`_按路切开` 里对这一路做一次"与"。

`输入路` 那张表**一个字没改**（七路、扩散半宽、"可回"标记全是原样）。
