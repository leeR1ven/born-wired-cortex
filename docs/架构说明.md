# 架构说明（中文）

本文把整个模型从“神经元”到“脑区”再到“整条闭环”逐层讲清楚。
代码全部用中文命名，阅读时请对照相应文件。

---

## 0. 一句话总览

这是一个**纯神经元连接**的仿脑模型：
外界信号进入各感觉前处理网络 → 变成稀疏的神经元放电 →
汇总到前额叶（思考/联想/专注）→ 前额叶既能把信号**镜像返回**给各感觉区
（想出一个东西），也能把命令发给运动区 → 运动区经**反向网络**展开成肌肉发力 →
身体动作又产生新的感觉输入。整条路上“海马体时间环”提供统一时钟，
记忆区把每一帧的放电模式按时间挂起来，构成可回放的连续记忆。

学习只发生在**连接权重**上；所有“想 / 回忆 / 动作”都只是放电沿连接传播。

## 1. 三个基础构件（所有脑区共用）

### 1.1 特征神经元池（`class 特征神经元池`）
- 每个“特征”用**正、反一对**神经元表示，二者竞争，**恰好激活一个**。
- 信号往池里累积后调用 `更新所有对()`：正信号 ≥ 反信号则正神经元激活，否则反神经元激活，然后清空信号。
- 好处：不需要任何额外规则，“每对一个”和“恰好一半激活”由配对竞争自动保证。
- 常用它表达强弱：一个特征分 `每档对数` 对，亮度/响度/发力 L 档 =
  前 L 对的正神经元亮、后面全反（温度计码），于是 0 ~ N 共 N+1 级全都能表示。

### 1.2 稀疏局部连接神经网络（`class 神经网络`，视觉/听觉/运动/前额叶共用）
- 每层神经元数量 = 输入层神经元数量（输入层就是特征神经元池）。
- 神经元只连上一层**环形邻域**（默认 ±10，首尾相接成环），权重出生时随机取
  `[0, 权重范围)` 后**固定不变**，阈值放电（`加权和 ≥ 阈值` 才亮）。
- 这类网络负责“处理信号”，**不做赫布学习**，权重永远不改，所以速度快、可预测。
- 每个文件顶部集中写着：`层数`、`连接半径`、`权重范围`、`阈值初值`，改这些数字即可换网络形状。

### 1.3 连接表（`权重连接管理_weight_manager.py` 的 `class 连接表`）
- 给**可塑连接**（三个记忆区、前额叶联想区）用的“起点 → {终点: 权重}”表。
- 规则：用一次加 `强化量`；连接条数到 `警戒线`（默认 10 万）后，
  每隔 `衰减间隔` 次维护做整体衰减（全部 × 衰减率 0.9）；
  低于 `消失下限`（0.05）的连接删除。
- 效果：**常用连接维持，少用连接渐渐消失**，连接数不会无限膨胀。

## 2. 各区详解

### 2.1 视觉前处理（`视觉前处理_visual_preprocess.py`）
- 画面先降采样成 24 行 × 16 列马赛克“大像素”，每像素 R/G/B 三通道，
  每通道 `每档对数=10` 对神经元做 0~10 档亮度温度计。
- 特征对数 = 24×16×3×10 = 11520 对（23040 个神经元），三层网络（半径 10）。
- 输出层有个“目标亮数”校准（约 240 个）：给一个微调参数 α，让每帧亮的数量稳定，
  不会因输入强弱导致大面积沉默或癫痫。`解码亮度()` 可从放电读回画面，用于验证。

### 2.2 听觉前处理（`听觉前处理_auditory_preprocess.py`）
- 单声道，频谱被压缩成 1500 根频带，每根 `每档对数=10` 对做 0~10 档响度温度计。
- 特征对数 = 1500×10 = 15000 对（30000 个神经元），三层网络。
- `压缩频谱()` 负责把任意长度的频谱压成固定 1500 根，`解码响度()` 读回用于验证。

### 2.3 运动输出区（`运动输出区_motor_output.py`）
- 肌肉用“发力温度计”：`肌肉数=200`，每块 `每档对数=10` 对 = 0~10 共 11 级发力，
  共 2000 对（4000 个神经元）。
- 大脑对外发命令用**正向网络**（同其它区），命令码亮在最后一层；
  `解码发力()` 把放电读回成每块肌肉 0~1 的发力。
- **反向赫布网络**（`class 反向赫布网络`）解决“命令码 → 肌肉特征”的反向问题：
  - ① 单调只增：命令码亮起的神经元向本帧激活的肌肉特征铺连接，一次学会（`一次学会=True` 权重到 1 即饱和），**学会永不遗忘**；
  - ② 门控省位：每次先自测召回，若已接近真实肌肉就认为这条路已学会，不再新增连接——反复做同类动作不会把记忆铺满淹没；
  - ③ 天生镜像底版：召回时叠一条固定镜像线的微弱投票，让没学过的全新命令码也先给出肌肉的大致位置（不学习、不占内存）。
- `镜像投票()` 是出生固定、逐层沿正向网络回传的镜像返回线，只有反向网络宽度与全局运动网一致时才叠加（闭环仿真里的迷你运动系统用自己的小网络，自动跳过）。

### 2.4 三个记忆区（`视觉记忆区_visual_memory.py` / `听觉记忆区_auditory_memory.py` / `运动记忆区_motor_memory.py`）
- 结构与规则三者一致，只是分别对接视觉/听觉/运动输出层：
  每个记忆区神经元数量**自动等于**对应 `网.输出层数量`，改前处理网络的层宽，
  记忆区数量跟着变，不需要手动同步。
- 每个记忆区维护两个方向：
  - `特征到时间`：哪一帧特征亮了，当时是哪些时间神经元（“这事发生在什么时刻”）；
  - `时间到特征`：某个时刻有哪些特征亮（“那个时刻发生了什么”）。
- `学习(旧时间, 新时间, 新特征)` 按海马索引给的旧/新时间记一帧；
  `回忆(特征模式, 步数, 阈值)` 从当前特征沿时间链逐步回放。

### 2.5 海马体时间区（`海马体时间区_hippocampal_time.py`）
- 一条全系统**共享**的时间线：172.8 万个时间神经元首尾相连成一圈，
  每个占 0.05 秒；外界信息一帧 = 0.1 秒 = 走 2 格；
  绕一整圈 = 1728000×0.05 秒 = 24 小时。
- 一帧连亮 2 个相邻时间神经元，保证帧与帧在时间轴上紧密承接、不漏不串。
- 记忆区以它为准把事件排到时间上，需要“重放”时沿时间顺序把特征再点亮。

### 2.6 前额叶区（`前额叶区_prefrontal.py`）
前额叶是“思考中枢”，分四层结构：

1. **前额叶神经网络**（class 前额叶神经网络）：输入 = **七个区各压过一遍的信号**
   拼起来的一条。输入路 那张表是唯一的一份真相（加区 / 改宽度只改那一处，
   主循环和返回线都自动跟着变）。七路是：
   视觉（第 4 层，压缩完的）/ 听觉 / 本体感觉 / 平衡感觉 / 机身状态 / 运动记忆 / 运动。
   每一路先按**自己那一路**的“扩散半宽”扩成小亮斑（视觉、听觉 10；身体那三路 5；
   运动记忆 10；运动 1 —— 运动那一路只有 160 个细胞，糊大了九个动作就分不出来），
   拼成一条后进局部连接网络（3 层，局部连接半径 10，出生随机权重 0~0.1）。
   隐藏层阈值 0.55、输出层阈值 1.2，所以输出永远是稀疏的一小撮。
   ★ 2026-09-18 补齐：在这之前只有 视觉 + 听觉 + 运动 三路，身体那三路和运动记忆
   只靠出生时撒的随机边碰运气，等于没有设计好的通道（见
   修复_前额叶七路与返回线_20260918.md）。

2. **天生互惠返回线**（class 天生互惠返回线）：把前额叶输出沿出生时固定镜像的连线
   逐层回传，走到输入侧以后**按路切开、谁的路还给谁**；每一路**各按各的峰值**算门限
   （返回保留比例 = 0.4）—— 不这样的话，一路大的（视觉 23040、听觉 30000）会把门限
   顶得很高，一路小的（平衡感觉 120）就永远回不去。出生固定、不学习、永不遗忘。
   ★ **现实盖住想象**（2026-09-18）：一拍里的顺序是
   ② 先算这一拍真进来的外界信号 → ③ 前额叶 → ④ 返回线把“想的”送回各区
   → ⑤ 真信号写上去，盖掉心里想的。眼睛睁着时，心里的红压不过眼前的红；
   身体在报数时，想的姿势压不过真本体感觉（不盖的话会凭空触发平衡反射，
   实测第 126 拍把身体弄倒）。反过来，眼睛闭上、身体不给信号时，想的那些细胞
   就留得住 —— 这就是“心里能看见”。
   ★ **感觉区不设返回线**（2026-09-18）：本体感觉 / 平衡感觉 / 机身状态只进不出 ——
   这三个区一被点亮就直接拉本能反射，"想象出来的歪"会真的去救身体（实测第 126 拍摔倒）。
   视觉 / 听觉 留着（断了就是心盲症、心失语症）。
   ★ **运动记忆这一路"只维持、不点火"**（2026-09-18）：回传的细胞必须是**这一拍运动记忆
   真的在跑的那些细胞**。运动记忆是一个细胞 = 一整套动作，返回线那圈粗信号（连接半径 10）
   会跨过动作边界把邻着的动作点着 —— 实测：趴着自己站起来，第 51 拍拍回了"趴下去"的头一拍，
   身体从 0.265 米沉到 0.180 米；加上这条限制以后 **0.261 米稳住**，走路 1.85 米不变。
   ★ 注意：这一路是**限制**，不是**砍掉** —— 前额叶往运动区发信息的通路必须留着
   （用户 2026-09-18："你把运动记忆/运动也不设返回线，那前额叶怎么发信息给运动区？"）。

3. **动态整体抑制**（皮层连接_cortex_links.py 里的 前额叶自压）：前额叶每多亮一个
   细胞，就给前额叶每个细胞多压那么多电流，保证前额叶始终只亮少数细胞
   （实测 100~150 个）。这是“调参调不到完美时”的兜底，不是架构的一部分
   （用户 2026-09-16 认可保留）。

### 2.7 闭环流程（`闭环流程_closed_loop.py`）
把所有部件（海马索引、记忆区回忆、联想区、专注闸门、天生互惠返回线）
接进**同一条闭环**联测的“使用清单 + 跑分”，只读不改其它文件。
`python 闭环流程_closed_loop.py [帧数]` 可复跑。

### 2.8 姿势互斥：一个身体同一时刻只摆一种姿势（2026-09-18）

运动区是"每块肌肉亮几个细胞就是几档力"，**两套动作同时亮 = 每块肌肉取最大值**（不是平均），
所以"站姿"和"坐下"同时亮，出来的力会把身体往下拽。本能表里因此有两条（二之二）：

    运动记忆:站姿  ->  运动记忆:坐下     -2.5   是
    运动记忆:站姿  ->  运动记忆:趴下去   -2.5   是

- **源**用「运动记忆:站姿」（记住"我在站着"的那段时刻），**不能用「运动:站姿」** ——
  那 60 个肌肉细胞是"12 块肌肉每块低档力"，走路/原地踏步/坐下/趴下去/站起来**每一套
  都把 60 个全用上**（实测 100% 重合）。拿它当源 = 站着压自己，实测走路从 2.19 米掉到 0.01 米。
- **目标**用整套动作的**入口**（运动记忆那条时间线的头一拍）。压肌肉细胞没用：50 拍的动作
  只有第 0 拍用那几个细胞。
- 只写"站着 → 压住坐下/趴下去"这**一个方向**（反方向会让它一辈子起不来）。
- `装()` 两处配套：① 写负数的规则**不展开成多拍**（否则会被当成兴奋连接写进去）；
  ② 源写「运动记忆:某动作」时取**那个动作的全部时刻**（站姿是 2 拍一循环，
  只取起手的话抑制神经元隔一拍才亮一次，被压的入口隔一拍就有缝）。

实测（自己从趴姿站住之后）：抑制神经元每拍亮着、坐下入口每拍被压 **2.50**，
整套"坐下"一次没开（0/240 拍）；同时**两幕该有的行为一点没坏**：趴着自己站起来
0.261 米歪 0°、站着看见红自己走过去 5 秒 2.19 米。详见 修复_姿势互斥_20260918.md。

## 3. 学习与固定 的分工（很关键）

| 组件 | 权重 | 为什么 |
| --- | --- | --- |
| 视觉/听觉/运动/前额叶 正向网络 | 出生固定，永不改 | 它们是“信号处理电路”，必须稳定 |
| 天生互惠返回线 / 镜像投票 | 出生固定，永不改 | 天生返回布线，不学不遗忘 |
| 三个记忆区 | 赫布学习 + 定期衰减 | 记“什么时刻发生了什么” |
| 前额叶联想区 | 赫布学习 + 动态抑制 | 学念头之间的先后关系 |
| 运动反向赫布网络 | 一次学会、单调只增 | 命令→肌肉的路，学会就固定，绝不遗忘 |

## 4. 数字在哪里改（联动关系）

- 各文件顶部“全局创建：数字只在这里改”区块是唯一需要手动填数字的地方。
- `视觉前处理_visual_preprocess.py`：`大像素行数/列数`、`通道数`、`每档对数`、`层数`、`连接半径`。
- `听觉前处理_auditory_preprocess.py`：`频带数`、`每档对数`、`层数`、`连接半径`。
- `运动输出区_motor_output.py`：`肌肉数`、`每档对数`、`层数`、`连接半径`。
- 改完上面任一数字，`网.输出层数量` 自动变；记忆区和前额叶输入宽度
  （`视宽+听宽+运宽`）都从对应文件的 `网` 读取，**自动跟着变，无需手改两处**。
- 前额叶：`层数/半径/扩散宽度/汇合比例/汇合每路线数/汇合阈值倍数/门槛/目标区间` 等
  也在文件顶部集中管理。
- 连接衰减：`权重连接管理_weight_manager.py` 顶部的 `强化量/衰减率/消失下限/警戒线/衰减间隔`。

## 6. 已知边界（诚实声明）

- 无锚点的自由联想会漂移（类似走神）；沿真实闭环的回放不漂移。
- 时间记忆连接随时间增长（1 万帧约 37.5 万条），当前仍实时（~20 ms/帧），
  长期运行依赖连接衰减机制；更大规模需按实际瓶颈决定硬件。
- 闭环仿真目前是二维推进身体；尚未实现双足、自然语言与完整 AGI，
  本项目是“验证架构可行性”的原型。
