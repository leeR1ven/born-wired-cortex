# 第 37 卷　怎么防止"假成功"

> **本卷目标**：给出一套**能揭穿假成功**的手法，每条都配一个**真的揭穿过**的例子。
> 这一卷可以当成"验收清单"用。

---

## 37.0 一句话原理

> **一个行为"出现了"，不等于"它真的会"。**
> 要证明它真的会，必须**改一个条件再看一遍**——
> **改条件之后还成立，才算数。**

### 生活里的比喻

学生答对一道题，不能说明他会——**可能是背的**。
换一道**同类型、不同数**的题，**还会做**，才算会。

---

## 37.1 五个诊断手法（全书通用）

| 手法 | 想排除什么 | 做法 |
|---|---|---|
| **① 把刺激搬走** | 「它真的在看吗」 | 去掉刺激再跑一遍，行为应该明显变 |
| **② 换没见过的位置复考** | 「它认的是东西，还是那个位置」 | 换个没考过的位置 |
| **③ 关掉学习再跑** | 「这个行为是学来的，还是本能就有的」 | 关学习重跑 |
| **④ 只点一次头细胞** | 「这条链自己转不转」 | 只点一次，看它能不能自己走完 |
| **⑤ 关掉/按灭某条通路** | 「这条通路有没有在用」 | 关掉它，成绩应该变差 |

---

## 37.2 硬判据（有具体数字的）

| 判据 | 数 | 含义 |
|---|---|---|
| **「搬走球」的落点差** | **< 0.05 m** | **就是没在看球** |
| **空场响应** | **0.0°** | 没有对象就不动（R6） |
| **清空本能表后的距离** | **每个种子正好 0.184 m** | 说明行为**真的是表给的**（R1） |
| **"红"被别的颜色点亮的比例** | 青屏 **42%** / 蓝屏 **25%** | 说明**没有东西表示"红"**（R4） |

## 37.3 四类典型的"假成功"

### 假成功一：**碰巧**

| 症状 | "球在左边它会左转" |
|---|---|
| 其实 | 没有球的时候，**它也是往左走** |
| 揭穿 | **把球搬走**：落点差 **< 0.05 m** → 它没在看球 |
| 正确的验收 | 有球 / 无球**两次都跑**，比落点 |

### 假成功二：**认的是位置，不是东西**

| 症状 | "它认识那个东西" |
|---|---|
| 其实 | 它只是记住了"**东西出现在屏幕那个位置**" |
| 揭穿 | **换没见过的位置**复考 |
| 正确的验收 | 用**它没考过的位置**（本例：18 个新位置） |

### 假成功三：**看错读数**

| 症状 | "它在追球" |
|---|---|
| 其实 | 你读的是"**细胞亮不亮**"，而不是"**拉不拉得动**"（第 26 卷） |
| 揭穿 | **两个数一起记** |
| 正确的验收 | 同时报"亮没亮"和"拉动了几个" |

### 假成功四：**任务本身没在考你想考的东西**

| 症状 | "它学会了先后依赖" |
|---|---|
| 其实 | **关掉顺序通路，成绩反而更好**（第 34 卷） |
| 揭穿 | **关掉/按灭那条通路** |
| 正确的验收 | 按 34.3 那三层次**分别**设计题目 |

## 37.4 三个"揭穿了自己人"的真实案例

| 案例 | 揭穿了什么 |
|---|---|
| **论文 R16**：眼睛"2.5 m 就能读出距离" | 那是**中心被无界放大**（畸变）**换来的**。诚实采样在 2.5 m 处**和平行没区别** → **撤回** |
| **论文 4.6**："突触后自己亮就压低权重" | 这个配置里**根本没有这一项** → 照实列进"待补" |
| **文字网络**：以为"多点亮几个字能变广" | 实测 **718 / 711 / 708 < 749** → **不成立** |

> **三个案例的共同点**：都是**自己查自己**查出来的。
> **没有人来揭穿，是自己揭穿。**

## 37.5 一条关于"重复"的硬规矩

| 不能说 | 应该说 |
|---|---|
| "重复三次结果一致" | "**三个种子（三只不同的动物）的结果分别是……**" |

> 因为 `--seeds 0,1,2` 是**三只不同的随机动物**——
> 一个种子同时决定**随机脚手架、身体复位、初始朝向**（第 36 卷）。

| 产出 | 要点 |
|---|---|
| **一套"改条件复跑"的脚本** | 有刺激 / 无刺激、旧位置 / 新位置、开学习 / 关学习 |

| **一本撤回登记簿** | 见附录 A |

## 37.8 怎么验证（验证你自己有没有在自欺）

| 你该问的自己 | 为什么 |
|---|---|
| **如果不给它刺激，它会不会也这样？** | 排除碰巧 |
| **如果换一个位置，它还行不行？** | 排除"认位置" |
| **这个成绩是哪个脚本哪个日志的？** | 排除"凭空来的数字" |
| **我有没有在看"亮不亮"就下结论？** | 排除读错读数 |
| **这道题真的能区分好坏吗？** | 排除废题 |
| **我这句话有没有被数据推翻过？** | 排除悄悄改口 |

---

## 37.9 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **只看"有没有出现"** | 行为出现了就上报 | 必须**改条件再跑** |
| **不做"无刺激"对照** | 把碰巧当能力 | 落点差 < 0.05 m 就是没在看球 |
| **只考考过的位置** | 以为通用 | **换没见过的位置** |
| **读"亮不亮"当"拉不拉得动"** | 以为它被激活了就是"在想" | 两个数**都要** |
| **拿草稿/未采用的目录当成果** | 引用未采用整合 | 明确标注"未采用" |
| **说"重复三次一致"** | 听上去严谨 | 那是**三只不同的动物** |
| **被推翻的说法悄悄改掉** | 读者对不上 | **明确写"撤回"** |
| **数字没有脚本和日志** | 追不出来 | 每个数字配**脚本名 + 日志名** |

## 37.10 自检三问

1. 为什么"把球搬走，落点差 < 0.05 m"就能判定"它没在看球"？请说清这个 0.05 m 在比什么。
2. 论文 R16（"2.5 m 就能读距离"）被撤回——**它错在哪**？
   如果你当时在场，你会设计**哪一个**实验早早发现它？
3. 有人说"我们跑了三次，结果都很稳"。这句话有什么问题？应该怎么改？
