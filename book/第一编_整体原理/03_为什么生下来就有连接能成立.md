# 第 3 卷　为什么"生下来就有连接"能成立

> **本卷目标**：回答第 1 卷的问题一——**一个网络凭什么一开始就是有序的**。
> 答案不是"初始化得好"，而是"**它一出生就有一张写好的连接表**"。
>
> 本卷要讲清楚四件事：这张表**长什么样**、**为什么模糊反而对**、
> **"写"和"学"的分界线在哪**、以及**为什么不能从沉默里学**。

---

## 3.0 一句话原理

> **本能不是一段代码，是这张网出生时的样子。**
> 它不是"一出生就会几个动作"那么简单——**它是一整张连接表**，
> 决定了哪块细胞跟哪块细胞连着、连多粗、哪些永远不许改。

### 生活里的比喻

把大脑想成一栋**刚交房的楼**：

- 楼里的**水电管路**（连接）在交房之前就已经铺好了：哪根管通哪一层，是施工图定的。
- 你搬进去之后能干的事，**取决于管子铺到哪**。管子没铺到的地方，你放个水龙头也不出水。
- 你住进去以后会改一些东西——但改的是**开关开合、管子流量**，
  **不是把楼重新盖一遍**。

**施工图 = 本能表。楼 = 皮层。装修 = 学习。**

---

## 3.1 这张初始连接网长什么样：**模糊，但方向大致对**

### 它不是一个精确的线路图

本能连接不是一个"看到红球 → 第 3 号细胞 → 第 7 号肌肉"这样精确的对应。
它是**一大片权重很小、随机、但方向大致对**的连接。

| 性质 | 具体是什么 |
|---|---|
| **权重小** | 单根连接很弱；要**一整块细胞一起亮**，才能把目标推动 |
| **随机** | 具体哪根连到哪个细胞，是随机撒的（但**固定种子**，见 3.4） |
| **方向大致对** | "前面有红的"这一类信号，总体上确实是往"往前走"那一边推的 |

### 论文里有两个说法，讲的都是这件事

| 说法 | 出自 | 说人话 |
|---|---|---|
| **本能是这张表的初始状态** | P4 | 天生那部分**不是一个单独的模块**，也不是代码里的一堆 `if`；它就是皮层**出生时带的连接**，包括区内和区之间的 |
| **这张表不是某一只动物一生的记录** | P4 | 它是**很多条命写出来的地图混在一起、糊掉一层**的样子 |

### 为什么"糊掉一层"反而是好事

因为糊掉之后，它**方向还对，细节全错**。这带来两个好处：

1. **能起步**："大致朝那个方向"就够开始跑了，不需要一开始就精确。
2. **有容错**：论文专门有一节（R7）测"把先天接线**再糊一点**会怎样"——
   结果是**行为还在，只是带上一个系统性的偏差**。这说明这套东西**不脆弱**。

## 3.2 一出生就分成两类：**可塑的**和**几乎固化的**

这是全书最容易被忽略、又最要命的一条。

> **"学"不是把所有连接都重来一遍。** 一出生，连接就分成两种命运。

| 类别 | 比例 | 一辈子会怎样 | 举例 |
|---|---|---|---|
| **高度可塑** | 大部分 | 会被学习规则慢慢改 | 视觉 → 前额叶、前额叶 → 各区 |
| **几乎固化（冻结）** | **约 30%** | 出生权重是多少，几乎就一直是那个数；学习**改不动它** | 平衡反射这一类"一辈子不能变"的东西 |

### "冻结"是怎么表达的

**不是代码里的特例，是连接表上的一行标记。**

| 做法 | 说人话 |
|---|---|
| 出生连接里有约 **30%** 带"冻结"标记 | 这几根**免于学习** |
| 本能表里写下的那些突触，可以标成冻结 | 这就是"**这一根不许动**"的表达方式 |
| 运动 / 运动记忆 / 前庭 / 本体感觉 / 身体状态 这五个区 | 它们的可塑倍率是 **0.02**（别的区大得多） |

> **"平衡反射一辈子几乎不变"，就是那一个数字 0.02 表达的**——
> 不是代码里写了一段"如果是在做平衡，就不要学"。

## 3.3 "写"和"学"的分界线在哪

这是本卷最关键的一节。很多人第一次听到"生下来就有连接"会问：
**那这些连接是谁定的？是不是偷偷训练过了？**

必须把话说透：

### 分界线

| | 写（本能） | 学（可塑性） |
|---|---|---|
| **什么时候发生** | **出生之前**，一次性 | **出生之后**，一直在进行 |
| **谁在动手** | 写表的人 | 连接自己（那条局部规则） |
| **看不看得懂** | 看得懂：表里就是一行行字 | 看不懂：几百万根连接各自微微变了 |
| **能不能解释** | 能：这一行就是我写的 | 不能：只有结果，没有理由 |

### 三条必须知道的实话

**第一，本能连接是"写"出来的，不是"学"出来的。**

> 论文原话大意：**写表的人就是"基因组"**。
> 换句话说，"本能"这个词背后的东西，就是**一个人（或一段程序）事先把连接写好**。

**第二，动作库那批规则，是从另训的强化学习策略里"蒸馏"出来的。**

> 这是**出生之前的监督**，**不是活着时候的监督**。区别极大：
> - 出生前监督：写表的时候借用了一个别的工具，**出生之后系统里没有它**；
> - 活着时候监督：系统运行中还一直有人在打分——**那就不叫"不要奖励函数"了**。

**第三，"模糊化"只是对**人**的描述，机器上不需要"继承"这一步。**

> 你说"这只动物的本能是从上一代继承来的、继承的时候糊了一点"——
> 这是**讲给人听的**。**在代码里你不需要真的去继承、再去糊**；
> 你直接把要的那张初始连接表**写在这个模型上**就行。
> 本能连接就是这张网的初始状态，**不存在"两张网"**。

### 一张图说清这条分界线

```
   出生之前（离线，写）                出生之后（在线，学）
   ─────────────────────              ─────────────────────
   写表的人 / 蒸馏来源                 只有：那条局部规则
        │                                    │
        │  写出：                            │  改的是：
        │  · 出生连接表（谁连谁、多粗）        │  · 那些**没被冻结**的连接
        │  · 冻结标记（约 30%）              │  · 权重一点点变
        │  · 本能表（一行条反应）            │
        ▼                                    ▼
   ┌──────────────────────────────────────────────────┐
   │              同一张网（皮层）                      │
   │   出生时的样子 = 初始状态                          │
   │   出生后的样子 = 初始状态 + 它自己活出来的改动       │
   └──────────────────────────────────────────────────┘
```

## 3.4 本能连接就是这张网的**初始状态**

### 这句话为什么重要

因为它否掉了一个很常见的错误做法：**"先建两套东西，一套本能一套学习，再想办法把它们拼起来。"**

**不需要拼。它们是同一套东西。**

| 错误做法 | 正确做法 |
|---|---|
| 先有一个"本能模块"，再有一个"学习模块"，两个模块之间做接口 | 只有一张网。**本能 = 它的初始状态**；学习 = 在这张网上继续改 |
| 本能写在一张表里，学习写在另一张表里 | **本能表只是"生成初始状态"的原料**；生成完，大家在同一张网里 |
| 出生后"继承"一遍再"模糊化" | 直接把初始状态写成你要的样子 |

### 一条工程上的硬要求：**权重必须固定种子**

这一点不是可选项，是必须：

| 要求 | 为什么 |
|---|---|
| 出生权重用**固定种子**生成 | 不然两次跑出来的网**不是同一张网** |
| 后果 | 你写死的本能**对不上**了：表里说"这一块连到那一块"，可这次的随机撒点根本没撒到那儿 |
| 实测 | 两次跑，权重的哈希值**完全一致** |

> 记一句话：**不同种子 = 不同的大脑**（原文 *different brains*）。
> 这句话在第六编讲演化的时候还会再出现一次——演化的本质就是**换种子**。

## 3.5 为什么"从沉默里学"不行

这是本卷要回答的**根本问题**。

### 沉默的网络长什么样

假设我们什么都不写，给一张随机初始化的网，然后指望它自己长出来：

| 会发生什么 | 为什么 |
|---|---|
| 大部分细胞**永远不亮** | 收到的电流都在阈值以下 |
| 少数细胞**乱亮** | 随机撒的权重偶尔凑够一次阈值，但和世界没关系 |
| 学习规则**无事可做** | 它只认"一起亮"。世界的信息和细胞的活动**没有对应关系**，一起亮的是噪声 |
| 结果 | **越学越乱**，因为你把噪声当成规律记下来了 |

### 论文的论证：不是一个技术判断，是一个生存判断

> **P5：网络不能从沉默开始。**
>
> 原文的理由很硬——一个必须从"什么都不知道"的状态出发、去摸索
> 怎么**站着**、怎么**呼吸**、怎么**稳住视线**的生物，**活不过摸索阶段**。
>
> 换句话说：**演化不会给你足够的时间去从零开始试。**
> 所以"出生时有序"不是设计偏好，是**唯一能活下来的方案**。

### 正确的顺序

```
   错：  随机初始化 → 学习 → 有序

   对：  天生就有序 → 学习 → 内容
```

| 天生就有的 | 学习负责的 |
|---|---|
| 行动的最初**套路**（怎么站、怎么走、怎么看） | 把**内容**写进去（"这个声音"后面跟着"走路"） |
| 连接的**骨架**（谁大致连谁） | 骨架上的**粗细** |

> 论文里对应的一句话：**天生接线提供的是一个"已经有序的起点剧目"；
> 经验之后负责往里写内容。**

## 3.6 怎么搭（这一步具体做什么）

对照第 0 卷的十一个零件，本卷对应的是**零件 2（出生连接表）**和**零件 3（本能表）**。

| 你要产出什么 | 长什么样 | 用在哪 |
|---|---|---|
| 一张**出生连接表** | 每一行：源细胞、目标细胞、权重、是否冻结 | 生成网络时按它接线 |
| 一张**本能表** | 一行一条反应，纯文本，人看得懂 | 加载时**展开成**连接，写进上面那张表 |
| 一个**固定种子** | 一个整数 | 生成随机背景连接用 |

**三条纪律**（第六编会展开，但这里先立住）：

1. 本能表是**数据**，不是代码。表里一行字，展开成一堆连接，**没有任何一句 `if`**。
2. 冻结标记是**表上的一列**，不是代码里的特例。
3. 生成顺序：先按种子铺背景随机连接 → 再把本能表**叠加**上去（本能表的那部分优先级更高）。

> **不能怎么做**（这是一个真实的失败）：**不能用"编号"来写本能**。
> 有人试过"满屏红的时候，让输入层编号某某区间的细胞亮"——
> 实测那个区间真的亮到的比例是 **6.1%**，而随机碰运气是 **6.7%**。
> **等于没有**。名字不能靠编号猜，得靠**标定**（第 12 卷、第 24 卷）。

## 3.7 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 固定种子真的产出同一张网吗 | 跑两次，比权重哈希——两次应完全一致 |
| 冻结的连接真的不会被改吗 | 让模型走一段，去查那些带冻结标记的连接权重有没有变 |
| 本能表真的是数据不是代码吗 | 打开 `model/本能表.txt` 看看——它就是一行行中文，没有 `if` |
| "本能是初始状态"是真的吗 | 查代码：本能表和随机背景连接是不是写进了**同一张边表** |

具体脚本和日志名在附录 B（每个数字配哪个脚本 + 哪份日志）。

## 3.8 常见坑

| 坑 | 症状 | 为什么会掉进去 | 正确做法 |
|---|---|---|---|
| **想"先随机会学出来"** | 觉得反正有学习规则，初始随便给 | 把 P5 当成一句口号 | **一开始就必须有序**。这是生存条件，不是优化项 |
| **把本能做成一个单独的模块** | 建了"本能模块"和"学习模块"，再写接口 | 直觉上"两件事"就该有两个模块 | **只有一张网**。本能是它的初始状态（3.4） |
| **本能写成 `if`** | 表里写着"如果前面有红的，就走" | 这样写最直观 | 本能表是**数据**。它只描述"哪块细胞连到哪块细胞、多粗" |
| **用编号代替标定** | 想让"红色"等于某一段编号 | 觉得编号可控 | 实测无效（6.1% vs 随机 6.7%）。名字必须**标定**出来 |
| **忘记固定种子** | 每次跑出来的模型行为都不一样，本能对不上 | 忘了随机数的事 | 出生权重**必须固定种子** |
| **冻结靠代码特判** | 写"如果是平衡反射就不学" | 图省事 | 冻结是**连接表上的一列**，不是代码分支 |
| **把"模糊化"当成必须的一步** | 真的去写一个"继承+加噪声"的流程 | 把讲给人的比喻当成工程步骤 | 那是**对人的描述**。代码里直接写你要的初始状态 |

## 3.9 自检三问

1. 有人问你："这些本能连接，是不是偷偷训练出来的？" 你怎么回答？
   （要点两个：**是"写"的**；**写表的人就是基因组**；还要说清"出生前监督"和"活着时候监督"的区别）
2. "本能是这张网的初始状态"——如果这句话成立，那么下面这件事**应该**是怎样的：
   模型活了三天以后，它的本能去哪里了？
   （提示：不是"被存起来了"，也不是"被删掉了"）
3. 为什么"约 30% 冻结"这件事**必须**存在？如果一根都不冻结，
   你觉得最先坏掉的是哪个能力？坏成什么样？
