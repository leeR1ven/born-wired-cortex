# 第 1 卷　这套方法在解决什么问题

> **本卷目标**：用一页纸说清楚——老办法要哪三样东西，我们把这三样拿掉以后，
> 剩下的三个"不可能"分别由什么来回答；最后给你一张全书总图。
>
> **本卷不放精确数字**。数字在第三编（规则）和第四编（精确规则）里，一条都不会少。

---

## 1.0 一句话原理

> **老办法靠三根柱子撑着：奖励函数（告诉它什么算好）、反向传播（把误差传回去改每一层）、
> 目标函数（定义什么叫对）。这套方法把三根柱子**全部抽掉**，
> 只留下三样东西：**出生就写好的连接**、**一条局部规则**、**一个闭环的身体**。**
>
> 抽掉柱子以后，它就必须回答三个问题——**不动怎么会有序**、**没奖励怎么学**、
> **不训练怎么会新本事**。这一卷就是回答这三个问题。

### 生活里的比喻

**老办法像考试**：做题 → 对答案 → 按错的地方回头把每一道题的解法改一遍。
它必须**先知道哪错了**才动得了。

**这套办法像学骑车**：你骑、你晃、你要摔，脚就自己往地上撑一下——
**没有任何人告诉你"刚才那一下是对的"**。但你踩过的那些路，**自己会变宽**。

> 区别就在这一句：**考试要整张卷子在手；骑车只要"刚才那两下"在场。**

## 1.1 老办法要三样东西，我们一样都不要

今天说"让一个网络学会做一件事"，默认要准备三样东西：

| 老办法要的 | 它干什么 | 这套方法 |
|---|---|---|
| **奖励函数** | 给行为打分："做得好 +1，做得差 −1" | **没有** |
| **反向传播** | 把"这次错在哪"从输出层倒着摊回每一层，改它们的权重 | **没有** |
| **目标函数** | 写清楚"什么叫做得好"，训练就是让这个数变小 | **没有** |

这三样是一套的：有目标函数，才有分数；有分数，才有误差；有误差，才有往回传的东西。
所以"不要奖励函数"不是省一步，是**连着抽掉三根柱子**。

抽掉之后，一个正常的深度学习工程师会说：那它拿什么学？

**这就是这套方法唯一要回答的问题。**

---

## 1.2 抽掉三根柱子以后，必须回答的三个问题

### 问题一：一个什么都不动的网络，凭什么会有序？

随机初始化的网络是**一片静默**：每个细胞收到的电流都差不多，谁都够不着阈值，
整张表要么全不动、要么一起乱动。有序不会自己长出来。

> 论文用一句话说这件事：**网络不能从沉默开始**（P5，*A network cannot start from silence*）。
> 原文的理由很硬：一个必须从"什么都不知道"的状态出发、去摸索怎么站着、怎么呼吸、
> 怎么稳住视线的生物，**活不过摸索阶段**。

### 问题二：没有奖励，它拿什么学？

如果没有任何东西告诉它"对/错"，学习规则就只剩下"**什么和什么一起发生了**"。
这套方法的答案是：**这就够了，前提是网里已经有序**。

> 对应论文 P6：一个"奖励样"的细胞群（不叫裁判，只叫**许可证**）可以存在，
> 但它不计算误差、不知道目标；它只决定"**这一刻算数，写下来**"。

### 问题三：不重新训练，怎么会长出新本事？

老办法要长新本事，就得重训——而且重训容易把老本事覆盖掉。
这套方法要的是：**老本事一点不动，新本事直接加上去**。

> 对应论文 P3（前额叶反复压缩、且通路是**互惠**的）和 P9
> （两个脑子各学一件事，**加起来**变成一个两件事都会的脑子）。

## 1.3 一句话答案

> **连接是生下来就写好的；这辈子只有一条学习规则；身体在闭环里。**

拆成三句话：

| 三句话 | 它的意思 | 它回答上面哪个问题 |
|---|---|---|
| **① 连接生下来就写好** | 大部分连接、权重、方向，在"出生"那一刻已经定了，是**写**出来的，不是学出来的 | 问题一：一开始就有序 |
| **② 只有一条学习规则** | 上一拍一起亮的两个细胞，它们之间的连接强一点；不一起亮就慢一点。**没有奖励、没有误差、没有目标** | 问题二：不用奖励也能学 |
| **③ 身体在闭环里** | 感觉进细胞 → 细胞驱动肌肉 → 肌肉改变世界 → 世界又改变感觉，一直转 | 问题三：新本事来自"活着的时候写进空连接里" |

这三句话是全书的骨架。后面每一卷，都是在把这三句话里的某一句**讲清楚为什么成立**。

## 1.4 全书总图：一拍里信号怎么走一圈

先看这张图。**整本书就是把这几个框，一个一个拆开讲。**

```
                        ┌──────────────────────────┐
                        │          世  界           │
                        │ 光 / 声 / 关节角 / 皮肤   │
                        └────────────┬─────────────┘
                                     │
                    ④ 世界被改变      │      ① 感觉进来
                                     ▼
        ┌─────────────────────────────────────────────────┐
        │ 感觉前处理：多层局部网络 → 压缩成稀疏放电         │
        │ （视觉 / 听觉 / 本体感觉 / 前庭 / 身体状态）       │
        └────────────────────────┬────────────────────────┘
                                 │  ② 汇合
                                 ▼
        ┌─────────────────────────────────────────────────┐
        │ 前额叶（思考 / 联想 / 专注）                      │
        │ 出口一：天生互惠返回线 → 把信号镜像回送各感觉区    │
        │         （"想出一个画面"就是这条线）              │
        │ 出口二：发给运动区                               │
        └────────────────────────┬────────────────────────┘
                                 │  ③ 运动
                                 ▼
        ┌─────────────────────────────────────────────────┐
        │ 运动区 160 个细胞 → 16 个肌肉组 → 身体            │
        └────────────────────────┬────────────────────────┘
                                 │
                                 └─────────►（回到世界）

        另外两样东西，全程挂在旁边：
        · 抑制池 8,000 个细胞：负责"压住"，让网不会一起亮
        · 时间环 + 三个记忆区：全系统唯一的时钟，按时刻把每一帧挂起来
```

图里有四件事要特别点出来，它们都是这套方法**跟老办法不一样**的地方：

| 图上的地方 | 老办法怎么想 | 这套怎么做 |
|---|---|---|
| 感觉前处理后面那一段 | "最后一层的输出就是答案" | **最后一层不是答案，是一根总线**（P1）。答案在读的人脑子里，不在这一层 |
| 前额叶 | 需要一个"推理模块" | **没有单独的推理步骤**（P2）：一个念头就是一个细胞群亮着，下一个细胞群完全由当前权重和此刻到达胞体的电流决定 |
| 运动区 | 需要一个"读出层"把隐藏状态翻译成动作 | **没有读出层**：运动命令就是那 160 个细胞此刻亮着的个数 |
| 整张网 | 训练时是一个东西，部署时是另一个东西 | **没有训练/部署的区别**：它一直在跑，学习只是连接在慢慢变 |

## 1.5 这套方法能搬到别的世界（面 C）

这张总图里，只有两处和"世界长什么样"有关：**最上面的感觉接口** 和 **最下面的运动接口**。
中间那一大坨（前处理、前额叶、抑制、记忆、一条学习规则）**跟身体长什么样没关系**。

所以同一套方法可以装在不同的世界里：

| 世界 | 感觉接口给什么 | 运动接口拿什么 |
|---|---|---|
| 最小小球（第 31 卷） | 屏幕上小球的位置 | 往某个方向推一把 |
| 机器狗（第 32 卷） | 1,920×1,080 画面 + 关节角 + 耳朵 | 16 个肌肉组的目标角度 |
| 文字网络（第 33 卷） | 一个词 | 下一个词 |
| 色标导航与人形（第 34 卷） | 色块位置 | 关节角度 |

**这就是这本书叫"通用教程"的原因**：它教的不是"怎么做一个机器狗大脑"，
而是"怎么造一个连接生下来就写好、只需要一条局部规则的大脑"——身体随便换。

## 1.6 怎么搭（本卷不写代码，只给路线）

读完这一卷，你不需要下载任何东西。你只需要能回答一个问题：

> 我要造的这东西，**它学的是什么？**

答案必须只有两个字：**连接**。如果你脑子里冒出来的答案是"参数""权重矩阵""策略网络"，
那说明你还站在老办法那边——回去看 1.3 的三句话。

## 1.7 常见坑

| 坑 | 症状 | 为什么会掉进去 |
|---|---|---|
| **把"不要奖励函数"理解成"随便给个分数就行"** | 你写了一个打分函数，只是不叫它 loss | 名字换了，机制没换。只要有一个东西在算"这次做得好不好"，你就回到老办法了 |
| **以为"没有反向传播"等于"完全不学"** | 觉得这套东西只能靠手写死 | 学习只有一条规则：**一起亮就强一点**。它不认对错，但它真的在改连接 |
| **以为"最后一层"是答案层** | 一直盯着前处理网络的输出找"识别结果" | 前处理是**压缩机**，它的输出是总线（P1）。**每个中间层都可能出特征细胞**，不是只有输入层（第 6 卷、第 18 卷专门讲） |
| **以为需要一个"推理模块"** | 到处找 `think()` 这种函数 | 没有单独的推理步骤（P2）。思考就是放电沿连接往下传 |
| **把多巴胺当裁判** | 说"多巴胺告诉它做得好" | 多巴胺**不说好坏**，它只说"**这一刻算数，写下来**"。对错它不管 |

## 1.8 自检三问

1. 老办法的三样东西里，**哪一样最难戒掉**？如果明天你要给别人讲这套方法，
   你打算先讲哪一样？（提示：多数人最先想要的是"给个分数"）
2. 用 1.4 那张图，不看文字，自己说一遍：一拍里信号从哪进、经过哪几个框、从哪出去、怎么回到起点。
   卡在哪一格，就是下一卷要重点看的。
3. 如果有人说"这东西就是没有训练的神经网络"，你打算用哪一句话反驳他？
   （提示：不是"它其实也训练"，而是"**它一开始就不是沉默的**"。）
