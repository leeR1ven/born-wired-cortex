# 第 0 卷　读这本书之前

> **本卷目标**：让你在写第一行代码之前，就知道自己要造什么、有哪几条不能碰的规矩、
> 以及怎么判断自己真的做对了。

---

## 0.0 一句话：我们要造什么

我们要造一个**大脑**。它长这样：

- 里面有十几万到几十万个**细胞**，每个细胞只有"亮"和"不亮"两种状态。
- 细胞之间用**连接**连起来，每根连接有个**权重**（粗细）。
- **大部分连接在"出生"的时候就已经写好了**——不是学出来的。
- 它这辈子只会用**一条学习规则**：上一拍一起亮的两个细胞，它们之间的连接粗一点。
- 它接在一个**身体**上：身体给它感觉，它给身体肌肉命令，身体动完又有新的感觉。

不需要奖励函数，不需要反向传播，不需要目标函数，也不需要"输入 token / 输出 token"。

**听起来不可能？** 本卷先把规矩立好，第 1 卷讲为什么这件事值得试，第 2 卷讲它整体怎么跑。

## 0.1 三个必须先接受的约定

这三条是全书的地基。你可以在心里反对，但读下去之前先接受它们，
不然很多设计你会觉得"为什么不用更聪明的办法"。

### 约定一：判断只发生在细胞和连接上

**不许代码替神经元做决定。**

反面例子（都是真实踩过的坑）：

```
if 看到红球:      # ← 这就是"代码替神经元做决定"
    往前走()
```

正确的做法是：红球亮了一批细胞 → 这批细胞通过连接去推运动细胞 → 运动细胞自己亮起来 → 肌肉动。
**没有任何一行代码知道"红球"这个词。**

这一条为什么重要：只要你写了一个 `if`，行为就不再是"从连接里长出来的"，
你也就永远说不清这个行为到底是网络算出来的、还是你写死的。

> 出处：用户 2026-09-14 原话——"一切都是神经元决定的，不要代码自动化。"
> 记在 `docs/架构规格_以你的描述为准_20260914.md` 第七节。

### 约定二：不许手动调连接

想让它学一个新本事，**不能去手改某几根连接**。主路只有一条：

> **随机生成一批模型 → 让它们考试 → 留下考得好的 → 生下一代。**

手调出来的一次性结果，既复现不了，也长不大。

### 约定三：没有奖励函数、没有反向传播

这条最反直觉。**记住一句话就够了**：
将来你会看到"多巴胺"，但多巴胺**不是裁判**——它不说"做得好"，
它只说"**这一刻算数，写下来**"。对错它不管。

（第 1 卷和第 4 卷会把这件事讲透。）

## 0.2 十一个零件（全书总清单）

把这十一个零件凑齐，大脑就能跑。**身体长什么样不影响这张清单。**

| # | 零件 | 一句话它是什么 | 没有它会坏在哪 | 书里 |
|---|---|---|---|---|
| 1 | 细胞表 | 一大排只有"亮/不亮"两种状态的细胞，按脑区分成几段 | 没有零件可用 | 第 5 卷 |
| 2 | 出生连接表 | 谁连谁、多大权重，出生就写好 | 一开始就是一片静默，什么都动不了 | 第 5 卷 |
| 3 | 本能表 | 一出生就会的那些反应（看见红→往前走；站不稳→站直） | 出生时什么都不会做，学也没得学 | 第 12 卷 |
| 4 | 感觉接口 | 把世界变成细胞亮度（像素 / 声音 / 关节角度 / 文字都一样） | 大脑看不到外面 | 第 15 卷 |
| 5 | 运动接口 | 把细胞亮度变成肌肉命令 | 大脑动不了 | 第 15 卷 |
| 6 | 学习规则 + 上下限与预算 | 唯一的规则；权重有上限、有下限、有资源预算 | 要么不会学，要么学疯 | 第 8 卷 |
| 7 | 抑制细胞 | 专门负责"压住"的另一种细胞 | 整张网会一起亮（癫痫） | 第 5 卷 |
| 8 | 相反细胞 | 每种感觉通道成一对，连"什么都没有"也有一对 | 模型不知道"外面是空的" | 第 9 卷 |
| 9 | 时间与记忆 | 唯一时钟 + 按时刻挂起来的记忆 | 分不清先后，记不住序列 | 第 10 卷 |
| 10 | 闭环 | 感觉→细胞→肌肉→世界→感觉，转起来 | 只是一个静态网络，不是生物 | 第 2 卷 |
| 11 | 演化 | 随机生成 + 题库考试 + 筛选 + 融合 | 只能靠人调参数 | 第 36 卷 |

## 0.3 名词表（全书统一，一个词只有一个意思）

| 词 | 意思 | 常见误解 |
|---|---|---|
| **细胞** | 一个只有亮/不亮的单元 | 不是"神经元模型"，没有膜电位方程 |
| **一拍** | 一次全局更新，**20 毫秒** | 不是"一次推理" |
| **连接 / 突触** | 从 A 细胞到 B 细胞的一根线，带权重 | 权重**永远是正的**（见下一行） |
| **抑制细胞** | 一种专门的细胞，亮了就把目标压到阈值以下 | **不是**负权重。网里没有一根负权重 |
| **权重** | 连接的粗细 | 不是"参数"，是结构本身 |
| **脑区** | 细胞表里的一段地址区间 | 不是独立的模块、没有单独的代码路径 |
| **皮层** | 每个区里**面向大脑内部的那一层** | 感觉区和前额叶的皮层是输出层，运动区的皮层是**输入层**（方向相反） |
| **本能表** | 一张纯文本的表，一行一条反应 | 不是代码，是数据；**写表的人就是"基因组"** |
| **力度** | 源那一整块细胞亮起来时，每个目标细胞一共收到多少电流 | 不是"一根连接的粗细"，会自动均分到每根连接上 |
| **特征神经元** | 表示某个特征的细胞 | **每一层都可能出特征细胞**，不是只有输入层 |
| **时间环** | 绕成一圈的时间细胞，是全系统唯一时钟 | 不是"计时器"，走一格就是 0.05 秒 |
| **闭环** | 感觉→细胞→肌肉→世界→感觉 | 不是"反馈控制"，没有目标函数 |
| **种子** | 生成随机背景连接用的随机数起点 | **不同种子 = 不同的大脑** |

## 0.4 环境怎么装

### 本机（Windows）

这一套有两个 Python 环境，别搞混：

| 用途 | 位置 | 说明 |
|---|---|---|
| 论文那一套（老架构，`model/` + `docs/`） | 系统 Python | 用来跑 `核对_论文数字.py` 这类复现脚本 |
| 新引擎（`engine_v2/`） | `engine_v2/.venv` | 训练、演化、看模型，都在这里 |

新引擎的第三方包钉在 `engine_v2/requirements.txt`：

```
numpy==2.4.6
mujoco==3.13.0
scipy==1.17.1
numba==0.65.1
pillow==12.2.0
torch==2.7.1
```

装的时候只装这一份，`torch` 按机器选：

```powershell
# 显卡机
pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118
# 纯 CPU 机器
pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cpu
```

### 云服务器

云上只有两条要命的规矩：

1. **必须设 `MUJOCO_GL=egl`。** 不设的话 MuJoCo 会掉到 Mesa 软件光栅上，**慢 177 倍**。
2. **不要按 `nproc` 开进程。** 容器里 `nproc` 报的是**宿主机**的核数（见过报 96），
   实际配额可能只有 24。按 `nproc` 开会把机器拖死。

### 怎么知道装对了

跑一次论文数字核对（几秒钟）：

```powershell
cd "F:\born-wired-cortex\model"
& $py -X utf8 核对_论文数字.py
```

看到 `对上 52 条，对不上 0 条 —— 全部一致 ✓` 就说明环境是对的。
想更硬，加 `重跑` 当场重跑一遍 R1（约 6 分钟），看新算出来的数和论文里是不是一样。

## 0.5 怎么判断"我真的做对了"

这套东西有个特点：**它太容易骗自己了**。模型动了，不代表它在看；眼睛对着球，不代表它在盯。

所以从第一天起就要用**四层证据**，一层比一层硬：

| 层 | 做法 | 你现在能做吗 |
|---|---|---|
| ① 论文自带索引 | 每个数字后面写着"跑哪个脚本、看哪份日志" | 能 |
| ② 自动核对 | `核对_论文数字.py` 自己翻日志、抠数字和论文比，52 条全过才算数 | 能 |
| ③ 当场重跑 | `核对_论文数字.py 重跑`，重新跑一遍，看数一样不一样 | 能 |
| ④ 自己看 | 双击 `回放_大脑_A.html`，让模型自己开一遍机器人 | 能 |

第 ④ 层最重要：**你不需要相信任何人的话，你自己眼睛看。**

还有一条自查规矩，后面每一卷都会用到：

> **对照实验**。说"它是因为看见红球才走的"之前，必须先跑一遍"把红球搬走"，
> 看它的行为有没有变。**没变就说明它根本没在看球**，前面那个"成功"是碰巧。
