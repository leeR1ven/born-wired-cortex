# 附录 A　名词对照表 + 撤回记录

> **本附录有两个用途**：
> 1. **名词对照**：**别人造的词 → 它实际是什么**。同一个东西只许用一个词。
> 2. **撤回记录**：凡是被数据推翻的说法，**一条都不能少**，**一条都不许悄悄改**。

---

## A.1 用词纪律（先立规矩）

| 规矩 | 说明 |
|---|---|
| 一个概念**只用一个词** | 第一次出现给代码名 / 英文名 |
| **不许乱造词** | 自己发明的比喻词（下面的 A.3 有实例）**不许写进文档** |
| 用错的词要**登记** | 不是删掉了事，而是写清"**这个词实际指什么**" |

---

## A.1.1 同一件东西的几种叫法（**统一口径**）

> 全书**一个概念只用一个词**。下面是"正式叫法"和"书里偶尔也出现过"的对齐表。
> **写新内容时用左边那一列。**

| 统一叫（正式） | 也出现过 | 备注 |
|---|---|---|
| **抑制细胞** | 抑制神经元 | 它是**一个独立的区**（8,000 个），不是"负的权重" |
| **相反神经元** | 相反细胞 | 第 9 / 21 卷的正式名字（每种通道配一对） |
| **特征神经元** | 特征细胞 | 第 6 / 18 卷的正式名字（正 / 反一对） |
| **天生互惠返回线** | 返回线、互惠线 | **第一次出现写全**，后面一律简称"**返回线**" |
| **记忆区** | 记忆区域 | 视觉 / 听觉 / 运动，三块结构相同 |
| **时间环** | 时间细胞环、海马体时间环 | 正式名就是"**时间环**"；"海马体"只在讲渊源时提一次 |
| **本能表** | 本能连接表 | "本能**表**"是那张纯文本文件；"本能**连接**"是它展开后长在线上的东西 |
| **区** | 脑区、皮层区 | 它不是房间，是**地址区间**（第 5 卷） |

> **规矩**：新写的内容一律用左边的叫法。右边那些**不删**——因为老文档、日志、代码里可能就是那么写的，
> 读的时候要知道它们是同一件东西。

## A.2 别人造的词 → 它实际是什么

| 别人说的词 | 它实际是什么 | 为什么不能这么说 |
|---|---|---|
| **「与门」/「逻辑门」** | **线性求和后过阈值** | 说"与门"会让人以为里面**有个判断**。R2 的 0.80 + 0.85 > 1.0 就是这个 | 
| **「注意力机制」** | **没有这个东西**。专注是**连接结构 + 历史**的结果 | "机制"暗示有一个零件；实际没有零件 |
| **「专注开关」** | **没有开关** | 你不需要写 `set_focus(True)`（第 26 卷） |
| **「奖励函数」** | **多巴胺区一亮＝许可证** | 它**不计算好坏**、不知道目标（第 8 / 20 卷） |
| **「训练阶段」** | **可塑性是每一拍的一部分** | 没有 `train()` / `eval()` 两个阶段（第 20 卷） |
| **「推理步骤」** | **没有单独推理步骤** | 下一拍由当前权重和电流决定（第 2 卷） |
| **「读出层」** | **没有读出头** | 运动命令就是那 160 个细胞的活动（第 23 卷） |
| **「负权重」** | **抑制细胞** | 网里**没有一根负权重**；`-4.5` 只是表格记号（第 24 卷） |
| **「中心放大 / 变焦」** | **诚实的采样**（中心密、边缘疏） | 旧版真正的"放大"是**畸变**（A.4 第 2 条） |
| **「读出器（给人看的那种）」** | **仪表**，不是架构 | 想看清可以加仪表，**但不许塞进架构** |
| **「海马体索引」** | **不需要** | 前额叶靠**自己的赫布权重**就有时间顺序（第 22 卷） |
| **「把两个读数合成一个」** | **会把"没有"这个读数吃掉** | 实测：黑帧会让**整张输出表全黑**（第 21 卷） |
| **「帧」** | **一帧 = 2 格 = 0.1 秒** | "帧"和"格"不是一回事，混用会算错时间（第 22 卷） |
| **「本能表就是训练数据」** | **它是基因组写的**；动作库的蒸馏发生在**出生之前** | 动物活着时**没有奖励、没有目标、没有误差**（第 24 卷） |

## A.3 用户点名过的**自造词**（禁用清单）

用户明确质问过下面这些词。**这些词不许再用**：

| 不许用的词 | 用户的话 | 它该被什么替换 |
|---|---|---|
| **「24 个小灯泡」** | "你别乱造词，24 个小灯泡是什么东西？" | 直接说**是什么细胞、有多少个**（或说"某一层的 24 个单元"） |
| **「轴」** | "轴又是什么意思？" | 说清是**哪一个方向 / 哪一根线**，不要用"轴"当黑话 |
| **「抖动涨到 12 度」这类没有单位的说法** | "怎么会 20 度就不抖，30 度就抖呢？" | 说清**是哪个量、单位是什么、在什么条件下** |

> **这条纪律的实质**：**读者看不懂，不是读者的问题，是写的人没写清。**
> 一个词如果**不能翻译成"具体是哪些细胞、多少个、多大"**，就不该用。

## A.4 撤回记录（被数据推翻的说法）

> **规矩**：撤回要**明确写出来**，写清"**旧说法 / 为什么它错 / 正确的在哪一卷**"。
> 不许悄悄改掉。

### 撤回 1：**"抖动是因为分辨率低"**

| 项 | 内容 |
|---|---|
| **旧说法** | 眼睛抖动**是因为分辨率太低**；分辨率高了就看不出来 |
| **谁说的** | 由"四个大力气神经元＋自动回正"那套推出来的直觉 |
| **为什么错** | 实测证明抖动是**"比例反射"这条路的两难**：**增益低 → 永远偏（下垂）；增益高 → 在目标两侧来回撞**。两头都实测到了（增益 1.0 → 抖动 0.002 / 偏离 0.150；增益 3.5 → 偏离 0.043 / 抖动 0.503） |
| **正确解释在** | **第 27 卷 27.5**；出路是**把眼肌时间常数放慢**（0.015 → 0.20 秒） |

### 撤回 2：**"2.5 m 就能读出距离"**

| 项 | 内容 |
|---|---|
| **旧说法** | 论文里写着"从 2.5 m 起就能读出距离" |
| **为什么错** | 那是**中心被无界放大**（畸变采样）**换来的**。诚实的眼睛在 **2.5 m 处和平行没区别**（2.5 m 上会聚角只有 2.5°） |
| **正确的数** | 诚实采样：2.50 m → **+0.000 / 1 格**；1.50 m → +0.104 / 2 格；1.00 m → +0.213 / 3 格；0.25 m → **+1.201 / 7 格**（每近一档多亮一格） |
| **正确解释在** | **第 27 卷 27.1** |

### 撤回 3：**"文字网络承担本能连接的来源"**

| 项 | 内容 |
|---|---|
| **旧做法** | 有一条流水线，用文字网络来生成"本能连接" |
| **为什么废** | 这条流水线**已作废**；文字网络的正式身份是**研究台**（研究权重增长规则），**不是**本能连接的来源 |
| **正确说法在** | **第 33 卷**、`00_框架.md` 的 E2 表 |

### 撤回 4：**"红 → 走是一个与门"**

| 项 | 内容 |
|---|---|
| **旧说法** | 把"视觉 0.80 + 前额叶 0.85 才过阈值 1.0"说成"**与门**" |
| **为什么错** | 它是**线性求和后过阈值**，**不是逻辑与**。用"与门"会让人以为里面有个判断 |
| **正确说法在** | **第 32 卷 R2**（作者**故意**不这么叫） |

### 撤回 5：**"多点亮几个字能变广"**

| 项 | 内容 |
|---|---|
| **旧直觉** | 每步只挑最强的 1 个字导致坍缩；那**同时点几个**应该就变广了 |
| **实测** | `argmax` 覆盖 **749**；`topk2/4/8` = **718 / 711 / 708** —— **更窄** |
| **正确说法在** | **第 33 卷 33.4** |

### 撤回 6：**"跑得快 ÷ 5，好狗几乎全顶到 1.0"**

| 项 | 内容 |
|---|---|
| **旧说法** | 定"跑得快"那一格怎么换算时说的：原来除以 5 米，**好狗几乎全顶到 1.0**，那一格分不出快慢 |
| **为什么错** | 那句是**估的，没量**。实测六批第 0 代 **193 只没摔的模型**：这一格读的是"追球那两趟**平均**跑了多少米"，**中位 3.85 米、最远 9.29 米**；除以 5 顶到满分的只有 **26%**（50 只），**不是几乎全部** |
| **正确的数** | ÷5 → **26%** 顶满分；÷6 → **8%**（16 只）。**÷6 这个结论没变**，但理由要改成"少了三分之二的人挤在满分线上"，不能再说"所有人都在那里" |
| **正确说法在** | **第 36 卷 36.5 坑二**；`engine_v2/tools/evolve_chase.py` 里那段注释也一并更正了 |
