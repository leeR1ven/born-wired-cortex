# 第 27 卷　眼睛的精确规则

> **本卷目标**：把眼睛这条线从头到尾写清楚：视网膜怎么采样、眼肌怎么控制、接线怎么算、
> 抖动到底是怎么回事、以及**两处必须撤回的旧说法**。
>
> 这一卷的绝大多数内容**论文里没有**，出自 `engine_v2/docs/` 与用户关于眼睛的多次纠正。

---

## 27.0 一句话原理

> **红球出现在视野的哪一块，就激活那里的特征神经元；
> 那些特征神经元直接连到"控制眼球肌肉的神经元"；肌肉按固定力气转，没力就自动回正。**

### 生活里的比喻

眼睛是一个**很沉的门轴**：你推它，它慢慢转；你不推，弹簧把它带回来。
**门轴上没有"我想转到 20 度"这种想法**——只有"往这边推多大"。角度是**推出来的结果**。

## 27.1 视网膜采样：中心密、边缘疏

| 项 | 规则 |
|---|---|
| 采样方式 | **直接在没被压缩的画面上采样**——**不打弯、不插值、不搬像素** |
| 位置映射 | `p = s·(k + (1−k)·s²)`，其中 `k = 1 / centre_gain` |
| `centre_gain` | **2.5**（中心一度上有 2.5 倍的细胞） |
| 每个细胞报告什么 | **它自己那一片的均值**（片宽 = 它到相邻细胞的间距，中间窄、边缘宽，正好铺满整幅画） |
| `oversample` | 自动 = `ceil(centre_gain)`——**画到这么细就够了**，再细只花渲染时间 |
| 中心是几倍放大 | **有限倍**（`dp/ds` 处处非零） |

### 撤回：旧版"中心无界放大"是畸变

| 旧说法 | 真相 |
|---|---|
| 旧版按 `|t|²` 变形后再取**单点像素**，中心 `dp/ds → 0` | 那是**中心被无界放大**：0.6 m 处的绿球被拉成**一条横条**；边缘的像素反过来被挤扁 |
| **论文里"从 2.5 m 起就能读出距离"** | **那是畸变换来的。撤回。** |

### 诚实的对照数字（同一场景、48×36、各 400 步）

| 目标距离 | 诚实采样 drive / 亮格数 | 旧（变形）采样 drive / 亮格数 |
|---|---|---|
| 2.50 m | **+0.000** / 1 | +0.075 / 2 |
| 1.50 m | +0.104 / 2 | +0.218 / 3 |
| 1.00 m | +0.213 / 3 | +0.265 / 3 |
| 0.60 m | +0.206 / 3 | +0.310 / 4 |
| 0.40 m | +0.255 / 3 | +0.376 / 4 |
| 0.25 m | +1.201 / 7 | +1.080 / 7 |

**怎么读**：诚实的眼睛在 **2.5 m 处和平行没区别**（2.5 m 上会聚角只有 2.5°，本来就接近平行）；
从 1.5 m 起**每近一档多亮一格**，到 0.25 m **七格全亮**。

> **另外发现一个早就存在的缺陷**（不是采样造成的）：**会聚在近处本来就不够**。
> 0.6 m 需要两眼张开 10.47°，实际只到 6.4°。
> 根子在 `STEREO_OFFSET_MAX` 是**列数**（6 列）而不是**角度**——视网膜越细，6 列覆盖的角度越小。

## 27.2 眼肌：8 个细胞，4 个方向 × 2 档力度

用户 2026-10-01 给的口径：

| 项 | 规则 |
|---|---|
| 每只眼几个控制细胞 | **8 个**：往左 / 右 / 上 / 下，每个方向 **2 个** |
| 两档是什么 | **大力气 = 继续转**；**小力气 = 保持** |
| 没有力度时 | **眼睛自己回正**（回正力**始终固定**） |
| 球不在正中间时 | 激活靠近球那一侧、且是**大力度**的那类神经元 |

### 用户后来又说的一种简化（也记在案）

> **"或者不要小力气神经元，总共就只要四个大力气神经元也行。"**
>
> 这样：球到视角中间 → 眼睛不再移动 → 视角自动往回 →
> 周围神经元再被刺激 → 眼睛又往旁边移动 → **抖动**。
> **但无所谓**：抖动是**分辨率太低**造成的，分辨率高了就看不出来。
>
> ⚠️ **最后这句"抖动是因为分辨率低"后来被实测推翻了**（见 27.5）。**撤回。**

## 27.3 眼睛的物理参数（它解释了"眼睛为什么慢"）

| 项 | 值 |
|---|---|
| 自由度 | **2** |
| 行程 | **30 度** |
| 肌肉加速度 | **500 度 / 秒²** |
| 负载 | **很强的粘滞** |
| 结果 | **一拍最大力只转约 0.1 度** |
| 所以 | **一次大扫视要约十拍** |

> **"眼睛看起来慢"不是 bug，是这几个物理数算出来的结果。**

## 27.4 接线：六条规则（`tools/wire_red_gaze.py`）

| # | 规则 |
|---|---|
| 1 | 起点是 `retinal_opponent` 的**红色通道**细胞（下标 `i % 3 == 0`），取被球亮过的（`peak > .15`） |
| 2 | 每个细胞对**方位**和**高低**各出一根线，**两轴独立**；一个细胞出多大力 = 该档「每弧度增益」× 它自己看到的角度 → **中央轻、越偏越重** |
| 3 | 方向：方位正则接 `left`、负接 `right`；高低正则接 `up`、负接 `down`（`+yaw = 往左看`、`+pitch = 往下看`） |
| 4 | **两档力度**：近处（3 度到 0.10 弧度）的细胞推得**轻**（保持档）；远处的推得**重**（移动档） |
| 5 | **3 度以内的细胞不接**（死区） |
| 6 | 别的看东西的通路（对比度、明暗变化、声音、记忆、会聚）全部掐到 `1e-9`；一根指令细胞**同时推到两只眼的同一关节** |

## 27.5 两个真正的错（都是自己找出来、改根因）

### 错一：归一化的分母用错了——球亮的是一"团"，不是一"竖列"

| 项 | 说明 |
|---|---|
| 错在哪 | 每档接线粗细 = 增益 ÷「球摆在该档最远处时点亮的那片细胞的 \|角度\| 之和」。那片细胞**只按方位卡**，把**所有高度**的细胞都算进了分母 |
| 症状 | 球在远处时指令细胞只放电 **0.041 ~ 0.138**（设计意图是 0.5 ~ 1）——**分母大了约 8 倍**，眼睛只能动一点点 |
| 改法 | 按**两个方向一起卡**：方位 ±3.3° **且** 高低 ±3.0°（球在视网膜上真正亮的那一团） |
| 结果 | 同一个探针的放电变成 **0.17 ~ 0.40** |

### 错二：抖动不是参数没调好，是"比例反射"这条路的两难

| 项 | 说明 |
|---|---|
| 比例反射的稳态 | 眼睛停在"**推力刚好顶住静息电流**"的地方，所以 **偏离 = 球的角度 ÷ (1 + 环路增益)** |
| 于是两头都坏 | **增益低** → 永远偏（下垂）；**增益高** → 在目标两侧**来回撞** |
| 实测两头 | 增益 1.0 → 抖动 **0.002**、中位偏离 **0.150**；增益 3.5 → 中位偏离 **0.043**、抖动 **0.503** |
| 结论 | **单档比例反射要求增益 < 2 才稳**，而偏离压到 0.10 以内要增益 > 2.5 —— **够不着** |

**试过的另一条路**：「**自激勾住**」（两个细胞互相激发，即用户说的**循环激活**）

| 配置 | 结果 |
|---|---|
| 勾 A（0.9） | 8/25 |
| 勾 B（0.98） | 15/25 |

抖动降了但**偏离更大**：因为指令细胞放电一饱和（速率上限 1）就变成"**要么顶死、要么不推**"。
**机制留着（`--latch` / `--cross`），但要配很小的输入增益才行。**

**走通的那条路：把眼肌本身放慢。**

| 项 | 说明 |
|---|---|
| 做法 | **慢肌肉跟不上快振荡**，眼睛就不抖，同时允许把增益留在能压住偏离的位置 |
| 参数 | 模型里默认 `motor-time` **0.015 秒**；这一轮用 **0.15 ~ 0.20 秒** |
| 性质 | 这是**肌肉自己的时间常数**，属于**把眼肌调慢**，**不是接线上的补丁** |

## 27.6 位置野表：原来没量到那么高

| 项 | 说明 |
|---|---|
| 问题 | 测试里球的高低 ±0.28 换算成**相对头的真实高低**是 **±0.37 弧度**，而旧位置野表只量了 **±0.36** |
| 后果 | 球在高处时，它的像上半团落在**没量过的细胞**上，驱动变弱 → **高处的球偏得多** |
| 重量的表 | `--bearings=-0.50,0.50,36 --elevations=-0.50,0.50,26` → **936 个位置** |
| 效果 | 新旧表各跑一遍，同一套增益下**最差误差 0.174 → 0.088** |

## 27.7 最终读数（照实抄）

接线命令：

```
python tools/wire_red_gaze.py --table artifacts\红球位置野_红_大.json ^
    --cell-time 0.01 --gain 2.5 --move-push 0.35 --hold-push 0.10 --motor-time 0.20
```

测试：**5×5 = 25 个球位**，每位置 **80 步（0.8 秒）**，取**后 25 步平均**，容差 **0.10 弧度**。

| 配置 | 命中 | 中位 | 平均 | 最差 | 抖动 yaw/pitch |
|---|---|---|---|---|---|
| **增益 2.5 推 0.35/0.10 眼肌 0.20 秒（当前最好）** | **25/25** | **0.045** | 0.046 | **0.088** | 0.056 / 0.032 |
| 增益 1.5 推 0.50/0.12 眼肌 0.15 秒 | 25/25 | 0.052 | 0.052 | 0.090 | 0.065 / 0.029 |
| 同上但死区 1.5 度 | 25/25 | 0.040 | 0.043 | 0.088 | 0.057 / 0.032 |
| 同上但死区 0.5 度 | 25/25 | 0.040 | 0.042 | 0.088 | 0.056 / 0.032 |
| **对照：球是绿的** | **2/25** | 0.228 | 0.232 | 0.325 | 0.009 / 0.000 |
| **对照：不分两档**（只留移动档） | **25/25** | 0.058 | 0.053 | 0.086 | 0.038 / 0.030 |
| 旧读数（大表之前）：增益 3.5 推 1.00/0.40 | 25/25 | 0.043 | 0.047 | 0.095 | **0.503** / 0.056 |

### 三条必须一起说的诚实结论

| 结论 | 依据 |
|---|---|
| **这条通路确实只认红色** | 绿球只有 **2/25**，而且那 2 个正好是球在正中央、**眼睛本来就不用动**的位置 |
| **两档没有明显好处** | **不分两档也是 25/25**（中位稍差、抖动更小）。真正起作用的是"**近处细胞权重轻**"这件事本身 |
| **抖动从 0.503 降到 0.056**（约 3 度） | 肉眼上已经不是"抖"，而是**很轻微的颤** |

### 剩下的误差结构

| 现象 | 原因 |
|---|---|
| **高低方向整体偏 +0.03 ~ +0.056**（眼睛比该看的位置略低），越靠近正中越明显 | **3 度死区 + 比例下垂** |
| 左右方向误差 | 已经都在 **0.088** 以内 |
| **两眼静止时不指同一点，差约 20 度** | **会聚属于还没做的第三关** |

## 27.9 用户给过的几条口径（原样记）

| 用户说 | 意思 |
|---|---|
| "红球在哪里激活了哪里的神经元，神经元激活肌肉然后移动眼球" | **不给角度、不给坐标、不做三角函数**——只有"哪块亮了就推哪边" |
| "根本不用记住角度" | 眼肌发多大力是**固定的**；激活了就发固定的力 |
| "回正力始终都是固定的，不要搞得那么麻烦" | 回正**不是算出来的**，是一个常数 |
| "眼睛的移动速度实际上可以自己设置吧，和大脑又没有关系" | 眼肌时间常数是**物理参数**，不是大脑的事 |
| "先做一只眼睛，一只眼睛没问题了两只眼睛就没问题" | 先**一只眼**跑通，再上两眼 |
| "让球离近一点显得球大，眼睛看到球差不多正中心就行" | 评判标准是"贴到中心附近"，不是"精确到小数点" |

## 27.10 怎么搭

| 产出 | 要点 |
|---|---|
| **一个诚实的视网膜** | 不打弯采样；`centre_gain=2.5`；每细胞报所在片的均值；**不插值** |
| **一张位置野表** | 至少量到 **±0.50 弧度**、936 个位置；**量小了高处会偏** |
| **8 个眼肌细胞 / 每只眼** | 4 方向 × 大/小力；没力时**固定回正** |
| **一条红色通路** | 球亮过的红色通道细胞 → 按位置野算出的线 → 眼肌细胞；**中央轻、越偏越重**；**3 度死区** |
| **一个眼肌时间常数** | 至少 0.15 ~ 0.20 秒（否则会抖）；这是**肌肉参数**，不是接线补丁 |
| **一个"别的通路全掐掉"的开关** | 对照用；不能给 0，构造要求正数，所以给 `1e-9` |

## 27.11 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 它真的在追球吗 | 5×5 共 25 个球位，每位置 80 步，取后 25 步平均，容差 0.10 弧度 |
| 它是不是只认红色 | **绿球对照**：应该几乎全不中（实测 2/25，且都是不用动的位置） |
| 抖动是参数问题还是结构问题 | 扫增益：**低增益 → 偏离大；高增益 → 抖动大**。两头都有就说明是**两难** |
| 是不是眼肌时间常数在起作用 | 把 `motor-time` 改回 0.015，抖动应该回来 |
| 位置野表够不够大 | 新旧表各跑一遍比最差误差（0.174 → 0.088） |
| 死区能不能去掉那个偏置 | 试 1.5 度 / 0.5 度死区，看高低偏有没有变小 |
| 有没有偷偷关掉别的通路 | 把别的通路从 `1e-9` 打开，看结果变不变 |
| 正常模型有没有被动过 | 跑单测 + 指纹核对（`red=None` 时**一个字节都不该动**） |

## 27.12 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **说"抖动是因为分辨率低"** | 听起来合理 | **被实测推翻**（27.5）。真因是**比例反射的两难** |
| **靠调增益消除抖动** | 越调越差 | 低增益下垂、高增益抖——**这是两难**，出路在**眼肌时间常数** |
| **拿"畸变换来的距离读数"当成果** | 2.5 m 就能读距离 | **撤回**；诚实采样在 2.5 m 和平行没区别 |
| **位置野表量小了** | 球在高处偏得多 | 量到 **±0.50 弧度 / 936 个位置** |
| **归一化分母按"列"卡** | 远处球只放电 0.041~0.138 | 要按**一团**卡（方位 ±3.3° **且** 高低 ±3.0°） |
| **给眼睛写"想转到多少度"** | 做三角函数反解 | 只有"哪块亮了就推哪边"；**不给角度、不给坐标** |
| **测试时把眼动关掉** | 图省事 | **红线**：眼球始终由大脑控制 |
| **以为两档是必需的** | 非要"小力保持" | 实测**不分两档也 25/25**；起作用的是"近处权重轻" |
| **把眼肌时间常数当"接线补丁"** | 觉得是在打补丁 | 它是**肌肉的物理参数**，性质完全不同 |

## 27.13 自检三问

1. 为什么"抖动"不能用"调大增益 / 调小增益"解决？请用 **偏离 = 球的角度 ÷ (1 + 环路增益)** 这句话解释。
2. 绿球对照只有 **2/25**，而且那 2 个都是"球在正中央、本来不用动"的位置。
   为什么这两个位置的存在**反而**让这个对照更有说服力？
3. 如果让**你把眼睛接上但不用位置野表**，你会怎么接？请说明为什么那样接**会失败**。
