# 第 30 卷　常见坑清单

> **本卷的用法**：**这是一张速查表，不是用来通读的。**
> 每一条都是**真踩过的**。附录 D 留了一份同样的速查。
>
> 分四类：**概念坑 / 代码坑 / 环境坑 / 工程坑**。

---

## 30.0 一句话原理

> **绝大多数坑，本质上是同一件事的两面**：
> 要么**让代码替神经元做了决定**，要么**把"没做到"说成"做到了"**。

---

## 30.1 概念坑（最贵的一类）

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **加奖励函数 / 反向传播** | "这样学得快" | 三条红线之一。学的东西**只有连接权重** |
| **手动调连接** | 手改几根线让它走直 | 主路是**随机生成 + 考试 + 筛选** |
| **参数没调好就加代码补** | 加个 α 自动校准 / 加个整体抑制 / 加个专注闸门 | 被用户点名批评的**同一个毛病**（第 26 卷） |
| **把学习当"训练阶段"** | 写 `train()` 和 `eval()` | 可塑性是**每一拍**的一部分 |
| **加"整体压低权重"求稳** | `w *= 0.99` | **红线**：稳定性是**更新规则**的性质，不是衰减项的 |
| **只在最后一层找特征** | 忽略中间层 | **每一层都可能出特征**（第 18 卷） |
| **把"没有信号"当成"两只都不亮"** | 丢掉"没有"这个读数 | "没有"**也是一个读数**（第 21 卷） |
| **给前额叶加索引** | 想让它"按顺序想" | 顺序就是它**自己的赫布权重**（第 22 卷） |
| **给眼睛写"转到多少度"** | 做反解三角函数 | 只有"哪块亮了推哪边"（第 27 卷） |
| **每个区自己造一个时钟** | 时间对不上 | **全系统唯一时钟** |
| **在接口里塞判断** | "顺手"解码一下 | 接口**只翻译、不判断** |
| **以为自己看见的就是它想的** | 用"它应该在想 X"下结论 | 只能确定一个**大致的思考范围** |
| **测试时关掉眼动** | 图省事 | **红线**：眼球**始终由大脑控制** |

## 30.2 代码坑

| 坑 | 症状 | 正确做法 |
|---|---|---|
| **`pkill -f 'evolve_chase'` 杀掉自己** | 那条 ssh 命令行**自己匹配到了自己**，会话被切断 | 用中括号写法：**`evolv[e]_chase`** |
| **稀疏执行不逐位等价** | 以为"近似加速" | 必须**逐位等价**，用指纹核对 |
| **每步重算结构量** | 慢 | 建成后**缓存一次**（第 29 卷） |
| **两遍 bincount** | 慢 | 合成一遍 |
| **`np.bincount` 返回整数** | 没有边的网络里类型退化 | 保证 `currents` 返回浮点 |
| **学习节拍没传下去** | 实际每 10 ms 学一次，文档写 50 ms | 检查参数**有没有真的传到位**（第 29 卷） |
| **归一化分母按"列"卡** | 远处球只放电 0.041~0.138 | 按**一团**卡（第 27 卷） |
| **把"消位"当成"省位"** | 反向赫布表被反复写满 | **门控省位**：先自测召回（第 23 卷） |
| **`previous_event_id` 被清空** | 顺序资讯丢掉 | 已发现的偏离，**不许说它没发生** |

## 30.3 环境坑（云上尤其多）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| **没设 `MUJOCO_GL=egl`** | 掉到 Mesa **软件光栅**，慢 **177 倍** | 云上**必须** export `MUJOCO_GL=egl` |
| **按 `nproc` 开进程** | 容器报的是**宿主机核数**（见过报 96，实际只有 24） | 用**自己配置的核数**，别信 `nproc` |
| **含中文的 `.ps1` 存成无 BOM** | 中文乱码，脚本报错 | **`.ps1` 必须 UTF-8 带 BOM** |
| **`.sh` 存成带 BOM** | Shell 把 BOM 当命令，报错 | **`.sh` 不能带 BOM** |
| **CRLF 混进 `.sh`** | `\r` 让命令找不到 | `.sh` 用 LF |
| **python 不在 PATH** | 命令找不到 | 本机用全路径：`C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe` |
| **依赖版本漂** | 结果对不上 | 钉版本：numpy 2.4.6 / mujoco 3.13.0 / scipy 1.17.1 / numba 0.65.1 / pillow 12.2.0 / torch 2.7.1 |

## 30.4 工程坑（写文档、写补丁）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| **补丁工具把行首的 `+` 写进文件** | 每个文件开头一堆 `+` | 用 `*** Add File:` 时，**确认补丁真的被解析成补丁**（本文档就踩过：8 个文件被写坏，已修） |
| **用相对路径调补丁工具** | "Failed to delete file" | 用**绝对路径** |
| **`Remove-Item` 被策略拦** | 删不掉 | 用 `*** Delete File:` |
| **一改就重跑全部实验** | 时间全花在重跑上 | **只跑用来验证这次改动的那几个**；别全量重跑 |
| **加一个机制就重跑所有题** | 一代跑一小时 | 用户明确说过：**没必要**。做**一个验证实验**就够 |
| **把"假失败 / 假成功"当成绩** | 好看但没用 | 每个数字配**脚本名 + 日志名** |
| **说过的被推翻就悄悄改** | 读者对不上 | **明确写"撤回"**，登记在附录 A |
| **改动后不跑旧实验** | 悄悄改坏了别处 | **零回归**：确认正常模型"**一个字节都没动**" |
| **题目本身是废的** | 十几道题测的是同一件事 | 题库要**自审**（第 36 卷） |
| **同一只动物测三次当三次重复** | 以为在做重复实验 | `--seeds 0,1,2` 是**三只不同的动物** |

## 30.5 一条总纪律

> **遇到任何一个"奇怪的结果"，先问三个问题**：
>
> 1. **是不是有代码替神经元做了决定？**
> 2. **是不是有一个我不该有的全局量 / 外部量（目标、坐标、索引、奖励）？**
> 3. **我是不是在看"细胞亮不亮"，而不是在看"拉不拉得动"？**
>
> 这三个问题能覆盖本卷里至少一半的坑。

## 30.6 自检三问

1. 为什么 `pkill -f 'evolve_chase'` 会**杀掉自己**？`evolv[e]_chase` 这个写法是怎么避开它的？
