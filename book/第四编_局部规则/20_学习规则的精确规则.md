# 第 20 卷　学习规则的精确规则

> **本卷目标**：把整本书**唯一的学习规则**写到能照着敲代码的程度：
> 三条更新、一张参数表、四个护栏、一个许可证（多巴胺）、两个"另一套"（抑制侧、重建引擎）。
>
> 为什么这么长、这么啰嗦？因为**这是全书唯一一个"改了就会变天"的地方**。

---

## 20.0 一句话原理

> **三条更新，搭上四个护栏，再加一张许可证。**
> 它**永远看不到奖励、目标或误差**。

---

### 生活里的比喻

**这一卷讲的是一本"记账本"**。它只有三栏：

| 栏 | 记什么 |
|---|---|
| **进** | 这两个细胞一起亮过 → 那把线**加粗一点**（但快到顶时会越加越少） |
| **出** | 一个亮了、另一个没跟上 → 那把线**细一点点**（每拍掉 0.5%） |
| **新开** | 同一对反复一起亮过 **4 次** → **新拉一根线**，粗细从 0.001 起 |

**记账员不看账本以外的东西**——不知道这两笔生意赚没赚钱、也不知道老板想要什么。
他只会把"**谁跟着谁**"这件事记下来。

> **护栏的作用**：不加护栏的话，这本账**越记越厚**（第 4 条那个真问题就出在这儿），
> 最后整张网被账本压垮。

## 20.1 三条更新（背下来）

| 情形 | 规则 |
|---|---|
| **一起亮**（顺序对：上一拍 A 亮、这一拍 B 亮） | `w ← w + η · m · (1 − w)` |
| **亮了但没带亮对方** | `w ← w · (1 − (1 − d) · m)` |
| **反复一起亮过、本来没连接** | 第 **4 次**见到时以 **0.001** 建立，然后走上面同一条规则 |

### 这两个公式在说人话

| 公式 | 人话 |
|---|---|
| `w ← w + η·m·(1 − w)` | 每次加强一点；**w 越接近 1，加得越少**（所以不会冲过头） |
| `w ← w·(1 − (1 − d)·m)` | 每次掉一点点；**w 越大，掉得越多**（按比例掉） |

> **`(1 − w)` 这一项就是"天花板"本身**：w 到 1 就再也加不动了。
> 你不需要另写一条"不要超过 1"的裁剪。

## 20.2 参数表（完整，照抄）

| 参数 | 值 |
|---|---|
| 兴奋学习率 `η` | **0.005** |
| 每拍衰减 `d` | **0.995** |
| 新突触出生权重 | **0.001** |
| 建立前要共激活几次 | **4** |
| 每拍最多考察多少对 | **4,000** |
| 每拍最多新建多少根 | **200** |
| 痕迹衰减 | **0.9** |
| 痕迹阈值 | **0.05** |
| 抑制侧学习率 | **0.0005** |
| 抑制侧上限 | **0.6** |
| 去抑制侧学习率 | **0.02** |
| 运动 / 运动记忆 / 前庭 / 本体 / 身体状态 的**可塑倍率 `m`** | **0.02** |

> **最后这一行是本书最漂亮的一处设计**：
> "平衡反射一辈子几乎不变"**不是一个特例分支**，就是这**一个数字**。

## 20.2.1　一个换算值得记住：**"每步慢 0.5%"**

在**可塑倍率 = 1** 的区里，一条"亮了但没带亮对方"的边，每拍掉：

```
1 − d = 1 − 0.995 = 0.005 = 0.5%
```

> 所以口语里常说的"**说话但没带动对方，每步慢 0.5%**"，
> **不是另一条规则**，就是 `d = 0.995` 这**一个数**。
> （固化连接除外——它们不参加任何衰减。）

## 20.3 新建连接：完整条件

| 项 | 规则 |
|---|---|
| 触发条件 | 一对细胞在**正确顺序**下被看到 **4 次** |
| 出生权重 | **0.001**（几乎为零，但存在） |
| 之后 | 走 20.1 那条**同一条**规则 |
| 每拍上限 | 最多新建 **200** 根 |
| 每拍最多考察 | 4,000 对 |

> **新建不违反"学习规则只有一条"**：它不是一条新规则，是**同一条规则作用在"本来没有的地方"**。

## 20.3.1　新边长出来最常出现在哪儿：区与区之间的**直连短路**

> **这一条用户点名说过是"漏得最厉害的一条"**，专门补在这里。

| 项 | 规则 |
|---|---|
| 区与区之间 | **既可以直接连**，**也可以经前额叶间接激活**——**两条路并存** |
| 直接的这一条 | 出生就有（第 17 卷的随机背景连接） |
| 绕前额叶的那一条 | 是长路：要走好几段 |
| **经常互相激活的两个神经元** | 后天会在**它们之间长出一根新边**——这就是**直连短路**，**跳过前额叶** |

### 短路是怎么长出来的

| 步 | 发生什么 |
|---|---|
| 1 | 一件事每次都要"绕一大圈"才能办成，那条长路的每一段都得**同时亮** |
| 2 | 于是**两端**在相邻两拍上**反复共激活** |
| 3 | 按 20.1 那条规则，**两端之间新建一根边**（这就是 20.3 说的"新建连接"） |
| 4 | 下次**不用绕了**——这根边就是**短路** |

### 它能解释三件事

| 现象 | 解释 |
|---|---|
| **熟能生巧** | 短路越长越多，反应越来越快 |
| **不依赖前额叶也能做** | 短路一旦长出来，前额叶那条路断了它照样走（论文 R8 就是"刺激发令、皮层运行"的例子） |
| **别手动接** | 短路是**长出来的**，不是接上去的——**手动接就是红线**（第 30 卷） |

> **注意**：它**不是一条新规则**，是 20.1 那条规则作用在"**跨区的一对细胞**"上。
> 这条也是"**区与区可以直接连**"这句话的来由。

## 20.3.2　一个真问题：**"新建连接"会被抽样吃掉**（实测，还没完全解决）

> 这一条是**顺手查出来的**，但它解释了后面好几处"**为什么挪不动**"。
> 记在这里，是因为**照着这本书做的人一定会撞上它**。

| 项 | 实测值 |
|---|---|
| 让脑子一直走 200 拍 | 前进动作点了 **199 拍**（一直在走，符合预期） |
| 新学出来的兴奋直连 | **0 条** |
| 共激活抽样被截断 | **200 次（每一拍都被截断）** |
| 主表里非固化的兴奋边 | **8,291,216 条**（出生时 8,291,375 条，**几乎没动**） |

**原因**：一拍要配对的是"**上一拍亮着的源** × **这一拍刚亮起来的目标**"。
光是亮着的视觉细胞就有 **5,000 多个**，乘上目标**远远超过"每拍最多考察 4,000 对"**——
于是**每一拍都只能随机抽 4,000 对**。
而"长出一根新连接"要求**同一对反复见过 4 次**；在随机抽样的前提下，
同一对平均要**几千拍**才被抽到一次。**所以新连接一根都长不出来。**

> **照抄时要注意**：规则里"**反复见过才算数**"这半句，
> 如果**配对是随机抽的**，就会被抽样**吃掉**。

**试着改快了**（只在实验里临时改，没动文件）：`每拍最多考察 = 100000`、`需要共激活次数 = 2`：

| 结果 | 数 |
|---|---|
| 新连接 | **长出来 39,659 条**（不再是 0）✓ |
| 颜色漂移 | **一点没变**：还是 24° 能点着、27° 断掉 |

**为什么改了也没用**：这 4 万条新边是**对着全脑 11.8 万个细胞均匀撒的**，
撒到"走路动作"那十几个细胞上的只有几条，每条才 0.001~0.01 的力度。
真正在起作用的，仍然是**出生时就撒在那儿的那些边被养粗**，
而不是"新边长出来的线"。

> **诚实的结论**：到这本书成稿为止，**"新建连接"这条在通用场景下还没有被证明真的用上了**。
> 它**不是错的**（规则本身没问题），但它**目前还是撒胡椒面**。
> 想让它真用上，得把配对**收窄**到"**这一拍真的有可能带亮对方的那一小撮**"。**这件事还没做。**

## 20.4 四个护栏，各防一种坏法

| 护栏 | 是什么 | 不装会坏在哪 |
|---|---|---|
| **上界（天花板）** | 每根边自己的最大权重（`(1 − w)` 那一项） | 反复用会**一路涨上去**，把别的信号压死 |
| **下界 + 系绳** | 每根边有自己的最小权重；还有"**出生权重**"当锚点拉着它 | 不用会**掉到零**，把天生会的东西忘光 |
| **两个预算** | 每拍最多考察 4,000 对、最多新建 200 根 | 一拍算不完（比身体还慢）／一拍写爆（**整个人群塌到自己身上**） |
| **冻结** | 一部分边标上"不许改" | 一辈子的**骨架**被慢慢磨掉，最先坏的是平衡反射 |

### "下界 + 系绳"就是用户要的那件事

> **用户的判据（原话大意）**：
> **反复用的不会无脑一直涨，很少用的也不会一直掉，总体维持在相对稳定的平衡。**
>
> 这一条在这里的对应就是：
> **涨**有天花板（`1 − w`）；**掉**有锚点（出生权重）。**两边都不是无限的。**

## 20.5 连接表维护：条数不会无限涨

| 项 | 值 |
|---|---|
| 用一次 | 加一点"强化量" |
| 条数到多少要清理 | **警戒线 = 100,000** |
| 之后每隔多少次清理 | **衰减间隔 = 200** |
| 整体乘 | **衰减率 = 0.9** |
| 掉到多少就删掉 | **消失下限 = 0.05** |

> **这不是学习规则，是"仓库管理"**：它管的是**条数**，不是"学什么"。

## 20.6 抑制侧和去抑制侧的学习

| 情形 | 结果 |
|---|---|
| 一个亮、另一个不亮（**无关**） | 亮的一方对它的**抑制变强**（有上限 0.6） |
| 两个**一起亮** | **抑制变弱**、**去抑制变强** |

| 参数 | 值 |
|---|---|
| 抑制侧学习率 | **0.0005 / 拍** |
| 去抑制侧学习率 | **0.02 / 拍** |

> **这两个数很小**，所以"越无关互相抑制越强"这件事**需要几十秒**才看得出来——这不是慢，是设计。
> 数字的实测见第 26 卷（R21）。

## 20.7 多巴胺快速路：三个约束

多巴胺区一亮，就把"**上一拍亮的细胞 → 这一拍才亮的细胞**"之间的连接**当拍写下来**。
它不是奖励函数，是**许可证**：它只说"**这一刻算数，写**"。

三个约束，**每个都是被翻车逼出来的**：

| # | 约束 | 不装的后果（实测） |
|---|---|---|
| ① | **两拍都亮的细胞要排除** | 60 拍写了 **115 万**根；一个听觉块从 609 个活跃细胞涨到 **2,202**（总共 2,749）——**塌到自己身上** |
| ② | **每个目标最多 8 个源，总驱动固定 0.50 均分** | 有目标细胞收到 **300** 单位电流，**而走路只需要 0.85**；碰巧亮过的细胞全被写满 |
| ③ | **快速路也要乘该区的 `m`** | 200 拍往运动区写 **26 万**根，步态散架：5 个种子里 **3 个走约一米就摔** |

> **第 ③ 条特别值得记**：多巴胺再"厉害"，也**不能绕过区域的倍率**。
> 否则运动区那 0.02 的倍率就形同虚设。

## 20.8 三个读数：权重到底在干什么（论文 R20）

想知道"权重的上升和下降是不是在失控"，就要**数**它。

| 读数 | 60 秒 | 300 秒 |
|---|---|---|
| 上升的边数 | 624,843 | 652,178 |
| 下降的边数 | 728,710 | 710,091 |
| 变动 > 0.001 的边数 | 67,936 | 202,527 |
| 最大上升 | +0.0784 | +0.0960 |
| 最大下降 | −0.0019 | −0.0253 |

**可动的边一共 1,978,225 根。** 三个结论：

| 结论 | 依据 |
|---|---|
| **不是在"滑走"，是在"沉降"** | 上升和下降的量彼此抵消，**总量没有单边走** |
| **用得少的边不会一路掉到底** | 最大下降只有 −0.0253，**远不到零** |
| **用得多的边不会一路涨上去** | 最大上升 +0.0960，**离天花板还很远** |

还有两个对照：

| 对照 | 结果 |
|---|---|
| 走**教学路线**，然后**静默 10 分钟** | 那批连接**保住了 97.5%**，而且权重**反而涨了** |
| **一直按着做**同一个动作 | 权重**停在天花板 1.500**，不再涨 |

## 20.9 另一套：重建引擎的更新式（论文 5.16）

重建引擎是**另一套**权重更新，别和 20.1 混起来：

```
变化量 = 学习率 × 调制量 × (突触后活动 − 目标活动) × 源活动率
        − 系绳系数 × (w − 锚点)
```

| 项 | 值 |
|---|---|
| `学习率` | **0.12** |
| `系绳系数 tether` | **0.2** |
| **衰减项** | **没有**（这一套里没有 `decay` 那一项） |
| 托儿所路线 | `tether = 0` |

> **它和 20.1 最重要的差别**：**这套里没有衰减项**，稳定性靠的是"系绳"和"目标活动"。

### 托儿所（nursery）的另一套参数（论文 R12）

| 项 | 值 |
|---|---|
| 空边出生权重 | **0.0001** |
| 下限 | **0** |
| 上限 `backup_cap` | **1.5** |
| 系绳 | 无 |

四臂对照（同一件事，四组不同的"有没有人管"）：

| 臂 | 起点 → 终点 |
|---|---|
| taught（教过） | 0.95 / 0.99 → **后退 1.000 / 腿驱动 0.504** |
| ignored（没人管） | 掉到 **0.000** |
| ungated（没门控） | 冲到天花板 **1.50** |
| no route（没路线） | 0.057 → **0** |

> **这一组数字的价值**："有人管 / 没人管 / 没限制 / 没通路"四种命运，**一条表就分清了**。

## 20.11 三条铁律（再列一遍）

| # | 铁律 |
|---|---|
| 1 | **可塑性是"一拍"的一部分，不是一种模式**——它从出生就在跑，没有"训练阶段" |

## 20.13 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 学习真的每拍都在跑吗 | 开 / 关各跑一次，比权重表 |
| 四个护栏真的生效吗 | **逐个拆掉**：应该分别重现"涨爆 / 掉光 / 塌掉 / 磨掉骨架" |
| 冻结真的免疫吗 | 只查带冻结标记的边，权重应该**一点都不动** |
| 多巴胺真的只是许可证吗 | 跑"多巴胺不亮"的对照：应该**学不到**，但**别的都正常** |
| 快速路三个约束真的必要吗 | 逐个拆掉，看 20.7 那三种塌法是否重现 |
| 权重在失控吗 | 数 20.8 那三个读数（上升 / 下降 / 大变动），看有没有单边走 |
| 稀疏版和全量版等价吗 | 两个版本各跑一遍，结果应**完全相同** |

## 20.14 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **把学习当成"训练阶段"** | 写个 `train()` 再写 `eval()` | 它是**每一拍**的一部分 |
| **给它全局信息** | 传进去"这一轮表现如何" | 一旦要全局信息，就必须有目标/误差——**红线** |
| **加一条"整体压低权重"** | 觉得更稳 | **红线**；稳定性是更新规则自己的性质（铁律 3） |
| **护栏靠调参而不是结构** | 试出一个不涨爆的数 | 护栏应是**结构性**的 |
| **冻结写成代码分支** | `if 是平衡反射: 不学` | 应该是**表上一列**或**一个倍率数字** |
| **以为多巴胺是奖励** | 说"它知道这样对" | 它**不知道对错**；它只说"现在写" |
| **让多巴胺绕过区域倍率** | "快速路嘛，特殊一点" | 会**直接毁掉步态**（20.7 第③条） |
| **把"重建引擎"和"赫布规则"混着写** | 以为是一套 | 是**两套**；重建引擎那套**没有衰减项** |
| **声称已经会"突触后自己亮就压低"** | 听起来更完整 | 论文 4.6 说**还没有**（20.10） |

## 20.15 自检三问

1. 用户说"反复用不会无脑涨、很少用不会一直掉"。请指出这两件事**分别由哪个护栏**保证，
