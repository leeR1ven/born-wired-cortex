# 第 18 卷　特征神经元的精确规则

> **本卷目标**：把"特征神经元"这件事从一句直觉，变成能照抄的规则。
> **最重要的一条**（用户点名的遗漏点）：**神经网络里每一层都可能出特征神经元，不是只有输入层。**
>
> 道理在第 6 卷，本卷只给规则和数字。

---

## 18.0 一句话原理

> **一个"特征"不是一个细胞，是**一对**细胞：一个说"有"，一个说"没有"。
> 它们互相竞争，**恰好亮一个**。
> 强弱不是靠"亮多大"，而是靠**亮几对**。

### 生活里的比喻

想象一排**跷跷板**，每块板上坐两个人，一个喊"有！"一个喊"没有！"。

- 信号进来 → 跷跷板倒向"有" → **正细胞亮、反细胞灭**。
- 信号没进来 → 倒向"没有" → **反细胞亮、正细胞灭**。
- 两边一样 → **算"有"赢**（平局算正）。

**"强弱"是另一回事**：不是把跷跷板压得更用力，而是**多压倒几块板**。

---

## 18.1 规则一：正 / 反一对，恰好激活一个

| 项 | 规则 |
|---|---|
| 表示单位 | **一对**细胞（正、反） |
| 竞争结果 | **恰好亮一个**——要么正、要么反 |
| 平局怎么办 | **算"正"赢** |
| 激活之后 | **清空信号**，这一对不再往上传原始值 |
| 唯一参数 | **`对数`**；这个特征池的细胞总数 = `对数 × 2` |

### 好处：不需要额外规则

"每一对里恰好亮一个"、""一半亮一半灭"这两件事，**是被配对竞争自动保证的**——
你不用写一段代码去维护它。

> **这是全书反复出现的一种设计手法**：把一条"必须成立的约束"变成**结构的副产品**，
> 而不是一句 `if`。

---

## 18.2 规则二：强弱用温度计码

| 项 | 规则 |
|---|---|
| 一个特征分成 | **N 对** |
| 表示 L 档（0 ≤ L ≤ N） | **前 L 对的正细胞亮**，后面全亮反细胞 |
| 一共能表示几级 | **N + 1 级**（0 到 N） |
| 名字 | **温度计码**（像温度计的水银柱，亮到哪里算哪里） |

**为什么不用"一个细胞亮多强"来表示强弱**：因为这里**没有"亮多强"**，细胞只有亮 / 不亮。
所以"强弱"只能变成**"亮几对"**。

> **温度计码的一个隐性好处**：相邻的档位**只有一个细胞的差别**。
> 所以"慢慢变强"看起来是**一格一格长**，不是跳变——第 27 卷眼睛的"一格一格挪"就是这个性质。

---

## 18.2.1　学习一次**只挪得动一档**

| 项 | 规则 |
|---|---|
| 一次**潜移默化**（被动漂移式的学习） | **只能挪动一档** |
| 为什么 | 强弱是用**温度计码**表示的——**一格就是一格** |
| 所以 | "慢慢变"是**一格一格**变的，**不是连续的小数** |

> 这和"开着学习能从红一路挪到黄绿、关掉学习就停在 78°"（第 32 卷 R4）是同一件事的两面：
> **学习填边界，不画边界。** 它挪的是一格一格的**边界**，不是重新画一张图。

## 18.3 规则三（最重要）：**每一层都可能出特征神经元**

| 说法 | 对 / 错 |
|---|---|
| "只有输入层才有特征神经元" | ❌ **错** |
| "**神经网络的每一层，都可能成为特征神经元**" | ✅ **对** |

### 这条为什么重要

| 如果把它理解错 | 会发生什么 |
|---|---|
| 只在最底下找特征 | 你会觉得"中间层只是过渡"，于是**中间层的信号被白白丢掉** |
| 用"最后一层才是答案"的思路读网络 | 反例见第 26 卷：**中间层能分开末层分不开的刺激** |
| 把某层的某个细胞当"这个词的编号" | 实测：**没有任何东西表示"红"**（第 33 卷 / 论文 R4） |

### 一个具体例子（实测，论文 R5）

红球出现在视野里时，看**新亮了哪些细胞**：

| 看哪一层 | 结果 |
|---|---|
| **第 1 层**（视觉细节） | **完美定位**：新亮的细胞全在"球的那一列" |
| **压缩输出层** | 散到 **13 列**；球正好在正中央时，**一个新细胞都没有** |

> **结论：信息是在"层级"里丢的，不是在"图像"里丢的。**
> 而且丢的时候，**每一层丢的东西不一样**——所以"每一层都可能是特征"不是修辞，是必须。

## 18.4 视觉这一层的具体数字

| 项 | 值 |
|---|---|
| 输入 | **1920 × 1080** 第一人称画面 |
| 马赛克 | **24 × 16** |
| 通道 | **3** 个 |
| 每档对数 | **10 对**（一对里"一个说到了、一个说没到"） |
| 一个视觉细胞大约管 | **6.25 度** |
| 视野 | **100° × 75°** |
| 有 10 对 → 能表示 | **11 级** |

**6.25 度是怎么来的**：水平视野 100°，横着 16 个格子：

```
100 ÷ 16 = 6.25 度 / 格
```

> 这个数以后会反复出现：**"一格 = 6.25 度"是眼睛那一卷的尺子**（第 27 卷）。

## 18.5 怎么读"它此刻看到了什么"

| 想读什么 | 怎么读 |
|---|---|
| 它此刻"看到了什么" | 找**一小撮一起亮的细胞**——这撮细胞就是"一个特征" |
| 在**哪一层**找 | **每一层都要看**，不是只翻最后一层 |
| 它是不是"真的看到了" | **不能只靠读细胞**。要做对照：**把刺激搬走**，看行为变不变（第 37 卷） |

### 一件必须讲清的事

> **视觉皮层被点亮，算不算"看到了"？**
>
> **算。链路没断。缺的只是一个"给人看的读出器"——那是仪表，不是架构。**
>
> 这条是红线：**不要为了让自己看清楚，往架构里塞东西。**

---

### 18.5.1　"认得出"的范围是**一段一段的**，不是一片

| 项 | 现象 |
|---|---|
| "认得出"的范围 | **一段一段的**，**不是连续的一片** |
| 说人话 | 有些变化它认得出；中间隔一段又认不出；再隔一段**又认得出** |
| 为什么是块状的 | 表示本身是**一档一档**的（温度计码），特征又是**一层层压出来**的 |

### 为什么"它不像人"（一个很有用的比喻）

人**看着一个人慢慢变老，还认得出来**——因为人不是靠"一格一格匹配"。
用"**同一个人慢慢变老**"去要求它，就会**误判**：那需要一种**它没有的连续性**。

**那它靠什么**：它靠**把这些段的边界挪一挪**（第 32 卷 R4）。
所以正确的期待不是"它能连续跟踪"，而是"**它能在一段一段的范围里重新划界**"。

## 18.6 怎么搭

| 产出 | 要点 |
|---|---|
| **一个特征池** | 给定 `对数`，生成 `对数 × 2` 个细胞，两两配对 |
| **一条竞争规则** | 一对里恰好亮一个；**平局算正**；亮完清空 |
| **一条温度计编码** | 一个特征占 N 对；第 L 档 = 前 L 对亮正、后面亮反 |
| **一条输出规则** | 特征池的输出**同时可以被上层读**——不要只让最后一层出网 |
| **一个"哪层都读"的习惯** | 读网络时，把**每一层的活跃细胞**都打印出来 |

---

## 18.7 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 一对真的恰好亮一个吗 | 抽样统计：每一对里**亮的个数应该恒等于 1** |
| 平局真的算正吗 | 构造一个"正反完全同强"的输入，看哪边亮 |
| 温度计码真的单调吗 | 让输入从 0 慢慢加到满，看亮度应该是 **0 → N 一格一格长**，不回头 |
| 每层都能出特征吗 | 同一件事，分别到**第 1 层和压缩层**去找新亮的细胞，比较定位精度 |
| 是不是每层都在丢东西 | 逐层统计"这件事在第 k 层还剩几个细胞能区分" |

---

## 18.8 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **只在输入层找特征** | 中间层的信息被忽略 | **每层都可能是特征**；用户点名过这一条 |
| **用"一个细胞 = 一个概念"** | 以为某个细胞是"红" | 实测**没有任何东西表示"红"**（第 33 卷） |
| **以为"亮得多" = "信号强"** | 把细胞当模拟量 | 细胞只有亮 / 不亮；强弱是**亮几对** |
| **把"恰好一半亮"当巧合** | 想写代码去修 | 它是配对竞争的**自动结果**，不该有代码 |
| **为了读数往架构里加东西** | 加一层"读出器" | 那是**仪表**，不是架构；加进去就说不清行为是哪来的了 |
| **忘了压缩是有代价的** | 以为输出层"更聪明" | 压缩层**空间定位更差**（散到 13 列）——这是**换来的**，不是免费的 |

## 18.9 自检三问

1. 为什么"一对里恰好亮一个"**不需要**额外规则？如果有人给你一个"每对被点亮两个"的实现，你会先怀疑哪里？
2. "每一层都可能出特征神经元"——请举一个**只看最后一层就会得出错误结论**的例子。
3. 有人看了 R5 的结果说："那我们把压缩层删掉，直接用第 1 层不就更准了吗？"
   你至少要说出**两个**反对理由。（提示：第 1 层"杂"，而且压缩换来的是别的东西）
