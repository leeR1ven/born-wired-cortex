## 17.0 一句话原理

> **皮层是一个平坦的数组。**"区"不是房间，是数组里的一段**地址区间**；
> 所有区间用**同一条方程、同一个节拍**更新，谁也不特殊。

### 生活里的比喻

想象一条很长的**走廊**，两侧是连续的门牌号 1、2、3……直到 148,032。

**"区"不是用墙围起来的房间，而是"门牌号 0–23039 这一段叫视觉，23040–46079 这一段叫视觉细节"**。

这样做有两个后果，都很重要：

| 后果 | 意思 |
|---|---|
| 一个细胞"属于谁"只是算术 | 谁都不是特例，代码里**没有 `if 是视觉区`** 这种分支 |
| 想查"谁离谁近"就是比门牌号 | 抑制细胞"就近投射"靠的正是**门牌号相邻**，不是解剖学距离 |

> **这就是为什么这套东西能长得很大**：加区、改宽，只是改几个数字。

## 17.1 细胞：一张表讲完

| 项 | 值 | 说明 |
|---|---|---|
| 细胞状态 | **二值**：亮 / 不亮 | 不是连续值，没有"放电率" |
| 一拍 | **20 毫秒**（50 Hz） | 全系统唯一的节拍 |
| 阈值 | **1.0** | 到达胞体的兴奋电流合计 ≥ 1.0 就放电 |
| 抑制 | 由**抑制细胞**做，被压住就沉到阈值以下 | **网里没有一根负权重** |
| 读出层 | **没有** | 运动命令就是那 160 个细胞的活动本身 |
| 推理步骤 | **没有** | 下一拍是什么，完全由当前权重和电流决定 |

**"没有读出层"是什么意思**：老办法里，网络内部的状态要经过一个**读出头**（通常是一层矩阵）才能变成动作。
这套方法里没有这个东西——**运动区那 160 个细胞亮几个，就是肌肉发多大力**。

**"阈值 1.0 是怎么定下来的"**：它和"每根边权重 ≤ 0.15、每个细胞约 100 条兴奋边"是一套的。
理论上一整块源全亮时能推出的电流是几十，所以阈值 1.0 是个**很低的门槛**——
真正的取舍见第 31 卷的"**刀锋问题**"：阈值太低会全体乱亮，太高会全体不亮。

## 17.2 区宽表（合计 **148,032**）

| 序 | 区 | 细胞数 | 它是什么 |
|---|---|---|---|
| 1 | 视觉 | 23,040 | 视觉层级的**压缩输出**（给皮层用的那个版本） |
| 2 | 视觉细节 | 23,040 | 同一个层级里**没被压缩的第一层**（空间定位准，但杂） |
| 3 | 视觉运动 | 1,920 | 帧差 / 中继细胞，给注视反射用 |
| 4 | 听觉 | 30,000 | 听觉层级的输出 |
| 5 | 前额叶 | 57,436 | **第二级压缩机**，被另外七个区喂 |
| 6 | 运动 | 160 | 16 个肌肉组 × 10 个细胞；**亮的个数 = 力气** |
| 7 | 运动记忆 | 3,576 | 时间细胞；**点亮一个动作的第一个细胞 = 播放整套动作** |
| 8 | 本体感觉 | 480 | 由关节角推出来的身体感觉 |
| 9 | 前庭 | 120 | 躯干倾角 / 倾角变化率 |
| 10 | 身体状态 | 60 | 比如"躯干低不低""是不是躺下了" |
| 11 | 多巴胺 | 200 | 奖励信号；它亮的时候共激活突触**当拍写**（只在 R9 用，平时静默） |
| 12 | 抑制池 | 8,000 | **每一条带抑制的本能，都从这里借一个细胞** |

### 23,040 这个数是怎么来的（值得一算）

视觉得到的是 **24 × 16 的马赛克**，每个格子 **3 个通道**，每档 **10 对**（一对里"一个说到了、一个说没到"）：

```
24 × 16 = 384 个格子
384 × 3 个通道 = 1,152
1,152 × 10 对 = 11,520
11,520 × 2（正、反） = 23,040   ← 正好是视觉区宽
```

> **所以"区宽"不是拍脑袋定的，是"马赛克分辨率 × 通道 × 档数 × 2"算出来的。**
> 你换身体、换感觉，区宽就跟着这套乘法走。

**视觉细节区为什么也是 23,040**：因为前处理网络的规矩是"**每层神经元数量 = 输入层数量**"（第 19 卷）。
所以第一层和压缩输出层**细胞数一样多**，只是**亮的细胞数**不一样（一个杂、一个稀）。

## 17.3 出生连接：背景

出生时每张网里都有两套"背景连接"，和本能表**无关**，由固定种子随机生成。

| 项 | 值 |
|---|---|
| 每个细胞的**兴奋**边数 | 约 **100** 条 |
| 其中**跨区**的比例 | 一半（约 50 条） |
| 兴奋出生权重 | 落在 **[0, 0.15]** 之间随机 |
| 其中**冻结**的比例 | **30%**（这一辈子都不许改） |
| 每个细胞的**抑制**边数 | 约 **100** 条 |
| 其中**落在 4 个门牌号半径内**的比例 | 一半 |

### 三个"不连接"的特殊区（很重要，加区时不这么做会全局失衡）

| 区 | 规则 | 为什么 |
|---|---|---|
| **运动 / 运动记忆 / 视觉运动** | **不接受**随机兴奋 | 它们的输入必须全部来自"算出来的信号"，不接受噪声 |
| **视觉细节** | **不发出**随机兴奋 | 它是层级的第一层，只负责往上供料 |

> **判据是"兴奋 / 抑制平衡"**：每加一个区，就检查整张网的兴奋总量和抑制总量有没有被带偏。
> 这三个"不连接"就是为了**让加区不扰动全局平衡**。

## 17.4 抑制池：8,000 个细胞怎么接线

| 项 | 值 |
|---|---|
| 抑制细胞总数 | **8,000** |
| 每个抑制细胞的出边 | **一半取离自己门牌号最近的细胞**（`抑制半径` = **4**）；**一半撒遍全表** |
| 每根抑制突触的权重 | **固定 1.5，永不改变** |
| 抑制细胞由谁点亮 | 本能表里带"抑制"的规则（见第 24 卷），展开成 `源 → 抑制细胞 → 目标` |

### "就近那一半"为什么故意做得很短

这一条是**被一次翻车逼出来的**，不是审美。

**运动记忆区是一条"一格一拍"的时间线**：动作的第 1 拍、第 2 拍……是**门牌号相邻**的。
如果就近抑制的半径取几十个门牌号，那么**本能链的第一拍会顺手把后面几拍压掉**——整套动作就播不完。

实测：半径 24 和半径 4 各跑一遍，**半径 4 明显更好**（站起 12/12、走路 11/12）。代价见第 29 卷。

## 17.5 随机种子：**不同种子 = 不同的大脑**

| 规则 | 说明 |
|---|---|
| 出生连接**必须固定种子** | 否则两次跑出来的网不一样，写死的本能对不上 |
| **换一个种子 = 换一只动物** | 实测：同一种子两次跑，权重哈希完全一致；不同种子就是不同的大脑 |

> 这一条后面反复用到。第 37 卷会讲一个**很容易踩的坑**：
> `--seeds 0,1,2` 得到的是**三只不同的随机动物**，不是同一只动物重复测三次。

## 17.6 稀疏执行：为什么它能跑得动

一次更新**不去碰全表**，只在"这一拍亮了的细胞牵连到的边"上跑，方程完全一样。

| 好处 | 数字（见第 29 卷） |
|---|---|
| 抑制更新从"每拍碰全部 2,760 万根"改成"只碰活跃细胞牵连到的" | 某一步 **554 毫秒 → 16 毫秒** |
| 而且**逐位等价** | 有专门的对照脚本证明结果一模一样 |

> **"事件驱动"不等于"近似"**：它是同一套方程的等价算法，不是近似加速。

## 17.7 怎么搭

| 产出 | 要点 |
|---|---|
| **一个平坦数组** | 只存 `亮 / 不亮`；区是地址区间 |
| **一张区表** | `名字 → (起点, 宽度)`；所有后续代码只查这张表 |
| **一张出生连接表** | 按 17.3 生成，**记下种子**；同时存"出生权重"当系绳锚点（第 20 卷要用） |
| **一个抑制池** | 8,000 个细胞；**按 17.4 分配出边**；权重常数 1.5 |
| **三个"不连接"标记** | 运动 / 运动记忆 / 视觉运动不接随机兴奋；视觉细节不发随机兴奋 |
| **一个稀疏执行器** | 与全量表等价，但只走活跃细胞牵连的边 |

## 17.8 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 区宽加起来对不对 | 求和应该**正好等于**数组长度（本配置 148,032） |
| 种子真的固定住了吗 | 同一种子连跑两次，**权重表哈希应完全一致** |
| 每个细胞的边数对不对 | 抽样统计：兴奋 ≈ 100、抑制 ≈ 100，跨区约占一半 |
| 冻结比例对不对 | 抽样统计：约 **30%** 的兴奋边带冻结标记 |
| 就近抑制真的短吗 | 抽样查抑制边的**地址距离**：一半应该 ≤ 4 |
| 抑制权重真的没变过 | 跑一段之后查抑制边权重，**应该全是 1.5** |
| 加一个区有没有带偏全局 | 加区前后各统计一次**全网兴奋 / 抑制总量**（第 29 卷有例子） |
| 稀疏执行等价吗 | 全量版和稀疏版各跑一遍，比对结果（应完全相同） |

## 17.9 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **把"区"当成模块写** | 代码里到处 `if 区 == 视觉` | 区只是**地址区间**；有分支就说明你想替神经元做决定 |
| **给区加特例** | 视觉用一套规则、听觉用另一套 | 全系统**同一条方程**；差异只该体现在**连谁、倍率多大** |
| **用解剖学距离做"就近"** | 想画一张三维脑图 | 这里的"近"就是**门牌号相邻** |
| **抑制写权重为负** | 图省事 | **网里没有负权重**；抑制是**另一群细胞** |
| **就近抑制半径拍脑袋取大** | 本能链第一拍把后面几拍压没了 | 半径 4 是量出来的；见第 29 卷 |
| **忘了固定种子** | 复现时对不上，本能表错位 | 出生权重的种子是**实验记录的一部分** |
| **加区不检查全局平衡** | 新网什么都不做了 | 加区后**一定**重新统计兴奋 / 抑制总量 |
| **把"稀疏执行"当近似** | 以为结果会有小差别 | 它与全量版**逐位等价**；不等价就是实现错了 |

## 17.10 自检三问

1. 为什么"区"必须是**地址区间**，而不能是"一个个独立的小模块"？（提示：抑制细胞的"就近"靠什么）
2. 出生连接里有 **30% 冻结**、抑制权重**固定 1.5**、还有"三个区不接随机兴奋"——
   这三条各自在防什么坏法？请分别说一条。
3. 有人想把就近抑制的 `抑制半径` 从 4 调大到 40，"这样抑制更有效果"。
   你要怎么回答他？请用**运动记忆是一格一拍的时间线**这一点来答。
