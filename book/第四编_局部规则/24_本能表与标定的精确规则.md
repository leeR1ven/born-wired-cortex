# 第 24 卷　本能表与标定的精确规则

> **本卷目标**：把"**生下来就会的那些东西**"写成能照抄的规则：
> 表长什么样、一个字一行怎么写、力度是什么意思、名字从哪来、以及**为什么不能用编号写本能**。

---

## 24.0 一句话原理

> **本能是"写"出来的，不是"学"出来的。**
> 写表的人，就是**基因组**。
> **表里没有一条 `if`**——动作选谁，是**电流在细胞体上抢**出来的。

### 生活里的比喻

它就像一张**菜谱**：

```
视觉:红            -> 运动:肌肉组0        2.0    是
视觉:红            -> 运动:肌肉组1        2.0    是
```

左边是谁、右边是谁、**多大力**、**能不能改**。
厨师（细胞）照着做，**不做判断，只按分量下料**。

---

## 24.1 一条规则长什么样

`model/本能表.txt`（**686 行，含注释**），格式：

```
源 -> 目标  力度  固化
```

| 栏 | 意思 |
|---|---|
| **源** | 哪个名字（比如 `视觉:红`） |
| **目标** | 哪个名字（比如 `运动:肌肉组0`、`运动记忆:...`） |
| **力度** | 见 24.2 |
| **固化** | `是` = **冻结**，这一根出生后永不修改（第 20 卷） |

---

## 24.2 "力度"到底是什么（关键定义）

> **力度 = 源整块亮起来的时候，每个目标细胞一共收到多少电流。**
> 它**自动均分到这条规则的每一根连接上**。

| 力度 | 效果 |
|---|---|
| **> 阈值（1.0）** | **整块源亮 → 目标细胞一定放电** |
| **< 阈值** | **只亮一小部分源 → 加起来不够 → 不动** |
| 2.0（常见值） | 整块亮必放电；零散亮则不会 |

**这条定义为什么重要**：它把"力度"从一个含糊的词，变成了**一个可以算的数**。
而且它自带一个非常有用的性质：

> **"整块一起亮"和"零零散散亮"被分开了。**
> 这正是"**一个念头点亮一整块 → 触发动作**"能成立的机制。

**展开时机**：**加载的时候**就展开成具体的突触（不是运行的时候现算）。

---

## 24.3 负数记号：不是负权重

| 表里写 | 实际展开成 |
|---|---|
| `-4.5`（负数） | `源 → 抑制细胞 → 目标` |

> **网里没有一根负权重**（第 17 卷）。**负号只是表格记号**，
> 展开时它变成"**借一个抑制池的细胞来压目标**"。

本能表的三种连接：

| 类型 | 表里怎么表达 |
|---|---|
| **兴奋** | 正数力度 |
| **抑制** | 负数力度 → 展开成抑制细胞 |
| **去抑制** | 抑制"抑制细胞"的那条（第 26 卷） |

### 585 条的分组

## 24.4.1　动作库是怎么"铺"出来的：**从 26 个动作到 221 个动作**

| 项 | 规则 |
|---|---|
| **最初**的动作库 | **26 个动作 / 288 拍** |
| **后来** | **铺成"地毯"**：扩成 **221 个动作** |
| 而且 | **每个动作的"前提"也一起烧进本能表** |

### "动作的前提"是什么

比如"**这个姿势只能从那个姿势过渡过去**"。
它**不是代码里的一句判断**，而是**写进表里的一堆连接**——
所以**执行的时候没有判断**（这就是第 2 卷那条"没有任何一条规则是 `if`"）。

> **铺成地毯的好处**：动作多了以后，**过渡不用现算**——
> 表里已经写好了"从哪来、到哪去"。这又是"**用表换计算**"的一次。

## 24.5 运动记忆类的规则：展开方式不一样（必须单独讲）

**动作库那一批（221 条）不是普通的一对一连接**，它展开成一条**时间链**：

| 步骤 | 展开成什么 |
|---|---|
| ① | **时间细胞互相串链**（第 1 拍 → 第 2 拍 → …） |
| ② | **每个时间细胞接它那一拍该动的肌肉** |
| ③ | **每个时间细胞下一拍自抑**（保证一拍只走一格，不回头） |
| ④ | **中间的时间细胞压住第一个**（防止从头再来一遍） |

结果是：

> **点亮一个细胞，就执行整套动作。**

这就是"**刺激只发令，皮层跑完**"在动作库上的具体实现，也是"**只点一次走路头细胞**"这个诊断手法能成立的原因。

## 24.6 名字从哪来：标定

表里写的是 `视觉:红`、`运动:肌肉组0` 这样的**名字**。名字不能凭空编，要靠**标定**。

| 步骤 | 做什么 |
|---|---|
| 1 | **点亮一个物理条件**（画一张图 / 放一段声音 / 摆一个姿势） |
| 2 | 跑对应的**前处理** |
| 3 | **记录输出层哪些细胞响应** —— 这些细胞就是这个名字 |
| 4 | **必须减去参考条件** |

### "减去参考条件"是什么意思

> **一个视觉方向名 = 该方向渲染红球 − 渲染空场景。**

**为什么必须减**：不减的话，你会把"**画面本来就有的东西**"也算进这个名字。
用"红球 − 空场景"，留下的才是"**因为这个球才出现的响应**"。

> **这是标定里最容易做错的一步**，也是后面"认得出"能不能测准的前提。

### 球半径怎么选（一个具体的坑）

| 用途 | 球半径 |
|---|---|
| 眼睛标定 | **0.30 m** |
| 注视反射的"按列"名字 | **0.05 m** 重标 |

**为什么按列要重标**：球**填满整格**的话，**每一层都看得见它**，就区分不出"是哪一列"了。

## 24.7 为什么**不能用编号**写本能（重要反例）

有人会想："何必标定，直接给每个东西编个号，本能表写编号不就行了？"

**实测结果**：

| 测什么 | 结果 |
|---|---|
| 满屏红时，皮层亮的细胞落在"输入层红色编号区"的比例 | **6.1%** |
| 纯碰运气能命中的比例 | **6.7%** |

**6.1% < 6.7%** —— **等于没有**。

**为什么**：皮层细胞代表什么，是**层层压缩后长出来的**，
不是"你给它编个号它就认这个号"。编号是**你脑子里的**，不是**它的**。

> **所以：名字必须靠标定量出来，不能靠编号指派。**

## 24.8 三条性质（对全书解释都重要）

| # | 性质 | 意思 |
|---|---|---|
| ① | **本能连接是"写"出来的，不是"学"出来的** | 写表的人就是**基因组**；动作库那批规则是从**另训的强化学习策略里蒸馏**出来的。这是**出生之前**的监督，**不是活着时候的监督** |
| ② | **没有任何一条规则是 `if`** | 动作选择是运动记忆细胞体上的**电流竞争**；两条规则可以**各自不够、合起来才够**；区与区的平衡**不是固定的** |
| ③ | **抑制由细胞做，绝不用负权重** | 见 24.3 |

### 关于 ① 一定要说清楚的一件事

> **"从强化学习策略里蒸馏"发生在出生之前。**
> 也就是说：**基因组在造这只动物的时候**，用另一个方法把"动作库"写好了。
> **动物活着的时候，全程没有奖励、没有目标、没有误差。**
>
> 这两件事必须分清，否则读者会以为"这不还是强化学习吗"。

---

## 24.9 另外三条容易搞错的

| 说法 | 正确的说法 |
|---|---|
| "本能要继承" | **不需要**。"继承"是对**人**的描述；实现上就是**直接在这个模型上写连接** |
| "本能是一张网，学习是另一张网" | **只有一张网**。本能连接**就是这张网的初始状态**，赫布学习在**同一张网**上继续长 |
| "本能只管几个反射" | **范围很广**：各区皮层一开始就有的连接 + 前额叶皮层一开始就有的连接 |
| "缺一条补一条" | **本能应该一次加齐**（第 36 卷会讲为什么） |

---

## 24.10 皮层在哪一行

| 区 | 面向大脑内部的那一层是 |
|---|---|
| 视觉 / 听觉 / 前额叶 | **输出层** |
| **运动区** | **输入层**（方向相反） |

**本能连接就长在"每个区面向大脑内部的那一层"之间**——同区内也长，跨区也长。

## 24.11 怎么搭

| 产出 | 要点 |
|---|---|
| **一张纯文本表** | `源 -> 目标  力度  固化`；**人类能读懂** |
| **一个加载器** | 加载时**展开**成突触；负数 → 抑制细胞；按 24.2 均分力度 |
| **一张标定表** | 每个名字对应"哪些细胞"；**必须减去参考条件** |
| **一套动作库** | 时间细胞串链 + 每拍接肌肉 + 下一拍自抑 + 中间压住第一个 |
| **一条纪律** | **不许用编号写本能**；**不许在表里写 `if`** |

## 24.12 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 力度真的≥阈值就必亮吗 | 把源整块点亮，看目标是否**一定放电** |
| 部分亮真的不动吗 | 只点亮源的一小部分，看目标是否**不动** |
| 负数真的变成抑制细胞吗 | 查加载后的突触表：不该有负权重，应该多出一个抑制细胞 |
| 名字标定得准不准 | 用"红球 − 空场景"量出来的细胞，应该**在别的位置出现球时不响应** |
| 动作库真的是"点一个跑一套"吗 | **只点一次**动作的第一个时间细胞，看整套动作跑不跑完 |
| 固化真的不动吗 | 跑一段后查那些突触的权重，应该**一点没变** |

## 24.13 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **用编号写本能** | 6.1% vs 6.7%——等于没有 | 名字**必须靠标定量出来** |
| **标定不减参考条件** | 名字里混进画面本来就有的东西 | 一定要 **红球 − 空场景** |
| **按列名字用大球标** | 每层都看得见球，分不出列 | 按列用 **0.05 m** 重标 |
| **在表里写条件判断** | "如果这样就这样" | **没有一条 `if`**；动作靠**电流竞争** |
| **以为本能是"非学习模式"** | 想分两张网 | **一张网**；本能是它的**初始状态** |
| **以为动作库是普通连接** | 展开成一对一的边 | 它是**一条时间链**（24.5） |
| **把"蒸馏"当成活着的监督** | 说"它有强化学习" | 蒸馏在**出生之前**；活着的时候**没有奖励** |
| **缺一条加一条** | 表越长越乱 | **一次加齐** |
| **把运动区的皮层当输出层** | 本能接错地方 | 运动区的皮层是**输入层** |

## 24.14 自检三问

1. "力度 = 源整块亮时目标细胞收到的电流"——请用它解释：为什么**整块亮会触发动作、零散亮不会**？
2. 为什么本能表里**不能**写条件判断？如果不写判断，那"该做 A 还是做 B"是谁决定的？
3. 有人说："本能表就是训练数据，先把表写好等于监督学习。"
