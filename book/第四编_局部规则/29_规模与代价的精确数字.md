# 第 29 卷　规模与代价的精确数字

> **本卷目标**：把"**要多大、要多久、值不值**"这三件事全部用数字说清。
> 里面还包含**全书最好的一个"怎么发现错"的教学案例**。

---

## 29.0 一句话原理

> **细胞便宜，连接贵。**
> 而一步的耗时**跟"这一拍亮了多少细胞"走，不跟"网有多大"走**。

### 生活里的比喻

一个城市：**多盖几栋楼（细胞）不贵**，贵的是**楼与楼之间的路（连接）**——
路要修、要养、要走。
但只要**不堵车**（亮的细胞不多），城市再大，**通勤时间也不变**。

## 29.3 原来的时间花在哪（剖一遍才有得优化）

参考尺寸 36 × 48，一步 **21 ms**，构成：

| 项 | 每步 |
|---|---|
| **突触学习**（`regulation.update` + `_project`） | **10.4 ms** |
| **听觉回路**（160 个采样点逐点循环） | 3.5 ms |
| 突触电流（两遍 bincount + 两次布尔索引） | 2.0 ms |
| 神经元电压更新（每步新建十几个临时数组） | 3 ms |
| 其他 | ~2 ms |

**三件事都是"每步重算一遍本来可以一次算完的东西"**：

| 改动 | 结果 |
|---|---|
| 学习节拍接上（`learning_interval` 没传下去 → 每 10 ms 学一次；改成 **50 ms**） | 规则不变，写入节奏回到文档写的值 |
| 结构量只测一次（边表、可塑性、下界占的预算**建成后就不变**） | 缓存 |
| 原地写入（神经元一步的加减乘写进固定数组；两遍 bincount 合成一遍） | 省一次遍历 |
| 学习只在**源细胞活跃**的边上算 | 源静默时那条表达式对所有边一样 |

**结果**：参考尺寸本身从 **21.1 ms 降到 7.7 ms**。
**改之前 36×48 一步合计 26.8 ms；改之后 120×90（4.8 倍细胞、2.9 倍连接）只要 31.0 ms。**

> **所有改动都要求"逐位一致"**——不是"差不多一样"，是改前改后的权重与活动摘要**完全相同**。
> 核对工具：`tools/check_model_fingerprint.py`（细胞数、连接数、初始权重 md5、20 步后 md5、200 步后身体位置与高度）。

## 29.5 成本跟着"活动"走，不跟着"规模"走（论文 R15）

| 对照 | 结果 |
|---|---|
| 细胞从 **10 万 → 80 万**（8 倍） | 成本只多 **1.06 倍** |
| 立体 / 平面 / 随机 三种配置 | **0.084 / 0.290 / 0.343** |

**为什么**：因为**不亮的细胞不算**——稀疏执行（第 17 卷）。

## 29.6 "模型太小"是一个**可以量**的说法（论文 R15）

不要用"感觉太小"来说话，要用数字：

| 测法 | 结果 |
|---|---|
| 运动细胞只有 **10 个**时 | 不同命令**挤在同一个码**上：0.50 ~ 0.54（几乎分不开） |
| 运动细胞到 **100 个**时 | 误差降到 **0.005** |
| 前额叶："想站" vs "想坐" | **12 个细胞 vs 10 个细胞**，重合度 **Jaccard 0.83** |

> **Jaccard 0.83 的意思**：两个不同的念头**几乎共用同一批细胞**——
> 这就是"太小"的**具体表现**，而不是一句感想。

## 29.7 一个必须报的代价：抑制接线修好之后（论文 2.1）

### 先讲错在哪（这是全书最好的"怎么发现错"案例）

| 步骤 | 发生了什么 |
|---|---|
| 症状 | 只有 **54,565** 个细胞能发抑制——而**前额叶 57,436 个细胞一个都发不出** |
| 根因 | 生成器"取一半"时，切的是**整张边表的一半**，而不是**每个源细胞自己那份的一半** |
| 后果 | 前额叶整区**没有抑制输出** |
| 修好之后 | 能发抑制的细胞 **124,792** 个；抑制边 **5,102,714 → 7,239,774** |

### 然后**没有**去重调强度（理由必须报出来）

| 量 | 改前 | 改后 | 比例 |
|---|---|---|---|
| 整网每拍总抑制电流 | 18,933 | 21,485 | **113%** |
| 传到"走路链头细胞"上的 | 2.84 | 2.70 | **95%** |

**读法**：变的是"**谁能抑制、抑制落在哪**"，**不是"按多重"**。
所以**强度不用重调**。

### 只有一个数必须重新选：**就近半径**

| 半径 | 12 个种子里能站起来的 | 能走向红块的 |
|---|---|---|
| 24 | 5 | 12 |
| **4** | **12** | **11** |

**取了能站起来的那个（4），并把代价一起报出来。**

## 29.8 系统偏差：偏一点会怎样（论文 R7）

| 项 | 结果 |
|---|---|
| 整体偏移 | **−3 ~ +3 列** |
| 偏移与结果的关系 | **线性的**：3.2° / 9.7° / 16.2° |
| 走路还工作吗 | **都 7/8** —— 偏一点，**仍然工作** |

> **这说明系统对"标定偏一点"是有余量的**，不是一次偏了就废。

## 29.10 怎么搭

| 产出 | 要点 |
|---|---|
| **一个指纹核对工具** | 细胞数、连接数、初始权重 md5、N 步后权重与活动 md5、身体位置与高度 |
| **一个分项计时工具** | 把一步拆成学习 / 感觉 / 电流 / 电压 / 其他 |
| **一条"逐位一致"的规矩** | 优化只能改速度，**不能改结果** |
| **一张规模表** | 每档的细胞、连接、一步耗时都留着 |
| **一条"报代价"的规矩** | 改好了要报**代价**，不能只报好处（29.7） |

## 29.11 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 优化真的没改结果吗 | 指纹核对：**改前改后 md5 必须相同** |
| 成本真的跟活动走吗 | 细胞翻 8 倍、活动不变，看耗时变化（应约 1.06 倍） |
| 抑制接线真的修好了吗 | 数"能发抑制的细胞数"（54,565 → 124,792）和抑制边数（510 万 → 724 万） |
| 就近半径选得对不对 | 12 个种子各跑一遍，数"站起来几个、走向红块几个" |
| 模型是不是"太小" | 量 R15 那两个数：命令码分不分得开、两个念头的 Jaccard |
| 偏差有没有余量 | 人为偏移 −3~+3 列，看行为曲线是不是线性、还能不能走 |

## 29.12 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **优化改出不一样的结果** | "快了就行" | 必须**逐位一致**；用指纹核对 |
| **只报好处不报代价** | 只说"修好了" | **代价一起报**（113% / 95%、半径 24→4 的取舍） |
| **用"感觉太小"下结论** | 拍脑袋 | "太小"是**可以量**的（命令码重合、Jaccard） |
| **以为"慢"一定是算力问题** | 先加机器 | 先剖分项：本例最大一块是**每步重算本可缓存的结构量** |
| **忘了抑制也会被"接错"** | 只看兴奋连接 | 抑制接线的错可以**整区失效**，且**不报错** |
| **拿"全场景 0.000"当"在工作"** | `eye_looming` 读数 0 也照说 | **照实报 0**，不要说它"在工作" |
| **改分辨率期待行为变化** | 调高了以为更聪明 | **分辨率不改行为** |
| **不记规模表** | 半年后不知道哪档多少细胞 | 每档都留数字 |
