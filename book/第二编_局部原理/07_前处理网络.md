# 第 7 卷　前处理网络

> **本卷目标**：搞清"感觉进来以后、到皮层之前"那一段在干什么，为什么必须长成那样。
> 这一段有个特殊地位：**它是全书唯一不学习的一部分**。

---

## 7.0 一句话原理

> **前处理网络是一台"信号调理电路"：多层、每层只跟邻居打交道、权重出生就固定。**
> 它的任务是把外围那一大堆通道，压成皮层接得住的一小撮。

### 生活里的比喻

想象一条**选矿的传送带**：

- 原矿（原始像素、原始声音）先过一道**筛子**，把最大的块筛出来；
- 再过一道，筛掉更细的；
- 每道筛子**只看它前面那一道流过来的东西**，不抬头看整条线；
- **筛子的孔大小是出厂就定死的，不会自己变。**

最后流出来的是一小撮**高浓度**的东西 —— 那就是皮层要的。

---

## 7.1 为什么是"多层"，而且**每层数量不变**

### 错误直觉

很多人第一反应是："那不就是逐层变小吗？像金字塔一样。"

**不是。**

| | 逐层变小（想当然） | **这套做法** |
|---|---|---|
| 每层有多少神经元 | 越来越少 | **和输入层一样多** |
| 变的是什么 | 数量 | **每一层"懂"的东西** |

每层数量一样，意味着：**这一层里，每一个位置都有一个细胞在盯着它**。
信息不是被"扔掉"了，而是被**一步步重新表示**。

> 这正好呼应第 6 卷那句：**压缩层丢掉的细节，还在它下层**。

### 每层只连"一圈邻居"

每个神经元只连上一层的**一小圈邻居**（左右各若干个，**首尾相接成一圈**）。

| 为什么这么连 | 说人话 |
|---|---|
| 局部 | 一个细胞不知道该看全图，它只知道"我附近这一段什么样" |
| **环形** | 首尾相接，是为了让**边界也是邻居**——不然图的边缘会长出一条假的"断裂" |

---

## 7.2 为什么权重出生固定、**绝不学习**

这是本卷最重要的一条。前处理网络的权重**一出生就固定，这辈子不变**。

### 为什么它不能学

| 如果它学了 | 会发生什么 |
|---|---|
| 学习规则只有"一起亮就强一点" | 前处理层**不知道对错**，它会开始**追着当前输入漂** |
| 前面的层一变，后面所有层跟着变 | **整套本能全部对不上**——因为本能表是按"某一版前处理"标定出来的 |
| 结果 | **整个系统没有稳定地基** |

> **一句话**：前处理网络是"**电路**"，不是"**记忆**"。
> 电路必须稳定，记忆才慢慢变。

### 那"学习"在哪里发生

**只在皮层上。** 具体说：在前额叶、各感觉区的皮层、运动记忆这些地方。
这条界线必须在架构上画清楚——第 3 卷那张图（"写"和"学"的分界线）就是它。

---

## 7.3 顶上那几个数，决定整台电路长什么样

前处理网络的形状**全部**由几个数决定：

| 参数 | 意思 |
|---|---|
| **层数** | 走几道筛子 |
| **连接半径** | 每个细胞看邻居看多远 |
| **权重范围** | 出厂随机权重的区间 |
| **阈值初值** | 多容易亮 |

**改这几个数，就是换一台电路。** 没有别的旋钮。

---

## 7.4 视觉那一版多出来的一层：归一化输出层

视觉的前处理比别处多一个部件，因为**光的绝对值会变**（同一样东西，
在暗处和亮处，像素数值差很多，但它还是同一样东西）。

### 它的做法

输出层不按固定阈值放电，而是**按这一层自己的统计量**来定阈值：

> **阈值 = 全层均值 + α × 全层标准差**

| 参数 | 意思 |
|---|---|
| **全层均值** | 这一拍整层平均有多亮 |
| **全层标准差** | 这一拍整层亮度的离散程度 |
| **α** | 一个系数，**出生时自动校准**（拿 8 帧随机输入跑一遍定下来） |

另外两个开关：

| 开关 | 作用 |
|---|---|
| **输出感受野** | 输出层可以单独用更宽的视野（默认沿用连接半径） |
| **`输出目标亮数 = 0`** | **完全退回旧版**——所有层都用固定阈值。这是留给对照实验的**后门** |

### 这个部件必须**诚实交代**

它是本书 0.7 节列出的**反面教材之一**：

> 用户的原话（多次强调过）：**"参数没调好，就加一段代码去补。"**
> 视觉最后一层这个自动校准 α，就是这种"加代码补"的典型。

**怎么对待它**：

| 做法 | 说明 |
|---|---|
| **不要否认它存在** | 它确实在，而且确实在起作用 |
| **不要假装它是优雅的** | 它是一个补丁 |
| **要能一键关掉** | `输出目标亮数 = 0` 就是那个开关。**所有涉及它的结论都必须报"关掉之后会怎样"** |

> 记一条规矩：**凡是"参数不好调，所以加一段代码"的地方，都要留一个"关掉它"的开关**，
> 并且把它登记在案。

## 7.5 怎么搭

本卷对应零件 4（感觉接口）的信号调理部分。产出：

| 产出 | 要点 |
|---|---|
| **一个多层网络** | 每层神经元数 = 输入层数 |
| **环形局部连接** | 每个细胞连上一层 ±半径，首尾相接 |
| **出生固定权重** | 随机取区间 → 存下来 → **之后永不改** |
| **阈值放电** | 当前层收到的电流够大就亮 |
| **（视觉）归一化输出层** | 阈值 = 均值 + α×标准差；α 出生校准；**留一键关闭** |
| **一个标定脚本** | 给后面的本能表提供"名字 → 哪一撮细胞"的对应 |

## 7.6 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 前处理真的不学习吗 | 让它跑很久，看这几层权重变没变（应该**一个都没变**） |
| 每层数量真的一样吗 | 数一数各层细胞数 |
| 环形连接真的首尾相接吗 | 查最边上的细胞，它的邻居里应该包含另一端的细胞 |
| 归一化输出层真的在起作用吗 | 把 `输出目标亮数` 设 0，对比"亮数是否回到固定阈值那版" |
| 标定出来的名字可靠吗 | 用**没参与标定**的条件去测 |

## 7.7 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **让它学习** | 觉得"端到端都该可塑" | **绝不学**（7.2）。它一动，全部本能标定作废 |
| **做成逐层变小** | 画成金字塔 | 每层数量**等于输入层**（7.1） |
| **忘了环形** | 只在直线上连邻居 | 首尾相接，不然边缘有假断裂 |
| **归一化输出层没有关闭开关** | 加了补丁就不管了 | 必须留一键关闭，并且报"关掉之后怎样"（7.4） |
| **把它的输出当答案** | 盯着前处理输出找"识别结果" | 它是**总线**，不是答案（第 2 卷 2.1） |
| **改前处理去迁就行为** | 行为不对就调前处理参数 | 那是**改地基**。行为靠演化/筛选，不靠改电路 |
