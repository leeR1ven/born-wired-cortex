# 第 9 卷　相反神经元

> **本卷目标**：讲清一条很容易被当成"多余部件"的设计：
> **每一条感觉通道都发两遍**——一个细胞说"到了"，紧挨着的另一个说"没到"。
> 有了它，**"什么都没有"也是一个读数**。

---

## 9.0 一句话原理

> **一根通道，两个读数：一个"有"，一个"没有"。**
> 第二个由"1 减去第一个"驱动，**同一步里**就位。

### 生活里的比喻

想一盏**门口的信号灯**：

- 只装一个红灯，"亮"表示有人来了。
- 那么灯灭的时候，你**分不清**是"没人来"还是"灯坏了、线断了、停电了"。

再装一盏绿灯，**永远和红灯相反**：

- 红灯亮 = 有人；绿灯亮 = 没人。
- 现在**任何时刻都有一个灯是亮的**，你永远不会对着"全灭"发呆。

**这就是"连'什么都没有'也有一对"的意思。**

---

## 9.1 它长在哪

每一种感觉通道都配一对。范围比你以为的广：

| 通道 | 配了什么 |
|---|---|
| **每一个光感受细胞** | 旁边一个伴生细胞 |
| **听觉**（三张表） | 分别配 6 个、6 个、4 个伴生细胞 |
| **触觉 / 足部障碍 / 足部负载 / 足部打滑** | 每一种配 **4 个**伴生细胞 |

### 一条规则：伴生细胞怎么算

> **伴生细胞 = 1 − 同一个数**，在**同一步**里驱动。
> 所以**第一个不亮的时候，第二个一定亮。**

### 视觉那一对还多一样东西

视觉的"没亮那一半"**会汇到它自己的一张表上**（`retina_opposite`），
用的增益和分区规则跟"亮的那一半"汇到 `retina` 时**完全一样**。

**别的通道没有这个待遇。** 这是视觉特有的。

---

## 9.2 为什么必须有它：没有它，模型不知道"外面是空的"

### 论文实测（几种"什么都没有"的情况）

在出生动物上，三个种子各测一遍：

| 情况 | 通道读数 | 伴生细胞读数 |
|---|---|---|
| **黑屏** | 亮的那一半 **0.00000** | 没亮的那一半 **0.96985**；它自己的那张表 **0.97143** |
| **白屏** | 两个**对调** | 同上 |
| **安静的屋子** | 听觉通道 **0.00000** | 它的伴生细胞 **0.98983** |
| **站着，什么都没碰到身体** | 触觉 / 障碍 / 打滑都是 **0.00000** | 它们的伴生细胞都是 **1.00000** |
| **四只脚负重** | 每只脚 **0.42 ~ 0.54** | 每只脚的 负载 + 伴生 = **1.000**（四只脚最大误差 **0.000**） |

题库里有四道题问的就是这件事：

- `the_dark_room_is_not_silence`（黑屋子不等于安静）
- `a_quiet_room_is_not_a_sound`（安静的屋子不等于有声音）
- `nothing_touching_it_is_not_nothing`（没东西碰它不等于"没有"）
- `the_weight_pair_still_carries_the_weight`（负重那一对仍然带着负重）

**出生动物在三个种子上四道全过。**

### 用户的口径（同源的另一半）

用户讲得更直接：**一个管"屈"一个管"伸"，一个管"向左"一个管"向右"；
外界没信号时，由那只"报安静"的细胞亮。**

---

## 9.3 它**不做**什么（边界要划清）

这条特别重要，因为很容易越做越多：

| 它不做 | 说明 |
|---|---|
| 不是"三路互相抑制" | 就是**一对**，不是三路互斗 |
| 没有别的功能 | 不负责判断、不负责决策、不负责"注意" |
| 只是**一对** | 一个说"有"，一个说"没有" |

> **架构原话**：**"不做别的。"**

---

## 9.4 它和"特征的正反一对"是**同源**的

第 6 卷讲过：特征用**正、反一对**表示，竞争，恰好亮一个。
这里的"相反神经元"是**同一套做法的另一种形式**。

| | 特征的正反一对 | 相反神经元 |
|---|---|---|
| 在哪 | 特征层 | 每种感觉通道上 |
| 一对里 | 正 / 反 | "到了" / "没到" |
| 共同点 | **都是"用一对细胞表达一个二值事实"** | 同左 |

**记住这个共性**：这套系统里，"**一个事实用一对细胞表示**"是一个**反复出现的模式**，
不是两个凑巧相似的部件。

---

## 9.5 代价和边界：必须诚实交代

### 它的代价（论文自己报的）

| 项 | 数字 |
|---|---|
| 多出来多少细胞 | **165,938** |
| 多出来多少突触 | **165,888** |
| 其中：每个光感受细胞配一个伴生细胞 | 165,888 个突触 |
| 其中：没亮那一半自己的汇总表 | 18 个细胞 |
| 其中：四种反射感觉各配 4 个伴生 | 32 个 |
| 配置对比 | **750,075 个细胞 / 1,978,219 个突触**（不加它是 584,137 / 1,812,331） |
| 每步耗时对比 | **13.29 毫秒**（不加它是 11.19 毫秒） |

> 反射通道的那几个伴生细胞**不带突触**。

### **它目前还没有做到的事**（论文原话大意）

这一段必须原样保留，不许写成"已经好了"：

> **目前还没有任何下游去读任何一对里的第二个细胞。**
> 没有一条边从"相反表"通向反射、联想或运动细胞；
> 画面**暗的那一半停在它自己那张汇总表上**。
>
> 所以：**一张黑画面目前仍然到不了任何反射细胞**，
> 这**不是**在声称"动物注意到了灯灭了"。

### 为什么这是个老问题

> 早先那个单层版本有**同一个缺口，原因不同**，而且当时就报出来了：
> 因为那一版把一对**加成"一个数"**放到最后一层，
> 于是黑帧会让整张输出表**全被压住、一片黑**——
> 因为每一对的"负"细胞全亮了，而它们上面**没有任何东西偏好暗**。
>
> 要补上这个缺口，需要**偏好暗的细胞**——
> 就像视网膜同时有 ON 细胞和 OFF 细胞那样，让"没亮的画面"能驱动上面的一层。
> **那是一个独立的结构步骤，有它自己的测量，本书这一版没有做。**

## 9.6 怎么搭

| 产出 | 要点 |
|---|---|
| **每条通道配一个伴生细胞** | 伴生 = 1 − 原值，**同一步**驱动 |
| **视觉多一张表** | 没亮的那一半汇到自己那张表，增益和分区规则跟亮的一半一样 |
| **不加别的** | 不做三路互斥，不加额外功能 |
| **留出接口** | 让"下游读第二个细胞"这件事**将来能接上**（虽然现在还没接） |

---

## 9.7 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| "什么都没有"真的有读数吗 | 跑黑屏 / 安静 / 不接触三种情况，看伴生细胞是不是亮着 |
| 一对真的和起来是 1 吗 | 查负重：`负载 + 伴生 = 1.000`（四只脚都查） |
| 白屏和黑屏真的对调吗 | 两种条件各跑一遍，两个读数应该互换 |
| 下游真的没读第二个细胞吗 | 查"相反表"的出边——**应该是零条** |
| 那四道题库题真的过了吗 | 跑 `taskbank.py`，看三个种子的通过情况 |

---

## 9.8 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **把它当成"多余的一倍细胞"** | 觉得浪费，想省掉 | 没有它，**"什么都没有"就不是一个读数**（9.2） |
| **越做越多** | 加上三路互斥、加上判断 | **不做别的**。就是一对（9.3） |
| **一对"加成两个数"** | 到最后把两个读数合成一个标量 | 早先那个版本就是这么坏的：黑帧会让整张输出表**全黑** |
| **声称"它知道灯灭了"** | 把"有读数"说成"有知觉" | 论文明确说：**下游还没有人读第二个细胞**（9.5） |
| **忘了它和"特征正反一对"同源** | 当成两个无关部件 | 它们是**同一个模式**（9.4） |
