# 第 34 卷　例子四：色标导航与人形

> 这一卷讲两个"**还没成功**"的例子。
> **它们存在的意义，恰恰是"照实报"这件事本身。**

---

## 34.0 一句话原理

> **这两个例子都"部分开展、未通过验收"。**
> 书里照样写，因为**"未能通过验收"这件事本身就是结果**。

---

## 34.1 色标导航：它想问什么

### 环境

| 项 | 值 |
|---|---|
| 场地 | **10 × 8 m**，**带墙** |
| 目标 | **三个色标** |
| 提示 | 先听一段 **0.6 秒的声音**，之后**静音**，自己找 |
| 给它的输入 | **只有**深度 / RGB 射线、速度、痛触、PCM |
| **不给** | **目标名、坐标、地图、路线、距离**——**全都不给** |
| 奖励 | **只在第一次进入判定范围时给一次 +1** |

### 它想测的能力（这是重点）

> **"要出屋，必须先出卧室"** —— 也就是**先后依赖**：
> 一件事必须在另一件事之前完成，才能到达目标。

---

## 34.2 色标导航：结果（照实报）

| 项 | 结果 |
|---|---|
| 部分路线出现**学习收益** | ✅ 有 |
| **"学会先后依赖、稳定到达"的验收** | ❌ **未通过** |
| 12 回合成功次数 | **4** 次（红 **2**、蓝 **2**、绿 **0**） |
| 一个刺眼的对照 | **关闭顺序通路之后，总成绩反而更好** |

> **最后这一行是决定性的**：
> 关掉"顺序"这条通路，成绩反而变好——说明**它并没有在用顺序信息**。
> **所以我们不能声称它"理解了要出屋必须先出卧室"。**

---

## 34.3 色标导航留下的最重要一件东西：**三件事要分开验收**

这是本卷最有价值的产出，**它是一条通用的方法论**。

| # | 要验收什么 | 说人话 | 它有没有 |
|---|---|---|---|
| 1 | **连续发生** | A 然后 B **先后出现** | 可能已经有 |
| 2 | **顺序影响动作** | 把 A、B 调换，**动作会变** | 需要专门测 |
| 3 | **掌握因果前置条件** | 知道"没有 A 就到不了目标" | **本条未通过** |

> **很多项目会拿第 1 条当第 3 条的成果上报。**
> 这三条分开以后，"到底做到了哪一层"就**赖不掉**了。

---

## 34.4 人形：它想问什么

| 项 | 值 |
|---|---|
| 身体 | `人形.xml`（`experiments/motor_experiments`） |
| 任务 | **站立** |
| 本能区连接 | **582** |
| 每一代怎么考 | **96 × 2 回合** |
| 成功标准 | **坚持 2.6 秒** |

---

## 34.5 人形：结果（照实报）

| 项 | 结果 |
|---|---|
| 跑到第 **186 代** | **停滞了 120 代** |
| 之后怎么办 | 围绕**历史最佳**（**1.26 秒**）**重启探索** |
| **历史最佳** | **只到 1.26 秒** |
| **成功标准** | **2.6 秒** |
| **结论** | **没到。照实报。** |

> **"停滞 120 代之后重启探索"是一个可以复用的做法**：
> 一直在原地打转时，**回到历史最佳附近重新撒种子**，
> 而不是继续在已经没希望的区域里随机。

---

## 34.6 一份必须交代的档案：`未采用说明.md`

`experiments/architecture_integration/未采用说明.md` 这份文件本身**就是一个诚实样板**。它交代了三件事：

| # | 交代什么 |
|---|---|
| 1 | **2026-09-06 用户明确纠正**：**不需要分开保存记忆**——模型**共用时间神经元**、所有记忆**按顺序关联**、**不得擅自改架构** |
| 2 | 这个目录是**未采用的整合草稿**，**不能当作原架构的验收结果** |
| 3 | 导航原型里"**清空 `previous_event_id`**"是一个**已发现但未改**的偏离 |

**并且指明真源**：时间机制见 `海马体时间区_hippocampal_time.py`——
**全系统只有一个共享时钟，时间环每刻只有一个当前时间细胞激活**。

> **这份文件的价值**：它把"**我做过一个东西，但它不算数**"这件事**写在明面上**。
> 没有这份说明，后来的人（包括自己）会把草稿当成成果。

---

## 34.7 这两个例子教给我们的通用道理

| 道理 | 证据 |
|---|---|
| **"未通过验收"要照实写** | 色标导航、人形都写了 |
| **一个刺眼的对照比一堆好看的数字有用** | "关掉顺序通路反而更好" |
| **同一个词在不同层次上有不同含义，必须拆开验收** | 连续发生 / 顺序影响 / 因果前置 |
| **停滞时的正确做法是回到历史最佳重启** | 人形 186 代 |
| **草稿要标明是草稿** | `未采用说明.md` |
| **偏离要登记，哪怕还没修** | "清空 `previous_event_id`" |

---

## 34.8 怎么搭

| 步骤 | 做什么 |
|---|---|
| 1 | 色标：搭 10×8 带墙场地，只给射线 / 速度 / 痛触 / PCM |
| 2 | 色标：**不给**目标名、坐标、地图、路线、距离 |
| 3 | 色标：**只在第一次进入判定范围给一次 +1** |
| 4 | 色标：**必须做"关掉顺序通路"的对照** |
| 5 | 人形：96 × 2 回合 / 代，成功标准 2.6 秒 |
| 6 | 人形：停滞时**回到历史最佳附近重启** |
| 7 | 两份档案：**未采用的东西写说明；发现的偏离登记** |

---

## 34.9 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 它真的用了顺序信息吗 | **关掉顺序通路**再跑，成绩应该变差（本例：**反而更好**→ 说明没用） |
| 它是"连续发生"还是"掌握因果" | 按 34.3 三层次**分别**设计测试 |
| 人形是不是停滞了 | 看连续多少代没有改进（本例 **120 代**） |
| 偏离有没有被掩盖 | 查有没有 `未采用说明.md` 这类档案 |
| 时间机制有没有被改 | 查**是不是只有一个时钟**（真源：`海马体时间区_hippocampal_time.py`） |

---

## 34.10 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **拿"连续发生"当"掌握因果"** | 上报成功 | 三层次**必须分开验收** |
| **不做"关掉某条通路"的对照** | 说不清它有没有用那条路 | 必须做（本例揭示了真相） |
| **把草稿当成果** | 引用未采用的整合目录 | 它有明确的"未采用"说明 |
| **偏离不登记** | 以后自己都忘了 | 登记，哪怕没修 |
| **停滞时继续原地随机** | 白烧机时 | **回到历史最佳附近重启** |
| **"差不多快到 2.6 秒了"** | 想四舍五入 | **1.26 就是 1.26**，没到就是没到 |
| **记忆分开存** | 各建一套 | **共用时间神经元**，**所有记忆按顺序关联** |
