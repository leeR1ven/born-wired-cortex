# 第 32 卷　例子二：机器狗（四条腿 + 两只眼睛）

> **这是四个例子里的"主力"**：论文里 R1–R9 的数字基本都来自它。
> 本卷按**同一张模板**讲：**身体 → 感觉 → 本能表 → 基因 → 题库 → 结果 → 通用道理**。

---

## 32.0 一句话原理

> **四条腿的身体 + 585 条写好的本能 + 一条学习规则 = 会站、会走、看见红球会走过去。**
> 全程**没有奖励、没有目标、没有反向传播**。

## 32.4 结果：论文 R1–R8（照实抄）

### R1　**天生接线就能闭环**

| 测什么 | 结果 |
|---|---|
| 趴着能不能自己站起来 | **5/5**（中位 **0.256 m**；12 个种子 **12/12**） |
| 看见红球会不会走过去 | **5/5**（中位 **+1.61 m**；论文他处 **+1.73 m**） |
| **不给任何感觉**会怎样 | **5/5 全塌**（0.184 m、倾斜 **41°**） |
| **把本能表清空**会怎样 | **站起来 0/5、走 0/5**，每个种子**正好 0.184 m** |

> **最后一行是全套设计最硬的证据**：
> **清空本能表 → 什么都做不到**。说明这些行为**真的是那张表给的**，
> 不是"随机连出来的运气"。

### R2　**行为是由特定细胞群算出来的**

| 条件 | 走动成功的比例 |
|---|---|
| 红球 + 前额叶正常 | **199/200** |
| **把那一块细胞按灭** | **0/200** |
| 黑屏 | **0/200** |
| 蓝屏 | **0/200** |

**"红 → 走"是两条规则合起来的结果**：

| 来源 | 电流 |
|---|---|
| 视觉那一路 | **0.80** |
| 前额叶那一路 | **0.85** |
| 阈值 | **1.0** |
| **结论** | **各自都不够，合起来才够** |

> **⚠️ 故意不叫"与门"**：它是**线性求和后过阈值**，
> 不是逻辑与。用"与门"这个词会让人以为里面有个判断。**（附录 A 有登记）**

### R3　**本事靠加结构，不靠重训**

| 阶段 | 本能条数 | 结果 |
|---|---|---|
| A | **221** | 会站会走 |
| B | **227** | 加一种能力 |
| C | **233** | 再加一种 |
| D | **236** | 再加一种 |
| E | **581** | 再加一批 |

**每种新能力只由自己那组规则点亮，而且不破坏已有的。**

**一处照实报的失败**：

| 测什么 | 结果 | 判据 |
|---|---|---|
| 红球单独 | **199/200** | — |
| 红球 + 声音（想让它"被音叫停"） | **15/200** | **判据是 ≤10 才过** |
| **判定** | **失败（0/3）** | **没有改判据，照实报失败** |

> **这一条比任何一个成功数字都重要**：它证明"照实报"是真的在做，不是口号。

### R4　**认得出的边界**

| 测什么 | 结果 |
|---|---|
| 色相**渐变**（红→黄绿），**开着学习** | 停在 **96°**（15 次里 **13** 次） |
| 同一件事，**关掉学习** | 中位 **78°** |
| 结论 | **学习填边界，不画边界** |

**另一条更狠的结果**：

| 刺激 | "红"这个块被点亮多少 |
|---|---|
| 青屏 | **42%** |
| 蓝屏 | **25%** |

> **所以：系统里没有任何东西表示"红"。**
> 说"它认出红色了"是**人加上去的说法**。

### R5　**层级压缩的代价**

| 看哪一层 | 红球在视野里时新亮的细胞 |
|---|---|
| **第 1 层** | **完美定位**——全在球那一列 |
| **压缩输出层** | 散到 **13 列**；**正中央的球 0 个新细胞** |
| 输入层每球能看到几个细胞 | **11 个** |

**方向名跨列共享的程度**：

| 层 | 共享程度 |
|---|---|
| 第 1、2 层 | **0.00** |
| 压缩层 | 中位 **0.14**，最差 **0.75** |

> **结论**：**信息是在层级里丢的，不是图像里丢的**（第 18 卷）。

### R6　**注视是长出来的**

| 本能组成 | 条数 |
|---|---|
| 静态 | **14** |
| **运动起始** | **322** |

| 场景 | 响应 |
|---|---|
| 小球穿过 | **5.6°** |
| 小球突然出现 | **4.8°** |
| **空场** | **0.0°** |

> **空场 0.0°** 是这里最关键的一个数：**没有对象就不动**——说明它认的是"有个东西"。

### R7　**天生地图偏移带来系统偏差**

| 项 | 结果 |
|---|---|
| 整体偏移 | **−3 ~ +3 列** |
| 结果 | **线性**：3.2° / 9.7° / 16.2° |
| 走路还工作吗 | **都 7/8** |
| **存活曲线** | 走路**只靠 2 条规则却能丢 1/4**；注视**靠 336 条却最先坏**；**听觉最顽强** |

### R8　**刺激发令，皮层运行**

| 测什么 | 结果 |
|---|---|
| 撤掉红球后，走路还能不能继续 | **495/495** |
| **掐掉回响**（皮层自己的循环） | **站立 0.184 m 0/3、走路 0/3** |
| 同一条件下，**注视** | **5.6° 不变** |

> **结论**：**反射是写好的，动作是轨迹。**
> 掐掉回响，反射还在（注视不变），但**动作跑不完**。

## 32.7 这个例子教给我们的通用道理

| 道理 | 证据 |
|---|---|
| **本能表清空 → 什么都做不到** | R1（0/5、0/5，且**每个种子正好 0.184 m**） |
| **一个行为可以"各自不够、合起来才够"** | R2（0.80 + 0.85 > 1.0） |
| **加结构就能加本事，不用重训** | R3（221 → 581，逐步加且不破坏已有） |
| **"它认出了什么"往往是人的说法** | R4（"红"被青屏点亮 42%） |
| **压缩是有代价的** | R5（第 1 层准、压缩层散） |
| **反射和动作不是一回事** | R8（掐回响：注视不变、动作没了） |
| **失败要照实报** | R3（0/3 失败，**不改判据**） |

## 32.8 怎么搭

| 步骤 | 做什么 |
|---|---|
| 1 | 接上 MuJoCo 身体（关节角伺服、每拍 10 个子步） |
| 2 | 按 32.2 做六路感觉接口（**接口只翻译、不判断**） |

## 32.9 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 行为真的是本能表给的 | **清空本能表**再跑（应 0/5、0/5） |
| 行为真的是某块细胞算的 | **把那一块按灭**（应 0/200） |
| 它真的在"看"红球吗 | 黑屏 / 蓝屏对照（应 0/200） |
| 认得出是有边界的吗 | 色相渐变，看停在哪（96°），并和关学习比（78°） |
| 它认的是"红"还是"亮块" | 用青屏 / 蓝屏点亮"红"那块（42% / 25%——说明没有"红"） |
| 回响真的必要吗 | 掐掉回响：动作应停、注视应不变 |
| 偏移有没有余量 | 人为偏 −3 ~ +3 列，看行为曲线是不是线性、还能不能走 |

## 32.10 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **说"红 → 走是一个与门"** | 听起来像有逻辑判断 | 它是**线性求和过阈值**；"与门"是错词 |
| **说"它认出了红色"** | 从行为倒推感受 | 青屏 42%、蓝屏 25%——**没有东西表示"红"** |
| **只报成功不报失败** | 报告好看 | "被音叫停"**0/3 失败**，**没改判据** |
| **不做"按灭细胞"的对照** | 说不清行为从哪来 | 必须做（R2） |
| **不做"清空本能表"的对照** | 以为是随机连出来的 | 必须做（R1） |
| **掐掉回响时说"它全坏了"** | 一概而论 | **注视不变、动作没了**——要分开说 |
| **以为偏一点就废了** | −3~+3 列就慌 | 走路**都 7/8**，仍是线性 |
| **拿 447 小时去硬跑** | 浪费机时 | 用**筛选流程**（第 36 卷） |
