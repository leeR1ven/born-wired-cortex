# 第 31 卷　例子一：最小的小球（1,000 个细胞）

> **为什么先讲这个例子**：因为它**小到你能一口气看完**。
> 前四编讲的每一条规则，都能在这个例子里亲手验一遍。

---

## 31.0 一句话原理

> **1,000 个细胞，就足够看到"生来有连接 + 一条局部规则"这套东西的全部现象。**
> 它站不起来、走不了路，但**该发生的都发生了**。

### 生活里的比喻

造模型像学开车：你要练的是**起步、换挡、看镜子**，
不必第一天就开一辆十八轮卡车。
**这个小球就是那辆教练车。**

---

## 31.1 身体与规模

| 区 | 细胞数 |
|---|---|
| 视觉 | **300** |
| 听觉 | **200** |
| 前额叶 | **400** |
| 运动 | **100** |
| **合计** | **约 1,000** |

**没有腿、没有眼睛电机**——"运动"只是一个能亮能看的输出区。
所以这个例子里**只测"网"本身的行为**，不测"身体动作"。

---

## 31.2 五项自检（这个例子存在的全部意义）

五项里每一项，都对应前面某一编的一条规则。

| # | 自检什么 | 观察到的现象 | 对应规则 |
|---|---|---|---|
| 1 | **出生就有连接，而且带出别的区** | 视觉亮 **120** → 全脑活动**稳在 277** | 第 17 卷"一半跨区" |
| 2 | **反复共亮会长出新短路** | 同一条边：**0 → 0.02 → 0.69 → 0.9998** | 第 20 卷"涨 + 新建" |
| 3 | **固化的边不被改** | 带固化标记的边，权重**一点没动** | 第 20 卷"冻结" |
| 4 | **无关的会互相抑制变强** | 出现了 **28,320 条强抑制边 / 3,237 条弱抑制边** | 第 26 卷"越无关抑制越强" |
| 5 | **去抑制会发生** | 去抑制的边确实长出来了 | 第 20 / 26 卷"去抑制侧学习" |

### 第 2 项那串数字为什么值得看

```
0 → 0.02 → 0.69 → 0.9998
```

| 阶段 | 在发生什么 |
|---|---|
| 0 | 本来没有这根边 |
| 0.02 | 共激活够 4 次，以 **0.001** 建立、然后开始涨 |
| 0.69 | 稳定上涨期 |
| 0.9998 | **逼近天花板 1**——这就是"反复用不会无脑涨"的证据：**它停住了** |

> **注意最后一位小数**：`(1 − w)` 越大涨得越多，所以它**越来越慢**，
> 是"**渐近**"到 1，不是"冲过头再被裁回来"。

### 第 4 项那对数字为什么值得看

**强抑制边比弱抑制边多了近 9 倍**（28,320 vs 3,237）。
这不是巧合，是"**无关的越来越互相抑制**"的直接体现。

---

## 31.3 这个例子最值钱的一课：**刀锋问题**

### 第一次跑就翻车了

| 版本 | 现象 |
|---|---|
| 第一版：把输入调成"亮 **20** 个" | **全灭**——什么都不亮 |
| 第一版：把输入调成"亮 **120** 个" | **全亮**——整张网一起亮 |

**为什么叫"刀锋"**：参数能用的区间**窄得像刀刃**——这边全灭、那边全亮，中间几乎没路。

### 怎么解决的：**调参数**，不是加代码

| 做法 | 说明 |
|---|---|
| 目标 | 让**每个神经元的抑制输出总和，和它的兴奋总和相当**（100 条抑制要跟兴奋同量级） |
| 手段 | 扫参数：**25 组** |
| 结果 | **合格带很宽** |
| 定下来的默认值 | **阈值 1.0 + 抑制强度 1.5** |

> **这一课极其重要**：
> 遇到"刀锋"时，正确反应是**回去把参数调到平衡**，
> **不是**加一段"如果太亮就压一压"的代码。
>
> 后者正是被用户点名批评的**同一个毛病**（第 26 卷）。**这个例子就是那条红线的正面教材。**

---

## 31.4 这个例子教给我们的通用道理

| 道理 | 为什么 |
|---|---|
| **小规模就能验证规则** | 1,000 个细胞就能看到全部五种现象 |
| **先验"网"，再验"身体"** | 身体会引入一堆新变量；先在纯网上把规则验干净 |
| **"合格带很宽"是好设计的标志** | 如果参数必须落在刀尖上才能用，说明**机制不对**，不是"参数难调" |
| **调参数不下补丁** | 31.3 就是范例 |
| **五项自检可以当模板** | 换任何身体，这五项都该先过一遍 |

---

## 31.5 怎么搭

| 步骤 | 做什么 |
|---|---|
| 1 | 按 31.1 建四个区：视觉 300 / 听觉 200 / 前额叶 400 / 运动 100 |
| 2 | 按第 17 卷生成出生连接（一半跨区、[0,0.15]、30% 冻结） |
| 3 | 建抑制池，按第 17 卷分配（一半就近、一半撒开），强度 1.5 |
| 4 | 装上唯一的学习规则（第 20 卷），含上下界、系绳、两个预算、冻结 |
| 5 | 跑五项自检（31.2） |
| 6 | 若出现"全灭 / 全亮"，**回去扫参数**（31.3），不要加代码 |

---

## 31.6 怎么验证

| 你想确认的事 | 怎么验 |
|---|---|
| 跨区连接真的存在吗 | 只点亮视觉 120 个，看**别的区**有没有亮 |
| 共亮真的会长边吗 | 盯着同一条边，记录它从 0 到接近 1 的整条曲线 |
| 固化真的免疫吗 | 跑完比对带标记的边，权重应**逐位相同** |
| 无关真的会互相抑制吗 | 统计强 / 弱抑制边的**条数比**（实测 28,320 / 3,237） |
| 参数是在刀锋上吗 | 扫参数（本例 25 组），看**合格带宽不宽** |

---

## 31.7 常见坑

| 坑 | 症状 | 正确理解 |
|---|---|---|
| **全灭 / 全亮就加代码** | 加"太亮就压一压" | **回去调参数**（31.3） |
| **一上来就上大身体** | 调试变量太多 | 先在 1,000 个细胞上把规则验干净 |
| **只在同区看连接** | 以为跨区连线坏了 | 出生就有一半是**跨区**的 |
| **以为"接近 1"说明要涨爆** | 慌了 | 它是**渐近**到 1，**自己会停** |
| **不数抑制边的强弱比** | 只看"有没有抑制" | 要数**强 / 弱条数**，这才看得出"越无关越强" |
| **把"合格带宽"当成"随便都行"** | 不扫参数 | 宽是**结果**，仍然要**扫** |

## 31.8 自检三问

1. 为什么"第一版亮 20 全灭、亮 120 全亮"这件事，**不能**用"再加一个控制代码"解决？
   正确的做法是什么，为什么它更好？
2. 权重曲线 `0 → 0.02 → 0.69 → 0.9998` 里的**每一段**，分别是哪一条规则在起作用？
3. 如果把这五项自检搬到**机器狗**上，你觉得**哪一项最可能先出问题**？为什么？
