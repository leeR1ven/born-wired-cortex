# 第 35 卷　四个例子放在一起看

> **本卷目标**：回答一个问题——**这套方法到底"通用"到什么程度？**
> 办法是把四个例子并排，看**哪些一个字都没改，哪些必须重写**。

---

## 35.0 一句话原理

> **脑子里那套东西一个字都没改；换世界只换"接口那一圈"。**
> **本能表和题库必须重写**——因为它们是"这个世界的知识"。

### 生活里的比喻

**引擎不变，换车身。**
同一台发动机，装到轿车、卡车、船上都能跑；
但**油箱位置、仪表盘、油门踏板**要重新做。

## 35.2 一个字都没改的东西（这些才是"通用"的部分）

| 部件 | 为什么能不改 |
|---|---|
| **学习规则**（三条更新 + 四个护栏） | 它只看"两个细胞"，**和身体无关** |
| **抑制细胞**（一半就近、一半撒开；强度 1.5） | "就近"靠**门牌号**，和身体无关 |
| **相反神经元**（每通道一对，含"什么都没有"） | 是**模式**，不是**某个器官**的事 |
| **特征神经元**（正反一对、温度计码、**每层都可能**） | 是**表示方式**，和感觉种类无关 |
| **时间与记忆**（一个时钟 + 三个记忆区 + 投票） | 记的是"**哪个时刻哪些细胞亮**" |
| **运动输出那套**（发力温度计、反向赫布、自循环） | 只要身体能被"角度"驱动就能用 |
| **前额叶那套**（七路 → 三层 → 返回线） | 七路是**配置**，不是写死的 |
| **演化流程**（随机生成 → 考试 → 留种） | 和身体无关 |

> **这一栏就是"通用"两个字的全部含义。**

---

## 35.3 必须重写的东西

| 部件 | 为什么必须重写 |
|---|---|
| **感觉接口** | 输入信号的世界不一样（像素 / 频谱 / 字 / 射线） |
| **运动接口** | 身体能怎么动不一样（关节 / 扬声器 / 无） |
| **本能表** | 它是"**这个世界的知识**"：这里该有哪几个动作、哪种刺激接哪个动作 |
| **标定** | 名字要靠**这个世界**的刺激量出来（第 24 卷） |
| **题库** | 什么叫"做对了"是**世界定的** |
| **区宽** | 由"马赛克 × 通道 × 档数 × 2"算出来，随世界变 |

> **注意：要重写的是"与世界的接触面"，不是"脑子里那套"。**

| # | 零件 | 换世界时 |
|---|---|---|

| 2 | 出生连接表 | 参数变，规则不变 |
| 3 | **本能表**（含力度定义） | **重写** |
| 4 | **感觉接口** | **重写** |
| 5 | **运动接口** | **重写** |

| 7 | 抑制细胞 | 不变 |
| 8 | 相反细胞 | 不变 |

| 10 | 闭环 | 换身体后自然成立 |
| 11 | 演化 | 不变（但要换题库） |

## 35.5 "通用"到什么程度：三层说法

| 层次 | 说法 | 证据 |
|---|---|---|
| **强通用** | 学习规则、抑制、相反细胞、时间与记忆、演化流程——**一个字没改** | 35.2 |
| **弱通用** | 感觉 / 运动接口、本能表、题库——**规则不变，内容重写** | 35.3 |
| **不通用** | 具体动作库、具体标定值、具体区宽——**只在这个世界里成立** | 例子里的 585 条、0.30 m 球半径等 |

> **最容易吹过头的地方是第一层**：
> 说"这套方法通用"时，**只该指第一层**。
> 第二层是"**模板通用**"，第三层**根本不通用**。

## 35.6 三个例子给出的三条硬教训

| 教训 | 来自 |
|---|---|
| **小规模就能验规则** | 例子一（1,000 个细胞，五项全过） |
| **失败要照实报，负结果也是结果** | 例子四（色标导航、人形都写了未通过） |
| **研究台要明说自己是研究台** | 例子三（文字网络不承担主线职责） |

## 35.7 怎么用这一卷

| 你要做的事 | 怎么做 |
|---|---|
| 换一个新身体 | 先照 35.2 **原样搬**脑子；只改 35.3 那一圈 |
| 判断一个改动"通不通用" | 问：**它动的是 35.2 还是 35.3？** |
| 判断别人的说法有没有吹 | 看他说的"通用"是**哪一层**（35.5） |
| 想加一个新能力 | 看它是"**加结构**"（本能表）还是"**加接口**"（重写） |

## 35.8 自检三问

1. 如果要把这套方法用到**一个只有触觉、没有视觉**的身体上，
   35.2 里哪些部件要改？35.3 里哪些要重写？
2. "这套方法通用"这句话，**在哪一层**成立、**在哪一层**不成立？
3. 例子三（文字网络）为什么不承担"本能连接的来源"这个职责？**它应该承担什么职责？**
