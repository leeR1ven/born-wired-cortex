## 16.2 每一拍发生的（顺序）

> 一拍 20 毫秒里，下面是**发生顺序**。

| 步 | 发生什么 | 精确处 |
|---|---|---|
| 1 | **感觉接口**把世界变成一团细胞亮度 | 第 15 卷 |
| 2 | 结算**这一拍被点亮的抑制细胞**送出的电流（包括就近那一半和撒开那一半） | 第 5、17 卷 |
| 3 | 每个细胞：**兴奋电流 + 其他到达胞体的电流 ≥ 1.0 且没被压住 → 亮** | 第 5、17 卷 |
| 4 | **前处理网络**按出生固定的权重走一遍（它不学习） | 第 7、19 卷 |
| 5 | 七路汇入**前额叶三层网络**；前额叶内部把**新编码"加"到正在跑的编码上** | 第 13、25 卷 |
| 6 | **返回线**：按各区自己的峰值 40% 送回各感觉区；**身体三区跳过**；**回运动记忆取交集** | 第 13、25 卷 |
| 7 | 运动区：**亮的个数 → 力气 → 16 个目标角度** | 第 11、23 卷 |
| 8 | 物理跑 **10 个 2 毫秒子步** | 第 15 卷 |
| 9 | **时间环走一格**；三个记忆区按帧**挂上 / 放出** | 第 10、22 卷 |
| 10 | **学习规则在"活跃细胞牵连到的那些边"上更新一次** | 第 8、20 卷 |

### 三条和"顺序"有关的重要性质

| 性质 | 说人话 | 精确处 |
|---|---|---|
| **刺激只发令，皮层跑完** | 一个动作被点着一次之后**自己跑下去** | 第 10 卷、论文 R8 |
| **没有单独的推理步骤** | 下一拍是什么，完全由当前权重和到达胞体的电流决定 | 第 2 卷、论文 P2 |
| **两条本能可以各自不够、合起来才够** | 各区的电流**全加起来**过阈值才算（不是"与门"） | 第 11 卷 |

## 16.3 怎么变（学习）

### 三条更新

| 情形 | 规则 |
|---|---|
| 一起亮（顺序对） | `w ← w + η · m · (1 − w)` |
| 亮了但没带亮对方 | `w ← w · (1 − (1 − d) · m)` |
| 反复一起亮过、本来没连接 | **第 4 次**见到时以 **0.001** 建立，然后走上面同一条规则 |

### 参数表

| 参数 | 值 |
|---|---|
| 兴奋学习率 η | **0.005** |
| 每拍衰减 d | **0.995** |
| 新突触出生权重 | **0.001** |
| 建立前要共激活几次 | **4** |
| 每拍最多考察多少对 | **4,000** |
| 每拍最多新建多少根 | **200** |
| 痕迹衰减 / 阈值 | 0.9 / 0.05 |
| 抑制侧学习率 / 上限 | 0.0005 / 0.6 |
| 去抑制侧学习率 | 0.02 |
| 运动 / 运动记忆 / 前庭 / 本体 / 身体状态 的可塑倍率 `m` | **0.02** |

### 四个护栏

| 护栏 | 防什么 |
|---|---|
| **上界（天花板）** | 反复用**一直涨** |
| **下界 + 系绳** | 不用**一直掉**（掉到**出生权重**就停，不是掉到零） |
| **两个预算** | 一拍算不完；或者一拍写爆、人群塌到自己身上 |
| **冻结** | 一辈子的骨架被慢慢磨掉 |

### 三条铁律

| # | 铁律 |
|---|---|
| 60 | **可塑性是"一拍"的一部分，不是这个系统的一种模式**；它从出生就在跑 |
| 61 | **它永远看不到奖励、目标或误差** |
| 62 | 这个配置里**没有**"突触后自己亮了就压低权重"那一项（论文 4.6 把它列为失败 / 待补） |
| 63 | **稳定性是"更新规则"的性质，不是"衰减项"的性质**：全系统**任何地方都不该有**"因为网络长太强了所以压低权重"这种项 |

### 多巴胺（快速路）

| # | 规则 |
|---|---|
| 64 | 多巴胺区一亮，就把**上一拍亮的细胞 → 这一拍才亮的细胞**之间的连接**当拍写下来** |
| 65 | 三个约束：**① 两拍都亮的细胞要排除；② 每个目标最多 8 个源、总驱动固定 0.50 均分；③ 快速路也要乘该区的 `m`** |
| 66 | 它是一个**许可证**（"这一刻算数"），**不是分数、不是裁判、不是老师**；它只能加强**它真的做了的事** |

### 抑制侧的学习

| 情形 | 结果 |
|---|---|
| 一个亮、另一个不亮 | 亮的一方对它的**抑制变强**（有上限） |
| 两个一起亮 | **抑制变弱**、**去抑制变强** |

## 16.4 怎么读（从外面怎么看懂它在干什么）

### 四个"读法"

| 想读什么 | 怎么读 |
|---|---|
| **它此刻在做什么动作** | 看运动区那 160 个细胞：**亮的个数就是力气** |
| **它此刻在想/看到什么** | 找"**一小撮一起亮的细胞**"。**每一层都可能是特征**，不是只有最后一层 |
| **它想起了什么** | 看时间细胞：**票最多且明显领先**的那个时刻 |
| **它是不是真的看到了** | **做对照**：把刺激搬走，看行为变不变 |

### 一套诊断手法（第六编会用）

| 手法 | 用来判断 |
|---|---|
| **只点一次**走路的头细胞 | 走路链**自己转不转** |
| **关掉学习**再跑一遍 | 这个行为是**学来的**还是**本能就有的** |
| **多巴胺不亮**再跑一遍 | 这个连接是**许可证写的**还是别的路给的 |
| **把刺激搬走** | 它是**真的在看**，还是碰巧 |
| **换没见过的位置复考** | 它是**真的认那个东西**，还是认了那个位置 |

### 一条常被问的问题

> **"视觉皮层被点亮，就算看到了吗？"**
>
> **算。链路没断。缺的只是一个"给人看的读出器"——那是仪表，不是架构。**
> **不要为了让自己看清楚，往架构里塞东西。**

### 这本书不声明什么

第 40 卷专门列。这里先立个态度：

> **没做到的就说没做到；说过的、后被数据推翻的，明确写"撤回"（登记在附录 A）。**
